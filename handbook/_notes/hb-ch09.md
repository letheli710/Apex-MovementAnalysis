## 2. 研究和 Unity 对不上的地方（章里两边都写了，没悄悄选）

和 hb-ch07 `_notes` §2 的 1–3 是同一件事，本章 §8 汇总表的 1–3 和那里一致。新增的：

1. **冲刺到开火没做**（章 §4.4）：R5 0.138–0.249 s，Unity 0。GM INDEX "Unity 该改什么"第 4 条早就写了"要改"，到 U#71 还没有。钩爪拉动中、爬墙段不能开火（FG §8，11-13）也没在 Unity 里找到。
2. **开镜漂移没做**（章 §3.7）：R5 开镜 ±0.3°，进子弹。RV §10.4 写"只有字段，公式没读"。
3. **单发枪开镜跳动、拉栓镜头没做**（章 §2.7、§2.8）：D-95 写了"没做"。
4. **下蹲比例只有 0 / 1**（章 §2.3）：RV §10.4 已登记。
5. **扩散锥半径可能差 2 倍**（章 §5.2）：`SpreadState.Cone` 用 `tan(degrees) × √U`，把读数当半角；TF2 `ApplyVectorSpread` 用 `sin(角/2)`，`GetAttackSpreadAngle` 的说明是"锥一边到另一边"（全角）。R5 腰射落点没测过，所以**没法说 Unity 错**，但如果 R5 和 TF2 一样，Unity 的腰射散得是 R5 的 2 倍。**建议优先核对**（不用 R5：读 Unity 测试的期望值和 IP2 / GM 的命中分布有没有间接证据；或者一次 R5 腰射落点实测）。
6. **开镜灵敏度用当前帧 FOV**（章 §3.6）：R5 用上一帧（EM §2，207 帧中位误差 0）。差 1 帧，影响很小，没写进 R5-DIFF。

以上 1–3、5 建议进 R5-DIFF "二 未改"或 99（hb-integrate 决定）；4、6 可以只记 99。
