## 2. 研究和 Unity 对不上的地方（两边都写在章里了，没悄悄选）

1. **第二组弹簧在 Unity 是两个**：R5 的移动事件 × 0.2 和武器 kick 进**同一个**第二组（拿枪时用武器弹簧，FG §1.3，PR #122）。Unity 原生镜头的 `punch2*` 永远 65 / 9、不乘 (1 − fraction)；武器 punch 是另一个 `ViewKick`（HSD-Unity PR #67）。影响：拿枪时移动事件第二组的峰值 R5 小（R-301 腰射 0.13 倍对 0.20 倍），总峰值差约 6 %。
2. **子弹不含 punch1 和开镜 drift**：FG §1、§5（11-13 实测）说子弹 = aim + punch1 + punch2 + 开镜 drift；Unity `ViewKick` 还是 aim + 武器 punch。落地 0.1 s 后开枪，R5 子弹低 16–17°，Unity 不低。
3. **鼠标抵消 punch 没做**（EM §1；`ViewKick` 注释写明留在 R5-DIFF）。
4. **`PunchAxis` 没有归零门槛**：DP T8 说 R5 弹簧 |x|² + |v|² < 0.001 归零（武器弹簧实测）；移动 punch 是否也归零没单独验证，Unity 移动 punch 不归零。差 < 0.03°。
5. **二段跳峰值三处写法不一样**：公式 (4.5 ± 0.5)·20 × 0.0771 = 6.2–7.7°（DP §6.2、本章）；DIFF FND 写"约 5.6–7.7°"；NC.cs `doubleJumpPunch` 注释写"Peak 4.6–6.6°"。本章按公式写 6.2–7.7°，建议改 DIFF 和 Unity 注释。
6. **CR §3.1 眼高 64**：本章用 70（K-4），已在出处标注。
7. **SKILL 过时两处**（00-INVENTORY 已登记）：还写 DP 在 PR #94；规则 2 子弹公式缺 punch1、drift。

以上 1–3 是 HSD 现在可能做错的，建议进 99 或 R5-DIFF（hb-integrate 决定）。
