# 实践检验 A2：冲刺（dash）设计

由 hb-slam 写（2026-11-14）。分支 `practice/dash`（叠在 `practice/slam` 上），还没合并。用户试玩下砸接滑铲后说"不够明显"，要一个像《三角洲行动》威龙"动力推进"那样的冲刺。**参考作品只借机制，不照抄**；参考作品的数（总控查的玩家攻略和社区 wiki，日期不一）标 [参考]，从手册推出来的标出处，拍板的标 [设计]。这份设计在写 Unity 代码之前提交；实现时改的地方只写在 §8。

下砸接滑铲保留在"实验动作"开关后面，默认关，不删。

## 白话说明

**一句话**：按一下冲刺键（默认左 Alt，或鼠标侧键），角色朝方向键指的方向（相对视角，水平面）猛冲约 10 m，用 1/3 秒；冲完保留不低于 420 u/s 的速度继续跑。空中也能冲，冲刺中不掉高度，所以"跳 + 冲"能飞过 10 m 的坑、冲到墙上接翻越上楼顶。冲完 0.25 s 内不能开枪。一次充能，冷却 15 s（试玩 build 设成 2 s），击倒敌人缩短冷却。

**要明显**（用户这次的核心意见）：开始那一下画面 FOV 猛地张开约 12°、再在 0.35 s 里收回，同时一个镜头 kick；侧冲带横滚；一个"喷气"声。FOV 和声音手册里判为 R5 没有的东西，所以都写成**偏离**、单独开关（§2.6）。

**和总控初稿不一样的地方**：

1. **时长 0.33 s，不是 0.20–0.25 s**。初稿的三个数（10 m、0.20–0.25 s、峰值约 2000 u/s 而且先快后慢）互相矛盾：0.22 s 走 394 u 的平均速度已经是 1790 u/s，峰值 2000 时曲线几乎是平的，没有"先爆发后放缓"。保留 10 m 和峰值 2000、用线性减速，时长就是 0.33 s（§2.2）。没选的两种写在 §2.9。
2. **出口速度用 max(420, 冲刺前的水平速度)**，不是固定 420。固定 420 会把冲刺前更快的速度（滑铲 460、下砸 520、钩爪 800）削掉，违反 P3"没有条件的削减不允许"（06 §6.1）。
3. **按键不用 V**：V 已经是投掷物（按住，`PracticeGame` 的 `ordnance`）。

## 1. 原理

1. **驱动者**（06 §6.1 第 5 种、§6.7、10 §10.2）：冲刺期间这个能力决定身体的速度，结束时按自己的规则交还（"替换"成出口速度）。和 Vantage 的 Echo 位移（05 §5.52）同一类：起飞快、之后按曲线降速。R5 里最接近的就是它。
2. **地板低、天花板高**（P4，03 §3.13）：一个键、方向就是方向键，不需要练也能用；会用的人拿它过坑、上楼顶、打断滑铲、侧闪。
3. **威力换预告、冷却**（P9，10 §10.1、§10.3）：冲刺很强，所以只有一格充能、冷却长（15 s，参考作品）；击倒敌人缩短冷却是"奖励进攻"。试玩 build 用 2 s 让用户能反复试。
4. **一次性的可以响亮**（P2，07 §4.4）：kick 和横滚都是一次性的，可以大；但"FOV 跳"和"喷气声"R5 移动里没有（07 §3.10 第 5 条、§6），只能是**偏离**。用户明确要求"要明显"，所以这两个偏离在冲刺里默认开，但各有开关，写进 D 行。
5. **镜头不改瞄准**（P1，07 §4.3）：冲刺中可以转视角（参考作品如此），镜头效果只加在画面上。

方向：方向键合成的意图方向（相对视角偏航，水平面，06 §6.12 的轴值）；没按方向键时 = 视角正前方。冲刺中方向**锁定**（转视角只转画面和瞄准，不转冲刺方向）。[设计]：参考作品"可以转视角"没说方向跟不跟；锁定和 Vantage 起飞后方向固定（05 §5.52）、滑索方向固定（05 §5.15 第 7 条）一致。

### 2.2 速度曲线

冲刺持续 T，水平速度从峰值线性降到出口值（位置是"先快后慢"的二次曲线）：

v(t) = v_exit + (v_peak − v_exit) · (1 − t/T)，距离 D = T · (v_exit + v_peak) / 2

| 量 | [m] | HSD 设计值 [u] | 身高比例 | 合理范围 | 依据 |
|---|---|---|---|---|---|
| 冲刺距离 D（算出来的，T = 40 条命令） | 10.24 m | 403.3 u | 5.60 H | 9–11 m | [参考] 约 10 m |
| 峰值 `peakSpeed` | 50.8 m/s | 2000 u/s | 27.8 H/s | 1150–2500 | [设计]（总控初稿）；R5 最快的一次性速度是跳板 / 扑击 1150（05 §5.32、§5.50），冲刺是它的约 1.7 倍 |
| 曲线出口 `exitSpeed` | 10.67 m/s | 420 u/s | 5.83 H/s | 299–460 | [设计]：高于冲刺 299（03 §3.1，冲完比跑快），低于滑铲上限 460（04 §4.1，冲刺不替代滑铲） |
| 时长 `duration` | — | 0.333 s（40 条命令） | — | 0.25–0.4 | [推]：D 和 v_peak、v_exit 定了，T 就是 2D / (v_peak + v_exit) |
| 曲线形状 | — | 线性降速 | — | 二次（Vantage 的 (1 − t/T)²） | [设计]：二次曲线开头更陡，同样距离峰值要到约 3900 u/s |

离散化：每条命令用这条命令**中点**的速度 v((t + dt/2)/T)，40 条命令走完（和连续公式的距离差 < 0.1 u）。

### 2.3 竖直、碰撞、结束

1. **冲刺中不掉高度**：竖直速度设 0、这条命令重力 × 0（`gravityScale` 0，10 §10.5"改重力 / 时间缩放"口子；升降梯就是这样做的，06 §6.2【技能】Horizon）。地面上起冲：身体当作离地（贴着地面平飞），不吃地面摩擦（03 §3.4 的 1250 减速会在 0.33 s 里吃掉 400 u/s）。[设计]（初稿"地面加一点抬升"：平飞贴地已经不刮地，不再加抬升）。
2. **撞墙**：世界照常扫掠、去掉朝墙分量（02 §2.5、06 §6.2【碰撞】撞墙是"投影"）。如果撞的面和冲刺方向的夹角 > 60°（法线 · 方向 < −0.5），**剩余的推力取消**，冲刺结束，速度 = 沿墙分量、大小不超过出口速度（"沿墙滑开"）。斜着擦墙（≤ 60°）继续冲。[设计]，阈值对照翻越的面向锥 35°（04 §4.9）取宽一点。
3. **台阶 / 坡**：照世界的规则（02 §2.7、§2.8）。上坡被坡面投影，下坡会离地平飞。
4. **正常结束**：t ≥ T。水平速度 = 方向 · max(`exitSpeed`, s₀)，s₀ = 冲刺开始前的水平速度（P3：冲刺不削已经有的速度；也不把它加上去——不叠加，所以冲刺不能刷速度，06 §6.1 第 2 条"相加必须带上限"）；竖直速度保持 0，下一条命令重力照常。之后完全是普通的地面 / 空中规则（地面上 420 会按 1250 u/s² 降回 299，约 0.1 s，03 §3.4）。
5. **被打断**（发射、别的驱动者、超时）：照 10 §10.2 第 2 条"保留当前速度"，但当前速度先换成出口规则（不留 2000 u/s 给后面）。

### 2.8 速度上限

技能层天花板（06 §6.3）水平 900 u/s 会把 2000 削掉。照"带更快动作的装备单独抬高"的做法（06 §6.3：钩爪 1100、Vantage 945），**冲刺进行中**天花板抬到峰值；冲刺结束后回到原值（出口速度本来就在 900 以下，除非冲刺前已经更快）。

### 2.9 没选的（留档）

| 决定 | 选中 | 没选（数据和理由） |
|---|---|---|
| 时长 | 0.333 s、峰值 2000、线性降速 | (a) 0.22 s 走 394 u：平均 1790，线性降速峰值要约 3160 u/s；(b) 二次曲线（Vantage 式）0.25 s 走 394 u：峰值约 3900 u/s。两者峰值都是 R5 最快动作的 3 倍以上，镜头里几乎是瞬移 |

| 方向 | 方向键相对视角，锁定 | 跟视角（含俯仰）三维冲：参考作品没说；会让"往天上冲"成为一种上楼方法，和"不掉高度"的规则重复；冲刺中跟视角转：难以预测落点 |

| 击倒减冷却 | −5 s / 次，开关可改成直接回满 | 不做：参考作品的核心设计之一 |

## 3. 实现模板

```
// 单位：u、s、°。一个能力，Driving 状态；只在"实验动作 · 冲刺"打开时加进能力列表（第一个）
BeforeMove(ctx):
    rechargeTick()
    if dashing:
        if lastWallContact into dir (n·dir < -0.5): end("WALL", along-wall velocity, |v| ≤ exit); return
        t = now - start; mid = (t + dt/2) / T
        v = exit + (peak - exit) * (1 - mid)
        vel = dir * v; vel.z = 0; grounded = false; mods.gravityScale = 0
        block mantle / wall-run; raise the horizontal ceiling to peak
        return
    if not pressed(dashKey): return
    if driverActive: refuse("BUSY"); return
    if charges < 1: refuse("COOLDOWN"); return
    if now < recoverUntil: refuse("RECOVERY"); return
    dir = wishDir or viewForward; s0 = |vel_h|
    if sliding: end the slide
    charges -= 1 (start the cooldown if it was full); dashing = true; start = now; event DASH_START
    (same command: the first push as above)
AfterMove(ctx):
    if dashing and now + dt >= start + T - 1e-9: end("END")
end(reason):
    vel_h = dir * max(exit, s0)   (WALL: the swept along-wall velocity, |v| ≤ max(exit, s0)); vel.z = 0
    dashing = false; recoverUntil = now + dt + recovery; fireBlockedUntil = recoverUntil
OnKill(): if killResetsCooldown: charges = max else next charge -= killCooldownCut
```
