# 实践检验 A2 报告：用手册做"冲刺"

由 hb-slam 写（2026-11-14）。研究仓库分支 `practice/dash`、HSD-Unity 分支 `practice/dash`，都叠在实践检验 A（`practice/slam`）上，draft PR，没合并。build：`HSD-Build/Practice-Dash`。

## 白话结论

用户试玩下砸接滑铲后说"不够明显"，要一个像参考作品（《三角洲行动》威龙"动力推进"）那样的冲刺。这一次手册**第二次**被拿来创造新动作，比第一次顺：

- **规则几乎全部能从手册推出来**：冲刺属于"驱动者"（06 §6.1），R5 里有一个几乎一样结构的先例（Vantage 的 Echo 位移，05 §5.52），仲裁、跳键屏蔽、天花板、冷却、恢复期都有现成规则。手册还纠正了总控初稿两处：时长和峰值互相矛盾（只是算术，但手册的三列表格逼着把距离、时长、峰值写在一起才看出来）；固定出口 420 会削掉更快的速度（P3）。
- **数据预言都对上了**：一次冲刺 403.33 u（设计 403.3）；冲完 0.108 s 回到冲刺跑速度（03 §3.4 预言约 0.1 s）；跳 + 冲 + 翻越最高 134 u（04 §4.9 预言 54.8 + 80 = 134.8 u）。
- **"明显"手册给不了**：手册明确说 R5 移动里没有 FOV 跳、没有技能音效（07 §3.10、§6），声音和屏幕效果是 99 待研究的 A-2、A-3。所以冲刺"明显"的部分都是**偏离**，用户要求，放开关、写 D 行。
- **手册缺的仍然集中在"怎么接进代码"**：这次又撞上了"每条命令里谁先谁后"（撞墙要晚一条命令才知道），还有输入位、战斗事件、开火接口。

测试：冲刺 24 个用例 + 下砸 31 个，55 / 55；开关关时原有 EditMode 全过、回放和手感对照 741 / 741 逐字节相同（结果见 HSD-Unity PR）。

**看得出来的设计问题**（共享日志 `pending`，等试玩）：

1. **地面冲完速度留不住**（0.1 s 回到 299）：地面冲刺的"冲完更快"几乎感觉不到。要不要冲完一小段时间不吃地面减速（像击退的无减速窗口，05 §5.38）？
2. **起跳后马上冲飞不远**：竖直清零的规则让"跳 + 马上冲"比"跳到最高点再冲"差很多（447 vs 679 u），时机要学。
3. **冲刺中按跳没用**：驱动者屏蔽跳键（06 §6.8）。要不要"冲刺中按跳 = 结束冲刺并起跳"？
