## 白话说明

做关卡要知道"从多高砸下来、冲出去多快、能滑多远"。这些数**不是估的**：是把 HSD 的游戏身体（Reference 配置）打开"实验动作 · 下砸"开关，放进平地和台子上跑出来的（`slam_harness/`，不开 Unity，直接调 `PracticeSession` + `R5MotorV2`；120 Hz 命令，u）。代码版本：HSD-Unity `practice/slam`（draft PR，还没合并）。

所有"开关开"的行都是按下蹲那一刻低头 60°、之后一直按住蹲和 W（落地后就是普通滑铲按住蹲）。每一种情况都另跑了一行"开关关"做对照：同样的路线、同样按住蹲，只是没有下砸（落地照常，按住蹲 ≥ 200 u/s 就落地续滑）。**R5 没有这个动作，所以没有 R5 对照列。**

读法：

1. **冲刺速度以下进来，下砸明显赚**：落地变成 520 u/s 的滑铲，比按住蹲正常落下（299 续滑）多滑 1 倍左右。
2. **已经很快（滑铲跳 407 u/s）进来，下砸不赚甚至亏**：水平先减半，落地再封顶到 520，滑铲距离比原样落下续滑短。高手不会在这时候用它——这是 [DESIGN](DESIGN.md) §2.4"几乎总是 520"的直接后果，写进 [REPORT](REPORT.md) 和试玩清单。
3. **高度只影响"静止起砸"**：有速度时 1 H 和 8 H 冲出去一样快；高处的好处是免掉硬着陆（8 H 不下砸只剩 171 u/s）。
4. **平地跳永远不触发**：原地跳、冲刺跳、滑铲跳在平地最高点按蹲都被拒绝（`SLAM_REFUSED_HEIGHT`），轨迹和开关关时逐位相同（测试 `GroundSlamTests.FlatGroundJumpsNeverSlam`）。从 1 H 台子上原地跳会落回台上，等于平地。

## 怎么算的

| 情况 | 做法（`slam_harness/Program.cs`） |
|---|---|
| `SL-drop.<n>H.still` / `.sprint` | 身体直接放在平地上方 n × 72 u 的空中，水平速度 0 或 299，第一条命令按蹲 + 低头 60°，之后按住蹲和 W |
| `SL-apex.flat.<跳>` | 平地上：原地跳 / 冲刺 3 s 起跳 / 冲刺后按蹲 0.208 s 滑铲跳（LS-06 最远的那一种），到最高点（竖直速度第一次 ≤ 0）按蹲 + 低头 60° |
| `SL-apex.<n>H.<跳>` | 同上，但在 n × 72 u 高的台子上助跑，台边起跳，落到台下的平地 |
| `.off` | 同一行，开关关（没有下砸能力），同样按住蹲 |
| 冲出去的速度 | 落地那条命令之后的水平速度；"转换前"是落地那一刻下砸转换之前的水平速度 |
| 滑多远 / 多久 | 落地到滑铲结束（按住蹲滑到 < 125 u/s） |

重新跑：见 `slam_harness/slam.csproj` 第一段注释，然后 `py -3 -I make_level_scale.py`。
