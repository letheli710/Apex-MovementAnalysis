# 实践检验 A：下砸接滑铲（设计）

由 hb-slam 写（2026-11-14 夜 / 11-15）。分支 `practice/slam`（从 `handbook/base` ee612b8），还没合并。这份设计**只看手册写成**（第 1 步，没有看 Unity 代码）；第 2 步实现时改动的地方都在 §8 单独列出，正文不悄悄改。

## 白话说明

**这是什么动作**：在空中从够高的地方（至少一个身高）低头往下看、按下蹲，角色就猛地往下砸；砸到地上不摔、不减速，而是把下落的冲劲转成向前的速度，直接滑出去。Apex 里没有这个动作，是我们自己的设计。

**为什么做它**：用户 11-15 选它来检验《HSD 动作与技术手册》v1 能不能用来**创造**新动作——只靠手册里的规则推出每一个数和每一条规则，推不出来的地方老实标成 [设计]，最后让用户亲手试玩判断手感。

**一句话的规则**：

1. 空中、离地 ≥ 72 u（1 个身高）、低头 ≥ 30°、冷却好了，**按下**蹲 → 下砸：水平速度留一半，竖直速度直接变成向下 1200 u/s，之后照常受重力。条件不满足就是普通的空中蹲，什么都不抢。
2. 下砸中不能翻越、不能跑墙、不能挂滑索；撞墙照常；被别的发射（跳板、二段跳……）或驱动（钩爪……）打断就取消。
3. 落地：不吃硬着陆降速；水平速度 = max(原速, min(原速 + 0.35 × 下落速度, 520 u/s))，直接进滑铲。之后完全按普通滑铲的规则走（衰减、松蹲、滑铲跳、退还）。
4. 镜头：起砸踢一下（"平常"档 2，约 3°），落地踢一下（"主动超常"档 4.5，约 7°），换掉这次落地原来的落地律；滑铲的眼高、FOV、倾斜照普通滑铲。**不加** FOV 收缩（手册判为偏离，做成默认关的开关给用户试）。
5. 下砸自己有 1.5 s 冷却（从起砸算）；落地进滑铲**算一次"开始滑铲"**，按手册统一规则刷新滑铲的 2 s 加成冷却。

**和总控初稿不一样的四处**（理由在 §2 各条）：落地镜头不用落地律、改用固定基础值（07 §4.5）；FOV 收缩改成默认关的偏离开关（07 §3.10、§4.4、§5.2）；落地封顶加"已更快的不削"（04 §4.1 的封顶写法）；落地进滑铲刷新滑铲冷却、早跳退还（04 §4.4、§4.6 的统一规则）。

## 1. 原理

1. **动量是玩家的资产**（DESIGN-PHILOSOPHY P3，06 §6.1）：下砸是玩家**主动**花掉高度换速度。按 06 §6.1 的五种处理方式归类：起砸 = 竖直**替换**、水平**削减**（有明确条件：玩家自己按的）；落地 = 水平**相加**再封顶（"相加必须带上限"）；之后交给滑铲（滑铲自己的削减规则）。没有一条"偷速度"的规则。
2. **地板低、天花板高**（P4，03 §3.13）：不会用的人完全碰不到它——平地上任何跳（原地 54.8 u、滑铲跳 48.8 u，关卡尺度表 LS-01、LS-06）都到不了 72 u，所以平地跑跳永远触发不了；空中蹲照旧用于蹲着翻越（04 §4.12）。会用的人多一个"从高处下来不丢速度"的路线工具：从台子上下来本来要硬着陆降速（03 §3.9），下砸把它变成一次 520 u/s 的滑铲。
3. **可预测，没有优先级表**（P8，06 §6.6）：下砸不需要新的仲裁规则。它在能力顺序里排在所有"状态拥有者"后面，只在"自由下落"状态里有效；和别的动作撞车时，用手册已有的发射选择、唯一驱动者、禁止口（06 §6.9、10 §10.5）自然决定谁赢。
4. **持续的克制，一次性的响亮**（P2，07 §4.4）：下砸只用两个一次性 kick 表达，不加持续效果（不动 FOV、不加速度线）。
5. **一个数就能记住**：起砸后的竖直速度固定（−1200 u/s），落地速度几乎总是 520 u/s（§2.4 的推导）。玩家不用算"从多高砸出去多快"，和"跳多高只由一个高度决定"（README 示范条目）同一个思路。

### 2.2 起砸

| 量 | [m] | HSD 设计值 [u] | 身高比例 | 合理范围 | 依据 |
|---|---|---|---|---|---|
| 水平速度保留 `slamKeepHorizontal` | — | 0.5 × | — | 0.3–1.0 | [设计]：下砸是"往下"，落点应该在视线附近；落地还会加回来（§2.4） |
| 起砸竖直速度 `slamVz` | −30.48 m/s | −1200 u/s | −16.67 H/s | −900 … −1500 | [设计]：和 R5 最大的竖直速度（跳板 1150 u/s，05 §5.32）同量级、反向；4 H 高也在 0.22 s 内砸到 |

1. **速度处理**（06 §6.1）：v_h ← `slamKeepHorizontal` · v_h（方向不变）；v_z ← `slamVz`（**替换**，不叠加原来的竖直速度，和起跳 03 §3.8 一样）。
2. 起砸走**发射**通道（06 §6.9、10 §10.5：替换速度的动作都是发射）：同一条命令有别的发射（跳板、扑击……），**优先级高的赢**；下砸的优先级 15（比所有现有发射低，[设计]：被动撞上的跳板应该赢过自己按的下砸）。发射过天花板：向下不夹、水平 ≤ 900（06 §6.3 第 3 条），所以 −1200 不会被夹。
3. 起砸**不开** lurch 窗口（06 §6.9 `launchOpensLurchWindow` 的例外，05 §5.14 那几种 Reference 不开的发射同理）：下砸是往下，不是起跳。之前的起跳窗口照常（起跳 0.3 s 后起砸，剩下 0.2 s 的 lurch 仍有效）。[推]
4. 起砸**不结束**驱动者——按 §2.1 根本没有驱动者时才会起砸。
5. 下砸是一个 **Effect** 状态（06 §6.7、10 §10.2：只改移动、不每条命令推身体），`maxEffect` 10 s（保证退出，10 §10.4 第 4 条；从 8192 u 砸下来也只要约 4 s）。

### 2.4 落地

落地的判定照 03 §3.9 第 1 条（下落中、2 u 内有能站的地面）。下砸状态中落地时，在这条（落地）命令上：

1. **不触发硬着陆降速**。理由是推出来的：下砸落地的竖直速度 ≥ 1200 u/s，超过硬着陆"降到 0"的 1092.9 u/s（03 §3.9 Unity 拟合），照原规则 f0 = 0，水平速度会被清光、1 s 内上限被压低——和这个动作的目的正好相反。所以这次落地**换掉**硬着陆规则（06 §6.1 第 3 条：削减要有条件；这里写明"下砸落地不适用"）。[推]
2. **落地速度**（06 §6.1 第 2 条"相加必须带上限"；封顶写法照 04 §4.1 起滑加成"加成后不超过它；已更快的不削"）：

   s = |v_h|，v = 落地那条命令**开始时**的向下速度（和硬着陆同一个定义，03 §3.9 第 5 条）

   s′ = max(s, min(s + `slamLandK` · v, `slamLandCap`))

   方向 = v_h 的方向；|v_h| < 1 u/s 时用视角偏航方向。

3. **直接进滑铲**（04 §4.1 第 3 条的"开始滑铲"那一套，不检查 200 u/s 门槛——s′ 一定 ≥ 0.35 × 1200 = 420）：
   - sliding = true，冲刺标志清掉；
   - slideStartTime = now：**算一次"开始滑铲"**，刷新普通滑铲的 2 s 加成冷却（04 §4.4"每一次开始滑铲都刷新 2 s 冷却"的统一规则）；
   - boosted = true，lastBoost = s′ − s，boostTime = now，下蹲过渡开始 = now + dt：**下砸的加成按滑铲加成对待**，所以落地后 0.2 s 内就跳（滑铲跳），加成要还回去（04 §4.6 第 1 条：刚起滑就跳，加成要还回去，"按蹲—立刻跳"不比直接跳快）。[推]
4. 下砸状态结束（Idle），事件 `SLAM_LAND`（带 s、v、s′）。
5. 镜头：这次落地**不用**落地律，换成下砸落地 kick（§2.6）。

由公式推出来的数（连续公式；120 Hz 半步积分的实际值见 `LEVEL-SCALE.md`）：

| 起砸离地 | 落地向下速度 v [u/s] | 原地起砸（s = 0）落地 s′ [u/s] | 带速度起砸（s ≥ 100）落地 s′ [u/s] |
|---|---|---|---|
| 1 H（72 u） | 1244.2 | 435.5 | 520 |
| 2 H（144 u） | 1286.9 | 450.4 | 520 |
| 4 H（288 u） | 1368.2 | 478.9 | 520 |

v = √(1200² + 2 · 750 · h)。**结论**：只要起砸时水平速度 ≥ 100 u/s（即起砸前 ≥ 200 u/s，走路以上），落地总是 520 u/s；高度只影响原地起砸。这是"一个数就能记住"（§1 第 5 条），也意味着"砸得越高冲得越快"**不成立**——写进待试玩（PLAYTEST）和 `pending`。

### 2.5 落地之后（全部是普通滑铲的规则，不新加）

- 衰减和转向：04 §4.2（按住蹲 D = 100，s′ = max(0, (s − D·dt)·0.7^dt)）。从 520 按住蹲滑到 125 约 1.91 s、约 573 u（连续公式；实际值见 `LEVEL-SCALE.md`）。
- 松开蹲：04 §4.3（> 350 继续滑、D = 400；≤ 350 当场结束）。下砸中松开了蹲，落地以后就是这一条。
- 滑铲跳：04 §4.6（0.2 s 内跳退还 lastBoost；之后 > 350 保持；不做超速削减）。
- 走下台边、上滑索、翻越、跳板：04 §4.3 第 3 条的"其他结束"。**下砸接翻越 / 接滑索**就是这一条：落地滑出去以后，翻越、滑索全部照常（下砸状态已经结束）。
- 斜坡：04 §4.5 照常（落在下坡上会越滑越快）。
- 技能层天花板 900（06 §6.3）照常。

## 3. 实现模板

```
// 单位：u、s、°。一个能力（ISkillAbility），Effect 状态；只在开关打开时加进能力列表
state: idle | slamming
lastSlamStart = -inf

BeforeMove(ctx):
    if state == slamming:
        if ctx.otherLaunchThisCommand: cancel("LAUNCH"); return
        if ctx.driverActive:           cancel("DRIVER"); return
        if vel.z > 0:                  cancel("RISE");   return
        ctx.blockMantle(); ctx.blockWallRun(); ctx.blockUse()
        return
    if not ctx.duckPressedEdge or ctx.grounded: return
    if ctx.driverActive or ctx.wallRunning or ctx.duckUsedByEarlierAbility: refuse("BUSY"); return
    if aim.pitch < slamPitchMin:                refuse("PITCH"); return
    if traceDown(origin, 8192) < slamMinHeight:  refuse("HEIGHT"); return
    if now - lastSlamStart < slamCooldown:       refuse("COOLDOWN"); return
    v = (vel.x * keepH, vel.y * keepH, slamVz)
    ctx.launch(v, priority = 15, opensLurch = false)    // 发射选择 + 天花板（向下不夹）

AfterMove(ctx):
    if launched by me this command: state = slamming; lastSlamStart = now; event SLAM_START
    if state == slamming and motor.landedThisCommand:
        s  = |vel_h|; v = max(0, -vzAtCommandStart)
        s2 = max(s, min(s + slamLandK * v, slamLandCap))
        dir = s > 1 ? vel_h / s : yawForward(aim)
        motor.startSlide(speed = s2, dir, boosted = refund, lastBoost = s2 - s,
                         refreshSlideCooldown = true)
        landingSlowdown.skipThisLanding()
        camera.replaceLandKick = true                    // 只读字段
        state = idle; event SLAM_LAND(s, v, s2)

camera Observe (只读):
    if slam.startedThisCommand: kick((2 + r1)*20, r2*20, 0.5*r3*20)     // 盐 vSS
    if slam.landedThisCommand:  kick((4.5 + r1)*20, r2*20, 2*r3*20)     // 盐 vSL，且不加 land
```

离散化要注意：

- 落地那条命令仍是空中命令（03 §3.9 第 1 条），所以"落地速度"要在这条命令的**末尾**写进去（`AfterMove`），下一条命令起按滑铲走。滑铲的减速从下一条开始。
- v 用落地那条命令**开始时**的竖直速度（和硬着陆、落地 kick 同一个定义，03 §3.9、07 §2.3）。
- 起砸那条命令本身也做空中移动，所以起砸后第一条记录到的竖直速度是 −1200 − ½·g·dt（发射写在移动前；照起跳的半步重力顺序）。

Unity 参考实现：第 2 步写，见 §8。
