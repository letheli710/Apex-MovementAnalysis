# 关卡尺度表

由 hb-tables 写（2026-11-14）。**原件是 [`level-scale.tsv`](level-scale.tsv)**（38 行）；这一页照着它写。

## 白话说明

做关卡要知道"角色能跳多远、能翻上多高的墙、多陡的坡滑不停"。这一页的数**不是估的**：都是把 HSD 现在的游戏身体（Reference 配置，就是按 R5 复刻的那套移动代码）放进专门搭的测试几何里跑出来的，每个数都能用同一个程序重新跑出来。

- 跑法：`level_scale_harness/`（C# 程序，不开 Unity，直接调 `PracticeSession` + `R5MotorV2`；120 Hz 命令，u 模式）。输出原样存在 `level_scale_harness/output.tsv`，滑铲跳时机扫描在 `slidejump_sweep.tsv`。
- 代码版本：HSD-Unity `units/switch` 5c79a50（PR #88，还没合并；移动代码和 main 一样，单位开关在 u 模式下输出逐字节不变）。
- 测试几何：无限大的平地 + 方块墙 / 台阶 / 斜坡。墙用 1 u 网格扫高度，台阶 0.25 u，坡 0.25°。
- 设计关卡时留余量：表里是"刚好能做到"的极限，正常玩家做不到每次都卡在极限。

**最常用的几个数**：原地跳 54.8 u（1.39 m，0.76 H）；冲刺跳远 227 u（5.76 m）；滑铲跳最远 292 u（7.41 m）；贴墙原地跳能上 222 u（5.64 m）的墙（会先爬墙），不爬墙只能上 84 u（2.13 m）；蹲着最多 155 u；台阶 18 u；坡 45.5°；平地滑铲 461 u（11.7 m，1.69 s）；10° 下坡还能停，15° 起就滑不停。

## 怎么算的

| 项 | 做法（`level_scale_harness/Program.cs` 里的函数） |
|---|---|
| 跳高、跳远 | `Jumps`：先跑 3 s 到稳定速度（走 / 冲刺 / 一直蹲），起跳那条命令按跳，空中按住前；起跳前一条命令的位置到第一次着地的位置。滑铲跳：冲刺 3 s → 按蹲 k 条命令 → 按跳，k 从 1 扫到 150 |
| 最高的墙 | `Mantles`：墙面在 x = 100，墙顶高 h（10–400 u，1 u 网格）。"贴墙"= 离墙 0.5 u 站着按跳 + 前；"冲刺"= 从 700 u 外冲刺，30 个起跳时刻取最好；"蹲"= 一直按蹲或起跳后按蹲。成功 = 最后站在墙顶上（z = h，在墙里面，着地） |
| 台阶 | `Steps`：走路（不冲刺）撞台阶，不跳、没有翻越事件、最后站在台阶上 |
| 斜坡 | `Slopes`：400 u 长的坡，冲刺 5 s，能到坡顶算能上 |
| 滑铲 | `Slides`：冲刺到位置后按住蹲 + 前，`slideStarted` 到 `slideEnded` 之间的路径长度（沿坡面）。下坡：坡顶平台上冲刺、到坡边按蹲；上坡：平地冲刺到坡脚按蹲。坡长 6000 u，到坡底还没停写"不停" |
| 跑墙 | `WallRuns`：Fun 配置，跑墙规则分三种（M7 设计 / TF2 规则 + R5 残留值 / TF2 规则 + TF2 值）；朝墙 10–40° 冲刺，离墙 20–80 u 时起跳，24 种取最长；`WALLRUN_START` 到结束 |
| 二段跳 | `DoubleJumps`：Fun 配置，原地跳后第 6–90 条命令再按跳，取最高 |
| 跳板 | `Pads`：地图跳板（`JumpPadParams.R5Reference`），站着 / 冲刺进 |

重新跑：见 `level_scale_harness/lvl.csproj` 第一段注释。结果和这张表对不上，先看 HSD-Unity 的移动参数有没有改（`check_params.py`）。

## 没算出来的

- **地图滑索的典型长度**：没有 R5 地图的滑索长度数据，只能给参数（滑索速度 600 u/s；滑索枪绳长 700–8000 u，速度 1000 u/s）。
- **钩爪一次拉多远**：只给了最远距离 850 u（参数），拉多远看钩点和地形，没有"典型"值；钩爪拉的轨迹规则见第 05 章。
- **TF2 本体的跑墙长度和二段跳高度**：TF2 研究没有量这两个距离。表里的数是 Unity 里"TF2 规则"跑出来的（用 R5 的重力 750）；TF2 本体按规则 [算] 二段跳约 150 u，没实测。
- **多陡的下坡滑不停**：只知道在 10°（能停）和 15°（不停）之间，没细扫。
- **R5 的同项对照**：跳远、最高墙、滑铲在坡上的距离 R5 都没有按这种方式量过，"R5 对照"一列只写了能对上的规则或数；要对照得在 R5 里搭同样的几何（写进 `_notes/hb-tables.md` 的建议）。
- **蹲着冲刺接近的最高墙**、**站着时爬墙的最长时间**：没单独列（蹲的三种做法都在 155–156 u）。
