# 重建检验题目：标准答案用的精确定义（hb-judge，2026-11-14）

总控给重建方的题目文字（原样）：

> 120 Hz 命令，平地，参考身体（站立、拿默认武器或空手，msc = 1），从静止开始。S1 按住前进 + 冲刺 2.0 s，然后按住蹲直到滑铲结束，继续 1.0 s。S2 同 S1，滑铲开始后 0.5 s 松开蹲。S3 同 S1，按蹲后 0.208 s 按跳（一条命令）。S4 20° 下坡（沿坡向下冲刺），同 S1。S5 S1 滑铲结束后马上（结束后第 1 条命令）再按冲刺 + 蹲，测冷却。L1 从 50 / 100 / 200 / 400 u 高处静止落下（不按键），落地后记 1.5 s，文件 `L1_50.csv` 等。L2 平地原地跳一次（一条命令按跳），落地后记 1.5 s。

文字里有几处可以有不同读法。标准答案按下面这一种做；评分时如果重建方的读法不同，先按读法归类，不算手册的错（REPORT 里单列）。

## 共同

- 每条命令 dt = 1/120 s。tick 从 0 开始，每行是**这条命令执行完**的状态；`t_s` = tick / 120（这条命令开始的时刻）。
- 身体：`MovementConfigs.Reference()`，msc 强制为 1（冲刺上限 260、起滑加成 min(s + 150, 400)）。u 模式。
- 世界：地面 z = 0 的平地（S4 见下）。起点 x = 0、y = 0，视角 yaw 0（沿 +x），俯仰 0。
- `state`：不着地 `air`；着地且在滑铲 `slide`；着地、不在滑铲、这条命令按着蹲 `crouch`；其他 `ground`。（不计分）
- `events`：这条命令里发生的：`slide_start`（按蹲起滑或落地续滑）、`slide_end`（任何原因结束，包括起跳）、`jump`（原生起跳）、`land`。
- `cam_pitch_punch_deg`：原生镜头两个 punch 弹簧俯仰之和（°，+ = 向下），不含晃动、漂移、翻越曲线。
- **落地 kick / 起跳 punch 的随机数用的命令号 = tick**（R5 是 usercmd 号；07 章的随机数公式按这个号算）。
- `eye_height_u`：原生眼高（原点上方，u）。（不计分）

## 滑铲题（S1 – S5）

- tick 0 – 239：按住 W + 冲刺，不按蹲。tick 240 起按住蹲（**这一条是按下沿**），W + 冲刺一直按着。
- S1：一直按住蹲。滑铲结束那条命令（`slide_end`）之后再记 120 条命令（1.0 s）。
- S2：tick 300 起松开蹲（滑铲开始后 60 条命令 = 0.5 s）。结束后再记 120 条。
- S3：tick 265 按一次跳（240 + 25，0.208 s × 120 = 24.96 取 25），蹲一直按着。空中不松蹲，落地续滑；续滑**自然结束**（不是起跳造成的那次结束）之后再记 120 条。
  - **注意**：这一题正好落在退还的边界上：下蹲过渡从 tick 241 算，到 tick 265 正好 24 × dt = 0.200 s，规则是"< 0.2 s 才退还"，所以**不退还**（出口 351.31）。如果按"≤"或从按蹲那条命令算，就会退还（出口约 190）。
- S4：一块 20° 的坡（一个静态实体，没有道具接缝），从 x = 0 沿 +x 往下，起点在坡上（原点 z = 2，第一条命令就贴到坡上）。输入同 S1。**20° 上滑铲不会结束**（平衡速度约 395 u/s），所以只记到按蹲后 480 条命令（tick 720，共 721 行）。坡上冲刺仍是 260。
- S5：前半同 S1。第一次 `slide_end` 的下一条命令松开蹲（W + 冲刺一直按着，重新加速）；之后第一条 **pre 水平速度 ≥ 200**（= 上一行的 `speed_h_u_s` ≥ 200）的命令再按下蹲并一直按住；这次滑铲结束后再记 120 条。
  - 为什么不是"结束后第 1 条命令就按"：滑铲结束时速度只有约 124、蹲着，再按蹲也不够 200，根本起不了滑，测不到冷却。按现在的读法，第二次起滑在 tick 459，离第一次起滑 219 条命令 = 1.825 s < 2 s，**没有加成**。

## 落地题（L1、L2）

- L1：tick 0 时原点在地面上方 h（50 / 100 / 200 / 400 u），速度 0，不按任何键。落地那条命令（`land`）之后再记 180 条（1.5 s）。
- L2：站在地上，tick 30 按一次跳（前 30 条什么都不按），落地后再记 180 条。L2 的起跳 punch（峰值 2.83° @ tick 48）在落地之前；评分只看落地之后的峰值。
- 落地那条命令的 z 不压到地面（还在离地 ≤ 2 u 的地方，例如 L1_50 是 1.849），下一条着地命令才贴地（03 章"落地"）。
