# 05 后坐和抖动

[回到目录](README.md)

## 结论

后坐有具体数值，而且大部分是现成字段，验证过。

1. **画面跟着 punch 走**，子弹也跟着，第一发没有偏移。
2. **一发的后坐**来自图案表的一行，乘系数，一部分直接加到角度（hard），一部分加到角速度（soft）。
3. **回落是弹簧**，腰射和开镜差很多。R-301 腰射约 2.5 s 回到原位，开镜约 1 s。
4. **图案不是到时间清零**，是一个数在倒数，停得短会从中间接着打。
5. **水平负数向右**。
6. **抖动**分三种：枪模每发后退和横滚、punch 横滚、开镜漂移。都有数。受击抖动**没测到**。

## 1. 一发的后坐怎么算

**[反编译，每发 Δv / Δx 实测完全吻合]**

```
kick = 表的这一行 × viewkick_pitch_base + 随机
随机 = |r|（在 innerexclude 和 1 之间）× 第 4 列 × viewkick_pitch_random × 0.5，符号随机
angle    += hardScale × kick × 缩放
velocity += softScale × kick × 缩放 × 20
```

没有图案的枪（Wingman、P2020）`kick = base ± random`。

验证 **[实测]**，Δ速度 / Δ角度：

| 枪 | 俯仰实测 | 公式 | 偏航实测 | 公式 |
|---|---|---|---|---|
| R-301 | 132.86 | 132.86 | 41.43 | 41.43 |
| Spitfire | 193.33 | 193.33 | 153.33 | 153.33 |
| Wingman | 37.14 | 37.14 | 40.00 | 40.00 |
| P2020 | 20.00 | 20.00 | 30.00 | 30.00 |

**缩放 [反编译，部分实测]：** 按累计值在 `scale_min`、`scale_max` 之间插值 × 不在地面时的 `air_scale_ads`（按开镜比例）× `duck_scale` × `move_scale`。第一发用 `scale_firstshot`。实测到的只有空中开镜 ×2，见 [08](08-states-gaps.md)。

## 2. 画面和子弹分别看到多少

```
准星 = 瞄准 + (1 − weaponFraction) × punch
子弹 = 瞄准 + 这一发 kick 之前的完整 punch
fraction 按开镜比例在腰射值和开镜值之间线性
```

| 枪 | 模式 | `weaponFraction` | punch → 画面的斜率 **[实测]** | 期望 |
|---|---|---|---|---|
| R-301 | 腰射 | 0.05 | 0.950 | 0.95 |
| Spitfire | 腰射 | 0.2 | 0.800 | 0.80 |
| Wingman | 腰射 | 0.4 | 0.600 | 0.60 |
| P2020 | 腰射 | 0 | 1.000 | 1.00 |

| P2020 | 开镜 | 0.2 | 0.774（扣掉漂移后） | 0.80 |

所以 R-301 开镜时准星和子弹完全一体；Wingman 开镜子弹比准星高 30 % 的 punch。腰射子弹用完整 punch 是 **[推断]**，腰射散布太大，样本分不出来。

## 5. 弹簧和回落

```
x'' = −k·x − d·v，三轴独立，按帧时间精确解
热度：每发 +heatpershot，上限 1；最后一发后保持 holdtime，再 fadetime 内降到 0
k, d = 冷、热弹簧按热度插值，再按开镜比例在腰射、开镜之间插值
|x|² + |v|² < 0.001 时直接归零
```

## 9. 开镜漂移（view drift）

开镜时不开枪画面也会慢慢漂 **[实测]**：R-301 俯仰 ±0.29°，偏航 ±0.21°。腰射没有。

**字段 [字段]，R-301：** 开镜 1.2 s 后开始（`viewdrift_ads_delay`），站 0.5 / 0.4，蹲 0.3 / 0.25，空中 0.6 / 0.8（俯仰 / 偏航），速度 0.5。腰射全是 0。枪托按比例减小。

姿态对漂移的影响没单独测，只有这些字段。
