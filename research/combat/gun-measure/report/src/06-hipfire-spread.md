# 06 腰射散布

[回到目录](README.md)

## 结论

**散布角 = 基础值 + 累计 kick。** 这个角是引擎读回的 `GetAttackSpreadAngle`，单位是度。两部分都和字段对上了 **[实测]**。

| 部分 | 怎么变 | R-301 |
|---|---|---|
| 基础值 | 看姿态：站、走、冲刺、蹲、空中。不是马上到，按固定速度过渡 | 站 3、走 6.6、冲刺 8.4、蹲 2.4、空中 8.4，上升 3 °/s，下降 30 °/s |
| 累计 kick | 每发加一点，到上限为止，停火等一会儿后回落 | 每发 +0.2，站上限 2，等 0.25 s，回落 100 °/s |

所以 R-301 站着连射：3.0° 起步，10 发后到 5.0°，停火 0.25 s 后约 0.02 s 回到 3.0°。

**一发子弹的方向 = 瞄准 + 后坐 punch + 这个圆锥里的一个随机偏移。**

**没测到的关键一点：圆锥内部的分布。** 这次所有批次都没有腰射命中点，是均匀、偏中心还是别的，**不知道**。字段和角度能确定圆锥多大，不能确定落点怎么散。第 8 节写了怎么补。

## 1. 形成过程

**[字段的含义由实测确认]**

```
每一帧：
  目标基础值 = 当前姿态的 spread_*_hip
  基础值 按 spread_moving_increase_rate 升向目标，或按 spread_moving_decay_rate 降向目标
  若距上一发 > spread_decay_delay：kick 按 spread_decay_rate 回落

开火：
  子弹方向在 基础值 + kick 的圆锥内
  kick += spread_kick_on_fire_*，不超过 spread_max_kick_*
```

霰弹例外，见第 5 节。

## 2. 实测和字段对得上吗

**基础值的过渡**，不开火时起跑和停下 **[实测，1 次]**：

{{spread_move}}

走和跳的上升和字段相符，下降接近字段（R-301 26–30 对 30，Wingman 跳 11.8 对 12）。**没解释的：** Wingman 冲刺这行上升只有 1.15 °/s，字段 5.5，没查。Wingman 走、冲刺的下降窗口太短，不算数。

**开火时** **[实测，每行 1 次]**：

{{spread_fire}}

- R-301 站：第一发前 3.0，每发 +0.2，封顶 5.0，等于 3 + 2。走 8.6 = 6.6 + 2，蹲 3.9 = 2.4 + 1.5。
- R-301 走这一行第一发前只有 5.77，因为才走了 0.9 s，基础值按 3 °/s 还没升到 6.6。**所以刚起步就开枪比走了一阵再开枪准。**
- 回落速度：Spitfire 1.75° 用 0.14 s，约 12.5 °/s（字段 12）；Wingman 约 11 °/s（字段 11）；R-301 2° 在约 0.02 s 内，和字段 100 °/s 相符 **[实测]**。
- Wingman 站：2.4 + 2.5 = 4.9，一发就加满一大截。P2020 站每发 0，字段就是 0。
- Flatline 站第一发前低于字段 4.5，因为这把枪刚拿到手，读数还在爬（第 4 节）。

**开镜时**：站和蹲基本是 0；空中不是 0，会往 `spread_air_ads` 爬，但窗口短读到的只有 2–3°。

## 3. 每把枪的腰射字段

**[字段]**，S21 文件的顶层值。空的是文件没写。SDK 重写过的枪（30-30、Nemesis 等）本地可能不同。

{{spread_hip}}

**几条规律：**

- **同一族字段相同**：R-99、C.A.R.、Alternator 一组；Kraber、Longbow、Sentinel 一组（站 8°）。
- **Flatline 明显比 R-301 散**：站 4.5 对 3，走 9.9 对 6.6。
- **P2020 走路 10°、空中 16°**，比站 4.4 差很多；Wingman 反过来，走 3、空中 6。
- **回落速度差很大**：R-301、Flatline 100 °/s，停火马上恢复；R-99 12 °/s；Kraber 4 °/s。这个差别比基础值更影响"点射准不准"。
- **基础过渡字段不是每把枪都有**，Spitfire 等没写，这些枪的过渡速度**没测**。Wingman 实测上升 5.47 °/s。

## 4. 刚拿到枪时

**第一次拿到的枪**，散布读数从接近 0 开始，按基础上升速度爬到站立值 **[实测]**。R-301 从 0.2° 约 1 s 到 3°。切回**用过的枪**直接是站立值（Wingman 2.4、R-301 3.0）。

这是客户端读数。这段时间开枪是否真的更准 **[没测]**。

## 6. 开镜字段

{{spread_ads}}

SMG 开镜有 0.35°，步枪和狙击 0。Sheila 每发 −0.18，越打越准（`spread_kick_on_fire` 负值，字段；Sheila 本地开火关客户端，**没跑**）。L4 激光也是负 kick，见 [04 §4](04-attachments.md)。

## 7. 什么能改腰射散布

| 来源 | 效果 |
|---|---|
| 激光 L1 / L2 / L3 | 基础和每发 kick ×0.8 / 0.7 / 0.6，回落 ×1.2 / 1.3 / 1.4 **[字段]**；R-99 上限 4.0 → 3.2 → 2.4 **[实测]** |
| 激光 L4 | 基础 ×0.6，每发 kick 变负 **[字段]** |
| `corrupted_barrel` | 站 ×1.4（变差）**[字段]** |
| Anvil（`altfire_highcal`） | 基础变大，站 ×1.44 到 ×2.17 **[字段]** |
| `elevator_shooter` | 空中 ×0.7 到 ×0.9 **[字段]** |
| 姿态 | 见 [08](08-states-gaps.md) 的实测表 |

## 8. 怎么补上分布这一块

**不需要鼠标**：用现有的脚本枪，站在 300 u 外对一面大墙或一排假人腰射，读 `dmg` 事件的命中点，每把枪 100 发以上，减去当时的 punch，就能看出分布。R-301 3° 在 300 u 约 16 u，假人身体宽度不够，要用墙或更近的距离。这次没做，需要启动一次 R5。
