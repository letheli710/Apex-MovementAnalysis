## 结论

| 东西 | 随开镜比例 `zf` 怎么变 | 来源 |
|---|---|---|
| `zf` 本身 | **匀速**：开镜 1 / `zoom_time_in`，关镜 1 / `zoom_time_out`，反向时接着走 | [实测] |
| 镜头视野 | **smoothstep** `3t² − 2t³`，两头慢中间快，残差 0.001° | [实测] |
| 枪的程序偏移 | 余弦，`zf` 0 到 0.5 走完 | [实测] |
| 枪的动画 | **每把枪自己的动画**，先甩后稳，开镜和关镜是两段 | [实测，只有两个挂点] |
| 鼠标灵敏度 | 跟当前视野走，到位约 ×0.712（R-301） | [反编译]，要真鼠标 |

**所以用户说的"开镜应该有加速度"是对的**，只是加速不在 `zf` 上。

## 1. 每把枪的开镜字段

**[字段]**。实际 FOV = `zoom_fov` × 1.27217（本地 `cl_fovScale`，由实测反推）**[算]**；基础 FOV 是 89。R-301、Spitfire、Wingman 的 `zoom_time_*` 和实际 FOV 都验证过。

{{ads_all}}

"开镜移速倍率"也验证过：R-301 ×0.5（86.75 u/s），Spitfire ×0.4（69.4），Wingman ×1.0（173.5）**[实测]**。

## 2. 视野的速度和加速度

公式 **[反编译，实测残差 0.001°]**：

```
t = clamp01((zf − 窗口起) / (窗口止 − 窗口起))
FOV = 基础 + (开镜 − 基础) × (3 − 2t) × t × t
```

所以视野的速度在 `t` = 0.5 时最快，是平均的 1.5 倍；加速度在两端最大。**[算]**

{{fov_speed}}

中途反向 **[实测]**：`zf` 从当前值接着走，没有跳变，视野也连续。

**R-301 开镜，每 0.05 `zf`（约 13.5 ms）[实测]。** 这是视线中心挂点的位置。"横向归一"是 0 到 1 的主曲线，超过 1 就是冲过头。

| 0.10 | 0.13 | 0.10 | −0.21 | −0.59 | 0.33 |
| 0.15 | 0.37 | 0.23 | −0.57 | −1.61 | 1.02 |
| 0.20 | 0.70 | 0.30 | −1.14 | −2.97 | 2.23 |
| 0.25 | 0.98 | 0.30 | −1.37 | −3.52 | 2.96 |
| 0.30 | 1.14 | 0.39 | −1.07 | −3.12 | 2.88 |
| 0.35 | 1.15 | 0.57 | −0.42 | −2.01 | 2.24 |

## 4. 瞄具

**[实测]**。窗口是拟合的（基础 89）。瞄具不只改倍率，还**改视野走的窗口和开镜时间**。

| 枪 + 瞄具 | `zoom_fov` | 实际 FOV | 窗口 | 开镜 / 关镜（s） |
|---|---|---|---|---|
| R-301 无 | 55 | 69.97 | 0–1 | 0.27 / 0.23 |
| `optic_cq_hcog_classic`（1×） | 60 | 76.33 | 0–1 | 0.29 / 0.25 |
| `optic_cq_hcog_bruiser`（2×） | 38.59 | 49.09 | 0.1–0.8 | 0.29 / 0.25 |
| `optic_cq_holosight` | 60 | 76.33 | 0–0.66 | 0.29 / 0.25 |
| `optic_cq_holosight_variable` | 60 | 76.33 | 0.1–0.76 | 0.29 / 0.25 |
| `optic_ranged_hcog`（3×） | 26.28 | 33.43 | 0.1–0.65 | 0.34 / 0.29 |
| `optic_ranged_aog_variable` | 38.59 | 49.09 | 0.1–0.66 | 0.36 / 0.30 |
| R-99 `optic_cq_threat` | | 76.33 | 0.1–0.8 | 0.24 / 0.22 |
| Longbow 无 | | 69.97 | 0–1 | 0.31 / 0.28 |
| Longbow `optic_sniper`（6×） | | 16.94 | 0.58–0.86 | 0.48 / 0.42 |
| Longbow `optic_sniper_variable` | | 25.26 | 0.58–0.86 | 0.51 / 0.45 |
| Longbow `optic_sniper_threat` | | 25.26 | 0.58–0.76 | 0.53 / 0.47 |
| Kraber 无（自带镜） | 13.31 | 16.94 | 0.58–0.86 | 0.58 / 0.55 |

窗口的意思：Longbow 6× 的视野要等 `zf` 到 0.58 才开始放大，0.86 就放大完。开镜 0.48 s，所以视野实际只用 0.134 s 走完，比 R-301 无镜的 0.27 s 快一倍，平均速度约 540 °/s **[算]**。这就是高倍镜"突然拉近"的原因。

**切镜 [没测]：** 可变倍率瞄具的第二档要按键切换，脚本命令没找到，读到的都是默认档。

**瞄具的灵敏度 [没测]：** 瞄具有 `zoomed_convar_sensitivity_index` 这类字段，效果要真实鼠标。

**枪托对开镜的影响**：见 [04 §3](04-attachments.md)。
