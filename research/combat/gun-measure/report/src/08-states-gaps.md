# 08 状态和没测到的

[回到目录](README.md)

**覆盖：** 开火 R-301、Flatline、Spitfire、Wingman、P2020、Mastiff，12 个状态 × 腰射 / 开镜，每格 **1 次**。需要场景或技能的状态只有 R-301、Wingman。其他枪**推断**同规则。

## 1. 状态对枪的影响

| # | 结果 |
|---|---|
| 1 | **移动和姿态主要改散布**，这是状态最大的影响 |
| 2 | **开镜不在地面，后坐 ×`viewkick_air_scale_ads`**（字段 2 的枪实测 1.6–2.1），腰射不变 |
| 3 | 走、蹲、滑铲不改后坐，差别在噪声内 |
| 4 | 冲刺开枪有延迟，滑铲几乎没有 |
| 5 | 滑索算空中；散布不降到开镜值 |
| 6 | 翻越打断开枪：R-301 只打 4 发，Wingman 1 发，之后枪收起 |
| 7 | 低血量没有影响 |

| 状态 | 能开镜 | 能开枪 | 第一发延迟（R-301 / Wingman，s） |

## 6. 没测到的（全部）

### 要真实鼠标和窗口焦点（约 15 分钟）

| 项 | 为什么重要 |
|---|---|
| 鼠标下压是否抵消后坐 | 手感影响大。反编译看起来抵消，没跑 |
| 开镜过程和关镜那一刻的灵敏度 | 只有反编译 |
| Hop-up 切换键、可变倍率切档 | 脚本命令没找到 |

### 不要鼠标，还能补

| 项 | 怎么补 |
|---|---|
| **腰射落点分布** | 对墙腰射读命中点，见 [06 §8](06-hipfire-spread.md) |
| 切枪后更多方向的开火时刻 | 现在只有 6 个方向，各 1 次 |
| 第一次掏枪后的开火 | 分析现有 `ws_*_swapfire` |
| 更多枪的开镜枪路径 | 现在只有 3 把 |
| 其他枪的表尾 | 用扩容弹匣打完 |
| 蓄力曲线 | Havoc、Charge Rifle、L-STAR |
| 姿态对开镜漂移的影响 | 开镜保持 2 s |
| 枪口焰时长 | 要探针 |
| 空中、滑铲时的换弹动作 | 现在只有站、走、冲刺 |

### 本地测不了

| 项 | 原因 |
|---|---|
| Sheila | 开火关客户端 |
| 真实中弹抖动 | 场景没有会开枪的敌人 |
| 二段跳、墙跑、挂边 | 这个角色和版本没有 |
| 金色配件 | 没有字段变化 |
| 手雷切换 | 本地没有这个武器 |
| 刀、传家宝 | 本地是空手 |
| S21 服务端的子弹行为 | 服务端是 S3 |
| 真实跳板 | 这次用脚本给速度代替 |
| 钩爪中开枪 | 这次钩子没拉动 |
| 枪模骨骼 | 只能读挂点 |
