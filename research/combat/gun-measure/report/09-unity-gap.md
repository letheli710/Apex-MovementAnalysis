# 09 Unity 和 R5 对齐到哪里了

[回到目录](README.md)

2026-11-03 盘点。最新构建是 `HSD-Build/WP4-Feel`（分支 `combat/wp4-reload-swap`，HSD-Unity #65，没合并）。换弹时间量的是 `WP4-Reload`，`WP4-Feel` 复测 R-301、R-99 相同。

**11-03 用户试玩后的改动**：枪用单独相机，垂直 65.5°，不随镜头 FOV 变，长度和粗细分开；换弹动作按 [RELOAD-MOTION](../reload-motion/RELOAD-MOTION.md) 逐帧；曳光从枪口出发，判定仍从眼睛。依据 [SCREEN-TRACER](../reload-motion/SCREEN-TRACER.md)。

## 1. 换弹时间：已对齐

Unity 构建里用真实时钟量的，和 R5 的差不超过 0.02 s。Unity 的逐帧时间约 144 fps，游戏没有变慢。**[实测，每行 1 次]**

| 枪 | 类型 | R5 加弹 / 解锁 / 结束（s） | Unity 真实时钟（s） |
|---|---|---|---|
| R-301 | 战术 | 1.387 / 1.614 / 2.399 | 1.385 / 1.607 / 2.391 |
| R-301 | 空仓 | 1.976 / 2.430 / 3.223 | 1.965 / 2.417 / 3.208 |
| R-99 | 战术 | 1.427 / 1.585 / 1.795 | 1.431 / 1.590 / 1.799 |
| R-99 | 空仓 | 1.953 / 2.190 / 2.446 | 1.958 / 2.201 / 2.451 |
| Wingman | 战术 | 1.483 / 1.915 / 2.100 | 1.479 / 1.917 / 2.104 |
| Wingman | 空仓 | 1.506 / 1.943 / 2.123 | 1.486 / 1.923 / 2.104 |
| P2020 | 战术 | 0.786 / 1.100 / 1.247 | 0.792 / 1.111 / 1.250 |
| P2020 | 空仓 | 0.940 / 1.067 / 1.246 | 0.951 / 1.076 / 1.250 |
| Spitfire | 战术 | 2.027 / 2.797 / 3.396 | 2.035 / 2.812 / 3.403 |
| Spitfire | 空仓 | 3.282 / 3.817 / 4.199 | 3.292 / 3.826 / 4.208 |

**但有两处会让换弹看起来比实际慢：**

1. **HUD 的 "reloading" 一直显示到动画结束。** R-301 战术 1.61 s 就能开枪，字还要再显示 0.79 s。
2. **`WP4-Reload` 以前的构建都是旧做法。** `WP4-Ads` 及更早的构建里，R-301 战术整整 2.4 s 不能开枪和开镜。

帧率低于约 10 fps 时游戏才会真的变慢（每帧最多补 12 条命令，每秒 120 条），这种情况下画面已经卡得很明显。

## 2. 持枪和跑动：没有对齐

**下面第 2 节是做之前的盘点。11-03 已按全枪数据做进 `WP4-Hold`，见第 3 节。**

**11-03 更正：** 全部枪已补测，结果以 [HOLD-POSE.md](../hold-pose/HOLD-POSE.md) 为准（31 把枪，558 次）。下表是第一版，只留作对照。冲刺的左右摆周期是 0.549 s，下面写的 0.279 s 只是步枪式的上下摆；枪身还会大幅转动，这张表没有。

下表从不开火的逐帧记录算出，只有 R-301 和 Wingman。**[实测，每格 1 次]** 姿态是枪口相对站立时的平均偏移，摆幅是这段时间的半幅，单位 u。

| 枪 | 状态 | 姿态 前 | 姿态 右 | 姿态 上 | 摆幅 前 | 摆幅 右 | 摆幅 上 | 上下周期（s） | 窗口（s） |
|---|---|---|---|---|---|---|---|---|---|
| R-301 | 走 | -0.12 | 0.10 | -0.59 | 0.04 | 0.69 | 0.36 | 0.402 | 1.33 |
| R-301 | 冲刺 | -2.16 | -9.94 | -4.63 | 2.02 | 6.45 | 2.66 | 0.279 | 1.10 |
| R-301 | 蹲 | 0.73 | -1.22 | -0.48 | 0.52 | 0.90 | 1.01 |  | 2.47 |
| R-301 | 蹲走 | 0.87 | -1.50 | -0.41 | 0.06 | 0.42 | 0.77 |  | 1.09 |
| R-301 | 滑铲 | 1.87 | -2.21 | -3.38 | 1.65 | 1.18 | 3.30 |  | 0.27 |
| Wingman | 走 | -0.13 | 0.04 | -0.54 | 0.03 | 0.31 | 0.25 | 0.423 | 1.32 |
| Wingman | 冲刺 | -9.68 | 12.77 | -15.05 | 12.85 | 8.45 | 10.18 |  | 1.10 |
| Wingman | 蹲 | 0.81 | -1.37 | -0.08 | 1.01 | 0.88 | 0.96 | 0.628 | 2.45 |
| Wingman | 蹲走 | 0.92 | -1.70 | -0.34 | 0.03 | 0.25 | 0.30 |  | 1.08 |
| Wingman | 滑铲 | -0.02 | -0.37 | -2.76 | 6.71 | 4.97 | 5.80 |  | 0.28 |

- **冲刺才是大动作。** R-301 枪口平均向左 10 u、向下 4.6 u，左右摆 ±6.5 u。Wingman 向右 13 u、向下 15 u。两把枪的持枪方式完全不同。
- **走路很小**：R-301 左右 ±0.7 u，上下 ±0.4 u，周期约 0.40 s。Wingman 约一半。
- **冲刺的上下摆周期 0.279 s**，和 Unity 镜头已有的 `swayPeriod` 0.280 s 一致，说明枪和镜头是同一个步频。
- **滑铲窗口只有约 0.27 s**，姿态只能当量级。Wingman 冲刺和滑铲的摆幅包含进入动作的过程，也偏大。
- 其他枪和转视角的枪模滞后，第一版没测，现在见 HOLD-POSE。

**每把枪的腰射位置也不同**：枪口在镜头前 19 u（P2020）到 68 u（Kraber），见 [02 §7](02-draw-swap.md)。Unity 只按枪类改模型长度，位置共用一个。

## 4. 数据是怎么算的

[`tools/an_hold_pose.py`](../tools/an_hold_pose.py) 读 `runs/sw_*_hip.txt`，结果在 [`data/R-HOLD-POSE.tsv`](data/R-HOLD-POSE.tsv)。每种状态只取速度稳定的那段的后 2/3，所以进入动作不全算在内，但窗口短的格子仍会带一部分。
