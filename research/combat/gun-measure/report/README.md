## 数字的来源

每个数字都带这几种标记之一。一张表如果整张同一来源，就写在表前面。

| 标记 | 意思 |
|---|---|
| **[实测]** | 在 R5 里跑出来的，或运行时读回并验证过效果 |
| **[字段]** | S21 武器文件或运行时读回的数值，没有单独验证效果 |
| **[算]** | 用验证过的公式和字段算出来的 |
| **[反编译]** | 从 `r5apex_dx12.exe` 读到的代码，没有跑 |
| **[推断]** | 没有直接证据，由别的结果推出 |
| **[没测]** | 没有数据 |

**单位：** 时间是秒；角度是度；距离是游戏单位 u。方向是相对镜头的前、右、上。

## 你问的问题，一句话答案

### 1. 动作和速度

"加速度"要分两层看。**动作的进度几乎都是匀速的，加速感来自枪和视野跟着进度走的曲线。** 所以下面分开写。

| 问题 | 答案 | 详见 |
|---|---|---|
| (a) 换弹速度 | 就是字段：R-301 战术 2.40 s，空仓 3.2 s。但 **1.39 s 已加弹、1.61 s 就能开枪**，后面的动画开枪可以切掉 **[实测]** | [01](01-reload.md) |
| (b) 换弹有加速度吗 | **动画进度是匀速的**（最大偏差 0.00–0.05），弹药是瞬间加上的。枪口的运动不匀速：R-301 战术最快约 34 u/s，空仓约 65 u/s，平均只有 15–17 u/s **[实测，采样粗，是下限]** | [01 §3](01-reload.md) |
| (c) 掏枪、切枪加速度 | **收枪先慢后快**，最快在中段，枪口落下 29–86 u。**掏枪一开始就快**，最快在前 40 %，然后减速到位，有小过冲 **[实测]** | [02 §3](02-draw-swap.md) |
| (d) 开镜、切镜加速度 | `zf` 匀速；**视野是 smoothstep**，中点最快（R-301 约 106 °/s）；**枪先甩后稳**，约一半时间就位，横向过冲 15 % **[实测]**。可变倍率切档**没测到** | [03](03-ads-optics.md) |
| (e) 换弹匣有加速度吗 | 同 (b)。能**缩短**换弹的是配件，都是按比例整体缩放，比如枪托 ×0.90，`corrupted_mag` ×1.35 **[实测]**。只有 30-30 的逐发装填真的越装越快（第 3 发起 ×0.8） | [01 §4](01-reload.md) |
| (f) 每个动作的变化 | 见下一节的总表 | |

### 2. 配件和属性

| 问题 | 答案 | 详见 |
|---|---|---|
| (a) 配件改什么 | 改字段，大多按比例。枪管改后坐，枪托改**所有动作时间**，激光改腰射散布，弹匣改发数（`corrupted_mag` 同时拖慢换弹），瞄具改视野窗口和开镜时间。Hop-up 多数只是标记，真正改行为的是切换用的 mod | [04](04-attachments.md) |
| (b) 后坐、抖动有数值吗 | 有。每把枪都有后坐的图案表、hard / soft、弹簧 k / d、fraction；枪模每发后退和横滚也有数 | [05](05-recoil-shake.md) |

### 3. 腰射

**散布 = 基础值（看姿态，慢慢过渡）+ 累计 kick（每发加，到上限，停火后回落）**，这两部分都和字段对上了 **[实测]**。R-301 站着是 3° 起步，每发 +0.2°，封顶 5°。

子弹方向 = 瞄准 + 后坐 punch + 这个圆锥内的随机量。**圆锥内部怎么分布没测到**，这次没有腰射命中点数据。详见 [06](06-hipfire-spread.md)。

## 这批数据有多可靠

- **一格一次的不少。** 状态和打断的表大多只跑了 1 次，后坐倍率差 ±0.2 以内都算没差别。
- **这是混合构建，不是正版。** 连续开枪时子弹比客户端 punch 越积越高（[05 §7](05-recoil-shake.md)），推断是两端版本不同造成的。
- **本卷里的新计算** 来自 [`tools/an_report.py`](../tools/an_report.py)，读逐帧记录，结果在 [`data/`](data/)。原始记录在私有仓库 `HSD-RawData`。
- **作废过的批次** 不在表里：弹药池为空的第一批换弹、顶住墙的第一批冲刺。这些在 [C-MOTIONS §0](../C-MOTIONS.md) 有说明。
- 表格由 [`tools/gen_report_tables.py`](../tools/gen_report_tables.py) 从数据表生成，改数字请改 `report/src/` 或数据，不要改生成后的文件。
