# 公共部件 C：锁定选目标 + 追踪投射物

批次 C（combat-c），2026-10-31，静态研究。来源根：`research-src/s21-platform/scripts/vscripts/weapons/`。

用到它的：Ballistic Whistler（`../ballistic-whistler/SYSTEM.md`，主来源 `mp_ability_debuff_zone.nut`，下文 `dz`）。对照：Valkyrie 导弹的"弯路径 + 摆动"（`../valkyrie-missile-swarm/SYSTEM.md` 3.2.3，`mp_ability_valk_cluster_missile.nut`，下文 `vk`）、批次 D 的"指派目标"（`D-TARGET-ASSIGN.md`，选队友版）。

## 0. 概要

- **部件**：每帧选目标的线程 + 锁定延迟 + 维持条件 + 发射时按"有没有锁定"分两种速度 + 引擎追踪。
- **一句话**：按住时服务端每帧在"距离 ≤ R、和准星 5° 锥内"的敌人里按 dot 打分，从高到低打可见射线，第一个看得见的当目标；锁上 0.3 s 后生效，锁上后只要 60° 视野内看得见就维持，4 s 看不见就丢；发射时有锁定就慢速追踪，没锁定就快速直飞。
- **分类**：系统。
- **谁能用**：任何"锁定后发射"的技能 / 武器（追踪导弹、锁定激光、智能手枪）。PvE：玩家锁 AI，或 AI 锁玩家。
- **可拆出的部件**：
  - 候选打分 + 多点可见检测 → 3.2.1
  - 锁定状态机（延迟 → 维持 → 超时）→ 3.2.2
  - 追踪启动延迟（按距离）+ 断追踪条件 → 3.2.3
  - 弯路径（不追踪的"导弹表演"）→ 3.2.4

## 2. 流程

```
空闲 →(按住)→ 选目标（每帧）→ 新目标：结束旧锁，开 AcquireLockon
AcquireLockon：锁定前特效，wait 0.3 → TrackingTargetLogic
TrackingTargetLogic：网络变量 = true；timeout = now + 4
  每帧：目标在 R 内且 PlayerCanSee(60°) → timeout = now + 4
  结束：超时 / 目标相位 / 隐身 / 被黑幕挡 / 锁定者死亡倒地相位上炮台被沉默 / 被 Seer 打中
松开：speed = 已锁定 ? 1500 : 3000；追踪线程：
  delay = 距离 ≥ 800 ? 0.4 : 距离 < 200 ? 0 : 0.15；wait delay；SetMissileTarget
  每帧：目标相位 / 隐身 → 断追踪
```

## 3. 代码

### 3.2.1 候选打分（`dz:592-759`）

```
过滤：同 realm、活着、非相位、非隐身、非倒地、非友方分身、非 loot tick
d = 目标中心 − 眼睛；|d| > R → 跳过
|d| ≤ 120：沿视线 120 u 射线直接打中它 → 立刻选它（近距离兜底）
dot(d̂, 视线) < cos45° → 跳过
在 cos5° 锥内？依次试 中心 / 脚底 / 眼睛，记分 = 那个 dot
按分排序；从高到低：黑幕挡（眼睛和中心都挡）→ 跳过；
   依次对 中心 / 脚底 / 眼睛 打 TRACE_MASK_VISIBLE 射线，第一个通的 → 选中
```

要点：**分数 = 和准星的夹角**（不看距离），**多点可见**（中心、脚底、眼睛任一看得见就算）。

### 3.2.2 锁定状态机

见第 2 节。锁上后不要求在 5° 锥里，60° 视野内看得见就续命——"锁很难，丢很难"。

### 3.2.3 追踪

- 追踪速度 = 转向速度 = 1500（`SetHomingSpeeds(1500, 1500)`），引擎实现转向。
- 远处先直飞 0.4 s 再追踪，近处立刻追踪——远处的弹道更像"先飞出去再拐"。

### 3.2.4 弯路径（Valk，不追踪）

三段方向向量（扇出 → 抬升转向 → 水平冲向目标）+ 各段时间比例 + 随机摆动；开始前用两条射线检查会不会撞墙，会撞就压低抬升、减小摆动（`vk:941-960`）。目标点固定，不追人。

## 6. HSD 实现

**已有部分**：`SpecialWeapons.cs` 的 `SmartPistol`（锥内选目标 + 锁定进度，`SmartPistol.Step`）。差别：智能手枪是多目标、按距离算锁定时间；R5 Whistler 是单目标、固定 0.3 s、按夹角打分、多点可见。

建议：新文件 `Combat/Homing.cs`：

- `LockOnSelector`（参数：距离、锥角、粗筛角、近距兜底、锁定延迟、维持视野、超时）——Whistler 用一套，以后 AI 锁玩家也用它。
- `HomingProjectile : ThrownItem`（参数：追踪速度、直飞速度、按距离的启动延迟、转向速度上限；每步把速度方向往目标转 `turnRate·dt`）。
- `CurvedMissile`（Valk 用）：三次贝塞尔 + 正弦摆动，不追踪。
