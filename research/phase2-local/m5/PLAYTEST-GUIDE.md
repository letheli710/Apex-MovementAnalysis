# HSD 练习场试玩指南（M5）

这是 High Speed Doom 的单人移动练习场。底层移动模型来自本地离线 R5Flowstate S21 的实测（M2–M4b），**不是**官方 Apex。
有两套配置可以随时切换：

- **参考配置（Reference，R5 校准）**：尽量贴近 R5 的基础手感。1 秒短窗口精度：95.4 % 的窗口位置误差 ≤ 4 u、速度误差
  ≤ 10 u/s（详见 `reference_config/README.md`）。
- **趣味配置（Fun，HSD 原创）**：参考配置 + 原创机制：**跑墙、飞行、重力切换**。速度上限仍按 SKILL-RULES §4（水平 900 u/s、
  向上 1100 u/s、加速倍率最多 ×1.40），不会无限叠速度。

## 1. 启动

运行工作区里 `HSD-Build` 文件夹下的 `HSD-Practice.exe`（窗口模式，1600×900，可拉伸）。鼠标会被锁定，按 **Esc** 打开菜单并释放鼠标。

## 2. 按键

| 按键 | 作用 |
|---|---|
| W A S D | 移动 |
| 鼠标 | 视角（灵敏度：菜单里 − / +，或 `[` / `]`） |
| 左 Shift（按住） | 冲刺 |
| 左 Ctrl 或 C（按住） | 蹲 / 滑铲（冲刺中按下即滑铲） |
| 空格 | 跳；空中贴墙时按 = 蹬墙跳（R5 公式）；Valk 装备在空中按住 = 喷气 |
| Q / E / Z | 技能槽 1 / 2 / 4（随装备变化，见下表） |
| F | 飞行开关（仅趣味配置） |
| G | 重力切换 ×1 → ×0.45 → ×1.6 → ×1（仅趣味配置） |
| Tab 或 F1 | 切换配置（参考 ↔ 趣味） |
| 1 / 2 / 3 | 切换三套预设装备 |
| R | 回到上一个检查点（静止，计时不停） |
| T | 回到起点，重新开始计时赛 |
| H | 显示 / 隐藏底部按键提示 |
| Esc | 暂停菜单（切换配置、装备、灵敏度、退出） |

切换配置或装备时位置和速度保留，技能冷却重新开始；正在进行的计时赛会中止（按 T 重新开始）。

### 三套装备

| 键 | 装备 | Q（槽 1） | E（槽 2） | Z（槽 4） | 其他 |
|---|---|---|---|---|---|
| 1 | Pathfinder-Octane 机动 | 钩爪（2 次 / 8 s） | 兴奋剂（4 s） | 跳板（15 s，放在前方 300 u） | — |
| 2 | Valk-Horizon 空中 | 重力升降（12 s） | — | 钩爪（1 次 / 8 s） | 空中按住空格 = 喷气（燃料 8）；Horizon 空中操控（80 / 800），落地不减速 |
| 3 | Revenant-Wraith 地面 | 猛扑（按住蓄力，0.9 s 起手 + 最多 1.3 s 蓄力，满蓄自动发射；6 s） | 虚空（Wraith 速度倍率：先 ×0.8 1.17 s，再 ×1.388；10 s） | 传送门式传送（6 s，出口 300 u/s，0.3 s 锁定操作） | — |

地图上的**固定跳板**（橙色圆盘）和**固定升降**（蓝色圆盘 + 竖杆）任何装备都能用。

### HUD

- 左上：水平速度（u/s 和 km/h，1 u = 2.54 cm）、垂直速度、地面/空中/滑铲/冲刺状态、当前配置和装备、每个技能的
  就绪/剩余冷却、喷气/飞行燃料、重力倍率、跑墙状态。
- 顶部中间：计时赛时间、下一个检查点、该配置 + 装备组合的最好成绩。
- 右上：最近的事件（技能释放、检查点等）。

参考速度：走路 199.5 u/s（18.2 km/h），冲刺 299 u/s（27.3 km/h），滑铲起步最高 460 u/s（42 km/h）。

## 3. 推荐路线（也是计时赛路线，7 个检查点：黄色 = 下一个，绿色 = 已通过）

起点在 **A 道** 的起跑圈里，离开起跑圈就开始计时。先用**参考配置**跑一遍，再用**趣味配置**跑一遍。

### A 冲刺 / 滑铲道（x 0–3000，每 500 u 一条白线）

- 按住 Shift 冲刺到 299 u/s，然后按 Ctrl 滑铲：速度瞬间 +172（最高 460），之后逐渐衰减。
- 滑铲中跳（滑铲跳）：滑铲开始 0.4 s 内跳会**退回**滑铲加速（防刷速度），0.4 s 之后跳保底 350 u/s。
- **体会**：起步加速的三段感（很快到 138，再到 199.5，冲刺段很慢到 299）；松开按键后的刹车（1250 u/s²，0.24 s 停下）；
  滑铲跳的时机窗口。

### B 跳跃 / tap strafe 场（x 3200–4800，四根橙色柱子绕桩）

- 连跳：落地后马上再跳只有 30 % 跳高，需要落地后约 0.75 s 才恢复满高；地面起跳水平速度最多 299。
- **单次按键 lurch（tap strafe）**：起跳后 0.2 s 内单点 A 或 D（或 S），速度方向会向按键方向偏转，速度大小不变，最多改变
  209 u/s；0.2–0.5 s 之间效果线性减弱。往后点 S = 空中直接刹 209 u/s。
- **体会**：落地后转向是**逐渐**的（参考配置的新模型：横向速度以 1250 u/s² 衰减），而不是瞬间转到按键方向；绕桩时这一点
  最明显。

### C 墙（x 5000–6600：两侧高墙的走廊 + 三个台阶 40 / 64 / 120 u）

- 蹬墙跳：空中贴墙（0.1 s 内碰过墙）按空格 → 离墙 182.8 u/s + 按键方向 75.1 u/s，竖直速度不变，0.4 s 一次。
- 台阶：40 和 64 u 可以跳上去，120 u 跳不上（练蹬墙跳 / 技能）。
- **趣味配置：跑墙**——空中按住 W、贴着墙、沿墙速度 ≥ 200 u/s 就会自动开始：重力只剩 0.15，沿墙速度拉向 300·msc，最长
  1.6 s；按空格离墙跳（离墙 260 + 向上 260，并打开 lurch 窗口）；按 Ctrl 脱离。同一面墙 0.6 s 内不能再跑。
- **体会**：参考配置里墙只是"挡住 + 蹬一下"；趣味配置里在走廊两面墙之间能连续跑墙。注意 R5 的攀爬 / 翻越（mantle）在游戏
  里**没有**做（只有公式和单元测试）。

### D 跳板 → lurch，升降（x 6900–8400：中台 300 u，塔顶 600 u）

- **固定跳板**（x 7000 附近的橙色圆盘）：弹射速度直接替换为 1150 u/s（水平 514、向上 1029），蹲着踩 = 更平的弹道；
  飞行中时间流速 0.8（慢动作）直到落地。
- **跳板 → lurch**（设计规则，R5 未实测）：弹射后同样有 0.5 s 的 lurch 窗口，用 A/D 单点把方向偏向中台（x 7300–8400、
  y 400–1200，高 300）。
- **固定升降**（x 7450 的蓝色圆盘）：上升 300 u/s，到 1080 u 悬停 0.5 s 后弹出（水平 400 + 向上 450；在轴心附近时朝视线，偏离轴心 40 u 以上时朝外）；
  在轴心附近**看着塔**弹出就能落到塔顶检查点。Valk 装备也能用自己的升降（Q）。
- **体会**：跳板不叠加之前的速度（替换）；兴奋剂也不放大跳板；升降弹出方向由视线决定。

### E 钩爪（x 8800–11600：三块悬空黄色锚点块、两根红柱，终点高台 200 u）

- 钩爪（装备 1 的 Q、装备 2 的 Z）：射程 850 u，瞄准点 = 命中点上方 32 u；挂上后先跳起 200 u/s，0.2 s 后开始拉：沿绳加速
  约 541 u/s²，横向速度被刹（不会像钟摆那样荡）；没有终端速度。按住 W 时沿视线方向速度上限 483。**跳不会松开钩爪**（与 R5 一致）。
  释放：接近钩住的面约 34 u、碰到墙、落地或拉了 3 s（游戏里没有手动松开），释放时动量完全保留。
- 终点高台 200 u：不靠技能上不去（台阶 64 u 也不够），要用钩爪 / 猛扑 / 喷气 / 飞行。
- **体会**：钩爪释放后的速度方向和大小（参考配置下与 R5 的偏差：释放瞬间 8–31 u/s、方向 0.4–2.5°）；钩爪 → 落地滑铲
  能保住速度但没有额外加速。

### 喷气 / 升降（装备 2）

- 空中按住空格喷气：起步 1.8 倍推力 0.5 s 内回落；松开后竖直速度 ×0.4，然后 0.45 g + 水平阻力直到离地 50 u。
- 燃料 8（每秒消耗 1 是**假设**，R5 未测到燃料下降）。
- **体会**：喷气 + 钩爪：钩爪会抢断喷气（同时只能有一个"驱动"技能），动量保留。

## 4. 参考 vs 趣味：比较什么

| 比较点 | 参考配置 | 趣味配置 |
|---|---|---|
| 基础移动（加速、刹车、跳、滑铲、lurch） | R5 实测 | 完全相同 |
| 墙 | 只能蹬墙跳 | 跑墙 + 离墙跳 |
| 空中 | 只有技能 | F 飞行（无重力，450 u/s，空格上升 / Ctrl 下降，燃料 5 s，落地 0.5 s 后每秒回 1） |
| 重力 | 750 | G 切换 ×1 / ×0.45（跳得更高更飘）/ ×1.6（短而快的跳），起跳速度不变 |
| 速度上限 | 900 / 1100 / ×1.40 | 相同（飞行、跑墙也受限） |

请重点告诉我们：参考配置哪里"不像 Apex"；趣味机制是否好玩、会不会破坏路线（比如飞行是否让钩爪站失去意义）。

## 5. 怎么反馈

每条反馈尽量包括：

1. **配置 + 装备**（HUD 左上角那两行）。
2. **位置**：哪一站（A–E）或哪个检查点之后。
3. **操作**：按了什么、什么时机（例如"冲刺滑铲 0.3 s 后跳，再点 D"）。
4. **感觉 vs 预期**："像 / 不像 Apex"，太快 / 太慢 / 太飘 / 太硬，并尽量附上 HUD 上的速度数字。
5. 计时赛成绩（如果跑完了）和截图 / 录屏（可选）。

示例：`参考配置 / Pathfinder-Octane，B 场，落地后立刻按 D：转向感觉比 Apex 慢，HUD 显示落地 296 → 0.2 s 后 200 u/s。`

## 6. 已知限制

- 地图是灰盒：只有平地和方块，没有斜坡、天花板、攀爬 / 翻越（mantle）、superglide。
- 钩爪的脱钩规则在 R5 中未识别，游戏里用"离面约 34 u"的近似；猛扑的满蓄自动发射、跳板 → lurch、蹬墙跳接技能等组合是设计规则，
  不是 R5 实测。
- 参考配置仍有误差的地方：落地后转向的前几帧（略快于 R5）、升降的进入 / 弹出时机、个别事件差一帧（详见
  `reference_config/README.md`）。
- 命令频率固定 120 Hz（画面插值），所以手感不随帧率变化。
