# HSD 练习场试玩指南（M5.5：移动反馈与可玩性）

本指南只写 M5.5 新增和改变的内容。地图、两套配置、三套装备、计时赛路线不变，见 M5 的
[`../m5/PLAYTEST-GUIDE.md`](../m5/PLAYTEST-GUIDE.md)。底层移动模型仍是本地离线 R5Flowstate S21 的实测（M2–M4b），**不是**官方 Apex。

M5.5 的所有新东西都是**纯表现层**：只读取模拟状态，不改变任何移动结果（有逐命令比特级一致的测试和回放回归作证，见
[`ACCEPTANCE-M55.md`](ACCEPTANCE-M55.md)）。

## 1. 启动

运行工作区 `HSD-Build\M55\` 文件夹里的 `HSD-Practice.exe`（在两个仓库之外）。鼠标会被锁定；Esc 打开菜单，F6 打开演示面板，
这两种情况下鼠标会释放。

## 2. M5.5 改了什么

| 部分 | 内容 |
|---|---|
| A 第一人称镜头（part A） | 眼高（站 60 / 蹲 38 / 滑铲 32 u）、滑铲侧倾、跑墙倾斜、起跳 / 落地的上抬和下沉、按速度和滑铲速度变化的 FOV、发射时的 FOV 冲击、身体惯性、速度线。全部可调、可关（Esc 菜单），设计细节见 [`CAMERA-FEEDBACK.md`](CAMERA-FEEDBACK.md)。 |
| A HUD 两种模式（part A） | **F3** 切换：普通（速度条、技能格子、燃料）/ 诊断（运动标志、lurch 窗口、各技能状态、最近 8 条命令的按键位、带时间的事件、镜头通道）。 |
| B 钩爪可视化（part B） | 瞄准时显示是否在射程内；钩头沿瞄准线按模型速度飞行；绳子；未命中、挂钩、收紧、牵引、释放各有不同的颜色、形状和文字。 |
| B 技能实体（part B） | 跳板（地图固定的和自己放的）、重力升降（固定的和自己放的）、传送门入口 / 出口、Valkyrie 喷气，都有亮色占位模型和半透明**触发体积**（F4 开关）；发射时闪光 + 一支按真实发射速度方向画的箭头（约 1.2 s）；落地时地面圆环。 |
| B 一键移动演示（part B） | **F6** 开发者面板：6 个演示，脚本输入走和玩家完全一样的输入路径；屏幕上显示真实输入时间线、实时事件、最后的 SUCCESS / FAIL 判定和测量值；可以平移关键按键的时机，看失败的样子。 |
| B 诊断 HUD 追加 | 钩爪状态（带颜色）、瞄准距离、射程说明、钩爪各时间点、上次释放原因、上次发射；实时移动事件（起跳、落地、滑铲开始 / 结束、lurch 窗口打开 / 关闭 / 使用、发射）。 |

## 3. 按键（新增的部分加粗）

| 按键 | 作用 |
|---|---|
| WASD / 鼠标 / Shift / Ctrl 或 C / 空格 / Q E Z / F / G | 同 M5 |
| Tab / F1，1 / 2 / 3，R，T，H | 同 M5 |
| Esc | 菜单：配置、装备、灵敏度、**镜头反馈设置**（开关、FOV / 侧倾 / 高度 / 惯性强度、基础 FOV、响应时间、速度线、默认 / 关闭预设），**表现层开关**（钩爪可视化、技能实体、触发体积、发射 / 落地特效），**打开演示面板** |
| **F3** | HUD 普通 ↔ 诊断 |
| **F4** | 触发体积显示开 / 关 |
| **F6** | 移动演示面板开 / 关 |
| **F7** | 运行当前演示（时机不平移） |
| **F8** | 按面板上的平移量运行当前演示 |
| **PgUp / PgDn** | （面板打开时）上一个 / 下一个演示 |
| **- / =** | （面板打开时）平移量 −0.05 / +0.05 s |

镜头和表现层设置会保存（PlayerPrefs `hsd.m55.*`）。

## 4. 怎么看钩爪状态

射程：**850 u：R5 配置值；实测有效约 830–840 u**（俯仰 0，见 [`GRAPPLE-RANGE.md`](GRAPPLE-RANGE.md)）。游戏里的判断按 850 u，
从身体原点 + 60 u 沿视线测量（和钩爪能力本身的判定是同一条射线）。竖直方向的射程和未命中时 R5 的具体表现没有测过。

| 状态 | 准星 | 世界里 | 文字（准星下方 / 诊断 HUD） |
|---|---|---|---|
| 射程内（按下会挂上） | 绿色 `( + )` | 表面上一个绿色圆环 | 距离，例如 `612 u`；诊断：`可抓取 in range 612 u ≤ 850` |
| 超出射程（按下不会挂上，也不会动） | 红色 `×` | 表面上一个红色菱形 | `超出射程 out of range 912 u`；准星下的小条：距离 / 850，白线 = 850 u |
| 没有目标（4000 u 内什么都没有） | 白色 `+` | — | 诊断：`无目标 no surface` |
| 冷却中（没有次数，按下会被拒绝） | 灰色 | 灰色圆环 | `冷却 3.2 s` |
| 发射 / 飞行 | — | 钩头（小方块）从手边沿瞄准线以 2035 u/s 飞出，白色细绳 | `钩爪飞行 hook flying → 320 u` |
| 未命中 | — | **红色**钩头飞到 850 u 再收回 | `未命中 miss: no surface`，或 `未命中 · 超出射程 912 u` |
| 挂上（attach） | — | 命中点圆环闪一下（变大变白），出现目标点小球（命中点 + 32 u） | `挂钩 attached · 收紧 wind-up 0–100%` |
| 收紧（0.2 s wind-up） | — | 绳子从黄色、下垂变成青色、拉直 | 同上，百分比 = 0.2 s 里的进度 |
| 牵引（pull） | — | 青色粗绳，轻微脉动；目标点小球 | `牵引 pulling 0.64 s` |
| 释放（release） | — | 绳子快速收回（橙色），身体位置的地面上一个橙色扩散圆环（1.5 s） | `释放 released · 原因` |

释放原因（诊断 HUD）：`贴近表面 envelope gap ≤ 34 u`（距挂钩表面 34.1 u，R5 规则未识别，这是包络近似）、`碰撞 contact`、
`落地 landing`、`超时 timeout 3 s`、`被打断 interrupted`（例如发射、传送、另一个驱动技能抢占）。

时机：钩头在「发射时刻 + 0.0043 s」后按 2035 u/s 前进，到达命中点的时刻就是模型的挂钩时刻；真正的挂钩发生在离这个时刻最近
的那条命令上，所以画面和模拟最多差半条命令（4 ms）。

## 5. 技能实体

- **跳板**：橙色圆盘 + 黄色标记；半透明橙色圆柱 = 触发体积（半径 32 + 16 u 身体，−16 到 +32 u）。触发时圆盘边缘的圈闪一下。
- **重力升降**：蓝色底盘 + 竖杆；半透明蓝色圆柱 = 触发体积（半径 70 + 16 u，高 1200 u），上面的圆环 = 90 % 高度的悬停带。
  乘坐时圆柱变亮。
- **传送门 / 传送**：按下后紫色入口环（起点）和品红出口环（目的地）之间连一条线，传送后保留 1.5 s。
- **Valkyrie 喷气**：屏幕底部蓝色光带 + 燃料百分比；低头能看到身下两道喷流。
- **发射反馈**（跳板、猛扑、升降弹出、传送门出口）：屏幕闪一下；黄色箭头 = 实际施加的发射速度（经速度上限裁剪后），
  长度 = 0.35 s 的飞行距离，画在飞行路线右侧 40 u；跳板发射很陡（63°），箭头常在视野上方，所以准星右下还有一个 1.2 s 的
  **侧视小仪表**：黄线的仰角 = 发射仰角，长度 ∝ 速度，下面写 `LAUNCH 1150 u/s / h 514 up 1029 63° · ahead`；诊断 HUD 写出
  `LAUNCH jump_pad: 1150 u/s (h 514, up 1029)`。
- **落地**：地面白色扩散圆环；超过 772 u/s 的重落地（触发落地减速）是橙色。

## 6. 移动演示（F6）

| # | 演示 | 起点 / 装备 | 成功判据（全部从模拟记录里测出来） | 失败示例（面板的“Failure case”） |
|---|---|---|---|---|
| 1 | 跳板 → Lurch | 参考配置，Pathfinder-Octane，D 区固定跳板前 | 跳板触发；空中第一次方向键按下距发射 < 0.5 s（lurch 窗口）；lurch 生效；水平方向改变 ≥ 10° | D 晚 0.5 s：`lurch window closed (0.63 s > 0.50 s)` |
| 2 | 滑铲跳 | A 道 | 滑铲开始；在滑铲中起跳；起跳水平速度 > 冲刺速度 299 u/s | 跳早 0.35 s：0.15 s 就跳，处在 0.4 s 加速回收窗口里，速度只剩 260 u/s |
| 3 | Tap strafe（单次按键 lurch） | B 区 | 起跳后 0.10 s 单按 A；lurch 生效，方向改变 ≥ 10° | A 晚 0.45 s：窗口已关 |
| 4 | 钩爪释放 → 滑铲 | C 区 120 u 台阶，从 +x 方向 | 挂上、牵引、释放（GAP）；落在台阶顶时滑铲恢复；落地速度 ≥ 释放速度的 90 % | 蹲晚 1.7 s：落地时没蹲 → 没有滑铲 |
| 5 | 蹬墙跳 | C 区走廊左墙 | 空中碰墙后 0.1 s 内按跳 → WALL_JUMP；离墙速度 ≥ 100 u/s | 第二次跳晚 0.3 s：`contact too old` |
| 6 | 钩爪射程 850 u | D 区塔楼正面 900 u 处 | 900 u 处按：未命中、不动、不扣次数；走近后按：挂上，挂钩时刻 = 0.004 + 长度 / 2035 s（±1 条命令） | 第二次按早 1.1 s：还在 869 u，仍然超出射程 |

怎么用：

1. 按 **F6**，点 1–6 选演示（或 PgUp / PgDn），看目标说明。
2. 点 **Run（F7）**。演示会先做和「回检查点」一样的重置（新的身体，静止站在起点，技能冷却清空），然后脚本按 120 命令/秒把按键
   和视角交给正常的输入路径。演示期间鼠标和键盘不起作用，Esc 中止。
3. 看屏幕：
   - 底部 **输入时间线**：每列 = 一条命令，每行 = 一个键（W A S D 跳 蹲 冲刺 Q E Z），黄色 = 按住；最下一行 = 视角变化量；
     红竖线 = 事件（起跳、发射、lurch、落地、滑铲开始、钩爪各阶段、lurch 窗口关闭）。右下是最近 8 条命令的按键、yaw / pitch 和变化量。
   - 左上 **实时事件**：从演示开始算的秒数 + 事件。
   - 右上 **判定**：SUCCESS / FAIL、一句原因，以及每条判据的实测值（✓ / ✗）。
4. 拖动 **平移** 滑块（或 - / =），点 **Run shifted（F8）**，看关键按键提前 / 推后后的结果；**Failure case** 直接用预设的失败平移。

判定不是脚本自己声称的：它在演示结束后读模拟记录（运动标志、能力事件、仲裁器的发射记录、接触时间）算出来。
同样的 12 次运行（6 个成功 + 6 个失败示例）也在测试里和构建的 `-smoke` 里无界面运行。

## 7. 请重点评价

1. **钩爪**：在射程边上来回瞄，绿 / 红 / 白的变化是否一眼能懂？未命中和超出射程是否和挂上明显不同？收紧（0.2 s）和牵引能不能感觉到？
   释放时你能不能看出是为什么释放的（诊断模式）？
2. **实体和触发体积**：跳板 / 升降的触发范围看起来是否和实际触发一致？发射箭头的方向和你飞出去的方向是否一致？
3. **演示**：跳板 → lurch 和 tap strafe 的时间线是否帮你理解了 0.5 s 窗口？平移失败示例是否有用？还缺什么演示？
4. **镜头**（part A）：滑铲、落地、发射的感觉；有没有晕；默认强度是否合适（Esc 里可调）。
5. 任何**画面和手感对不上**的地方（例如看到挂上了但没被拉、箭头和飞行方向不一致）——这些应该不会出现，出现了请记录位置和操作。

## 8. 已知限制

- 全部表现值（颜色、尺寸、时长、收回速度、箭头长度）都是设计值，没有经过试玩调整。
- 钩爪「射程内」判断用当前身体原点 + 60 u 和当前视线；下一条命令真正发射时用的是那一刻的位置和视线，所以在 850 u 边界上
  最多差一条命令的移动量（冲刺约 2.5 u）。
- R5 里竖直射程、未命中时钩头的样子、未命中是否扣次数都没测；未命中「飞到 850 u 再收回」和「不扣次数」是 HSD 的设计。
- 绳子的「手」是相机右下方的一个固定点，没有手或武器模型；第一人称下看不到自己的身体，跳板 / 升降的触发体积在脚下时需要低头看。
- 演示的起点和脚本是为当前地图写的；地图改动后需要重新校准（测试会立刻失败提醒）。
- 演示面板打开时普通 HUD 隐藏（只在面板里显示速度和状态）。
