# M10-B 试玩指南：Pathfinder Zipline Gun（滑索枪）

构建：`HSD-Build/M10B/HSD-Practice.exe`。角色按 **`\`** 切到 **Pathfinder (S21)**：Q 是钩爪（M10-A），**Z 是滑索枪（大招）**。

- **Reference** 配置（默认）：充能 **180 s**，和 S21 一样（弹匣 180，每秒回 1；R5 实测每秒 0.80–0.99）。一次只能打一条。
- **Fun** 配置（Tab 切换）：充能 **10 s**（HSD 设计值，方便练习接力），枪和绳子的规则与 Reference 完全相同。
- 想多打几条练习，切到 Fun。按两下 Tab（切配置再切回来）会原地重建身体：所有枪绳消失、充能回满，和 R5 重置一样（`R` 回检查点也会，但会把你送回路线检查点）。

结果分三类：
- 数值 / 规则测试：通过（EditMode `ZiplineGunM10BTests`、`M10BGameTests`）。
- 真实按键演示：通过（F6 面板 `m10b_*` 共 9 个，每个都有失败版本）。
- 真人手感：**尚未验收**，需要你来试。

## 1. 基本操作

1. 按 **Z** 举枪（准星下出现 `ZIPLINE … · raising`）。
2. 举枪 0.5 s 后可以开火（文字变成 `· LMB`，地面上的落点圈变绿）。
3. 按 **鼠标左键** 开火。弹丸 2600 u/s 飞向落点，落地时绳子出现（800 u 约 0.3 s，1500 u 约 0.6 s，3000 u 约 1.15 s）。
4. 再按一次 **Z** 收枪（不耗充能）；举着不动 20 s 自动收枪。
5. 绳子出现后，和地图上的滑索一样：**看向绳子按 X** 上绳。

准星和地面的提示（只是显示）：
- 举枪时有一条预览线：从你身边的起点桩到落点，**绿 = 可以打，灰 = 还在举枪，红 = 会空枪**。红色时准星下写原因。
- 绳子线被墙/物体挡住时，挡住的位置有一个红球。
- 左上角 / 底部状态栏：`zip gun …` 显示预览、弹丸飞行时间和 `ropes n/10`（场上枪绳数量）。

## 2. 什么时候能打、什么时候空枪

| 情况 | 结果 | 来源 |
|---|---|---|
| 站在地上（或 Fun 里贴墙跑 / 挂边） | 可以开火 | 脚本 [src] + R5 实测 |
| 在空中（跳起、下落） | **空枪**：没有绳子，**充能保留**，枪还举着 | R5 实测 0/3 |
| 落点离你不到 **700 u** | **空枪**（充能保留） | R5：600 u 0/3，800 u 3/3；墙 610 空枪、790 出绳 |
| 8000 u 内没有可以挂的东西（对着天空） | 空枪 | 脚本最大 8000 u（R5 场地太小没测到） |
| 弹道上有东西挡着 | 落点就是那个东西；如果它近于 700 u 就空枪 | HSD 设计（弹丸直线飞，碰到第一个实体） |
| 绳子那条线会穿过墙或物体 | 空枪 | HSD 设计（脚本里有站点之间的直线检测，原生规则没测） |
| 还没举完枪（Z 后 0.5 s 内） | 不开火（提示 raising） | HSD 设计（R5 实验举枪 1 s 后开火，更短没测） |

**绳子的位置**：起点在你身前 16 u、离地 112 u（R5 实测 16.2 / 112.1）；终点在落点正上方 112.7 u（R5 实测）。打在墙上或天花板上时，终点在墙面外 16 u、和弹着点同高（HSD 设计，R5 没测墙上的挂点）。

**陡绳**：绳子倾角超过约 44.4°（方向 z 分量 > 0.7，脚本规则）就是陡绳，预览里写 `steep`，绳子颜色偏橙。

**最多 10 条**：第 11 条出现时最早的那条消失（脚本规则；R5 实测 4 条可以同时存在）。正骑在被移除的绳上时会直接松开，保持当时的速度。绳子出现后 3 s 内被移除会退还充能（脚本规则；HSD 里没有破坏绳子的手段，只有第 11 条顶掉第 1 条这种情况，Fun 10 s 充能下也很难在 3 s 内发生）。

## 3. 骑枪绳：和地图绳一样，但速度更快

上绳、跳离、中途上绳、空中接绳、重新接绳的次数（地面 1 次 + 空中 2 次）、0.35 s 空中重接锁定、Super Jump、钩爪接绳，规则都和地图绳一样（M9-A）。不同的只有三点：

| | 地图绳（M6 / M9-A） | 枪绳（R5 实测） |
|---|---|---|
| 加速 | 0.5 s 内到 308，之后 +400/s，**最高 600** | 0.5 s 时 **502**，1.0 s **641**，1.5 s **782**，约 2.3 s 到 **1000** 并保持 |
| 到头自动松开 | 离终点 90 u，沿绳 600 | 离终点 90 u，**沿绳 600**（不管骑多快）；**陡绳只保留竖直分量：直直往上弹** |
| 跳离方向 | 水平沿绳 min(v,400) + 上 289.8 | 平绳一样 (400, 0, 289.8)；**斜绳沿绳方向**（42° 绳：296 水平 + 559 向上）；**陡绳沿你的视角**水平 400 + 上 289.8 |

所以想骑到 1000，绳子至少要约 1600 u 长（加速段约 1480 u + 末端 90 u）。

## 4. 场地：滑索枪训练区 ZG

在地图最东边、沿东边界的长条（东塔和 M7/M8 墙的东侧），站牌 “ZG M10-B Zipline Gun yard”。

| 位置 | 用途 |
|---|---|
| 黄色起点砖（x 12180, y −2450），面朝北 | **射击跑道**：前方地上标记 600（橙，空枪）、700（白，界限）、800、1500、2300、3000（蓝，R5 测过的距离） |
| 跑道东侧的平台（高 250，南边有坡道） | 站上去往跑道北边的地面打：**下坡绳** |
| 跑道西侧的矮墙（高 300） | Fun 配置贴墙跑时开火（S21 允许贴墙跑开火） |
| 北端起点砖（x 12180, y 1550）和前方 600 u 的高墙（1000 高） | **陡绳**：仰头约 51° 打墙面 800 u 高处 → 约 50° 的陡绳 |

## 5. 练习

### 5.1 打一条长绳骑到 1000（演示 `m10b_fire_ride`）
1. 站跑道起点砖，看向 **3000** 标记（几乎平视，略低头 1°），Z，0.5 s 后左键。
2. 约 1.15 s 后绳子出现在你头顶前方。**平视看着绳子方向按 X**。
3. 看左上角速度：0.5 s 502 → 1.5 s 782 → 约 2.3 s 到 **1000**，到头自动松开时是 600。
4. 失败版本：绳子还没出现就按 X（提前 1.4 s）：没有绳子可上。

对照（演示 `m10b_map_rope_cap`）：同一个 Pathfinder 去 I 站的地图平绳（x 5900–7900, y 1700），速度停在 **600**。

### 5.2 空枪（演示 `m10b_dry_fire`、`m10b_air_fire`）
- 看着橙色 600 标记开火：空枪，充能还在（状态栏仍是 ready）。把准星抬到 900 u 再开火就出绳。失败版本抬得太晚，两次都空枪。
- 起跳后在空中开火：空枪，充能还在；落地后再开火就出绳。失败版本第二枪也在空中。

### 5.3 陡绳竖直弹出（演示 `m10b_steep_exit`）
1. 站北端起点砖，仰头约 51° 对准高墙（落点在墙面 800 u 高），开火。
2. 绳子约 50°。**要抬头看着绳子（约 40°）按 X**：平视时绳子不在 34° 的上绳视锥里（这是地图绳就有的规则）。
3. 一直骑到头：自动松开时**几乎没有水平速度，直直往上弹**（vz ≈ 463；R5 52° 绳 v_h ~14），然后落回墙下。从墙面挂点没法直接上到墙顶（R5 也一样）。
4. 失败版本：到头前就跳离，就不是这个出口。

### 5.4 陡绳跳离跟随视角（演示 `m10b_steep_jump_view`）
骑陡绳时把视角转到想去的方向（例如右转 90°）再按空格：水平 400 沿视角 + 上 289.8（R5 2/3：(0, −400, 289.8)）。转晚了就沿着绳子跳。

### 5.5 Zipline → Super Jump → 空中转向（演示 `m10b_super_jump_turn`）
1. 打一条绳，站在起点桩下按 X 上绳。
2. 上绳后约 0.14 s 按空格跳离，**离上绳 0.2 s 之内再按一次空格**：Super Jump，向上约 564（R5 约 575）。
3. Super Jump 等于一次地面跳，会打开 Lurch 窗口：紧接着点一下 **D**（或 A），飞行方向会转一个大角度（演示里 |Δv| 144）。
4. 失败版本：第二下空格晚 0.2 s，没有 Super Jump（也没有 Lurch：Reference 里跳离滑索本身不开 Lurch 窗口）。

### 5.6 钩爪钩自己的枪绳（演示 `m10b_grapple_own_rope`）
1. 打一条到 1500 标记的绳。
2. 绳子出现后，抬头约 10° 看着前方 300 u 处的绳子按 **Q**。
3. 钩子钩住绳子，拉到离钩点 136 u 时自动转成上绳（和地图绳一样），然后按枪绳规则加速，超过 600（演示峰值约 890）。
4. 失败版本：绳子出现前就按 Q，钩子什么都钩不到。
5. 注意：R5 里这个只成功了 1/2（绳子在 112 u 高，第一次实验钩得太低全部没中）；R5 里转成上绳后速度从 0 重新加速，HSD 用的是地图绳的接法（保留拉动速度，再按加速曲线），开头 0.4 s 会比 R5 快一些。

反过来，**枪绳 → 钩爪**：骑绳时 Q 钩旁边的东西，骑行结束、钩爪接管（较新的动作优先），和地图绳一样。

### 5.7 两条枪绳接力（Fun，演示 `m10b_chain_two`）
1. Tab 切到 Fun（充能 10 s）。
2. 跑道起点打 1500 标记，上绳骑到头落地。
3. 等充能回来（第一枪后 10 s），在落点继续往北打第二条（约 2000 u），按 X 接着骑。
4. 失败版本：充能没回来就按 Z，举不起枪（状态栏显示冷却），没有第二条绳。

### 5.8 自己搭路线（自由练习）
- 平台下坡：从坡道走上东侧平台，往跑道北边地面打，骑下坡绳，到头 600 冲出去。
- 墙跑开火（Fun）：沿西侧矮墙贴墙跑，跑动中向北开火（S21 允许贴墙跑时开火）。
- 空中换绳：先打一条长绳，再打第二条在它前方交叉 / 平行（Fun），骑第一条时跳离、在空中看着第二条按 X（空中接绳规则同 M9-A；Reference 里跳离后 0.35 s 内不能空中接绳，Fun 没有这个锁定）。
- 最多 10 条绳同时存在，第 11 条会顶掉最早的一条。

## 6. 常见问题

- **按左键没反应**：没按 Z 举枪，或刚举枪还不到 0.5 s，或充能没满（Reference 要等 3 分钟）。
- **左键后没有绳子**：看准星下的红字（太近 / 在空中 / 绳线被挡 / 没有可挂的东西）。空枪不耗充能。
- **绳子出现了但按 X 上不去**：要看着绳子；陡绳要抬头；Reference 里刚跳离 0.35 s 内空中不能再接。
- **骑到 600 就不加速了**：那是地图绳，不是枪绳。

## 需要你反馈的

1. 举枪 0.5 s 再开火是否顺手（R5 实验是 1 s 后开火，真实举枪时间没测）。
2. 预览线 / 落点圈 / 红球是否清楚。
3. 枪绳加速到 1000 的手感，到头 600 的出口是否突兀。
4. 陡绳竖直弹出、跳离沿视角是否好用；墙上挂点在墙外 16 u 是否合理。
5. Fun 10 s 充能是否合适（Reference 保持 180 s）。
