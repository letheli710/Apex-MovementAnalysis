# M10-C 试玩指南：Octane（兴奋剂、跳板、天花板滑行）+ 滑铲修正（M10-D1）

构建：`HSD-Build/M10C/HSD-Practice.exe`。按 **`;`**（分号）切到 **Octane (S21)**：**Q = 兴奋剂（Stim）**，**Z = 跳板（大招）**，跳板飞行中按空格 = 跳板二段跳（M8-C）。

- **Reference** 配置（默认）：S21 基础 Octane，不选升级（跳板 1 个）。
- **Fun** 配置（Tab 切换）：同样的规则，外加 S21 二级升级 **Mad Hops**（跳板 2 个，可以连放两个）。
- 训练区 **OY** 在出生点西南（往左后方走）：三条带低天花板的跳板道、一个平台、一条跳板方向道、一块冲刺跳用的低板。**OS** 兴奋剂训练就用起点的 A 道（出生点正前方）。
- 地图上的跳板（训练区和 D 站）任何角色都能踩；Z 放的是你自己的跳板。

结果分三类：
- 数值 / 规则测试：通过（EditMode `SlideM10DTests`、`OctaneM10CTests`、`M10CGameTests`）。
- 真实按键演示：通过（F6 面板 `m10c_*` 共 10 个，每个都有失败版本）。
- 真人手感：**尚未验收**，需要你来试。

数字都来自本地 R5 实测（m10/r_octane、m10/r_slide）。**天花板滑行**是 S21 客户端的行为：本地 R5 的服务器（S3 版本）会把它拉回，但 S21 客户端代码就是这样预测的，社区教程（2021 年起）也是这样描述的，所以 Reference 按客户端做，标注 [S21-client]。

## 1. 兴奋剂（Q）

- 按 Q 后约 **0.16 s** 生效：移动倍率 ×1.298，持续 **6 s**，再用 0.5 s 渐渐恢复。冲刺极速 421（平时 299）。
- 所有和移动倍率挂钩的东西都一起变快：滑铲起速 **595**（平时 458）、空中速度上限、Lurch 上限（294）。
- **再按一次**：按下后 **6.7 s 内无效**（R5：+1.0 到 +6.6 s 都没反应；+7.5 s 能打第二针）。不能靠连按刷新时长。
- 扣血（−20）没有做。

练习：
1. **再次使用**（演示 `m10c_stim_relock`）：按 Q，3 秒后再按（无效，左下提示冷却），7 秒后再按（第二针生效）。失败版本：5 秒时按，被拒绝。
2. **兴奋剂滑铲**（演示 `m10c_stim_slide`）：在 A 道先按 Q，**按住 W + 冲刺跑到 421 再蹲**，滑铲起速约 595。先蹲后打针 = 普通滑铲 458。

## 2. 跳板（Z）

- 起飞速度固定 1150：**站着踩 = 63°**（向前 514、向上 1029，最高约 707）；**蹲着踩 = 45°**（向前、向上各 813，最高约 440，飞得更远更平）。
- **起飞方向 = 你踩上跳板那一刻的运动方向**，不看视角、不看按键：
  - 看着北边、按 D 往东走 → 往东飞；
  - 按住 W 冲一下然后松开、滑上跳板 → 照样沿着滑行方向飞（不是直上）；
  - **完全静止**（比如从正上方掉下来）→ 笔直向上。
- 冲多快都一样：跳板会替换掉你的速度。
- 落地有硬着陆减速（M4）；落地时按住蹲可以直接接滑铲（813 → 约 733）。
- 跳板二段跳：起飞 0.11 s 后按空格（M8-C 实测）。S21 三级升级 Airborne Agility 在 R5 里测不出区别，所以二段跳不变。
- **跳板后 TS（Lurch）**：Reference 里跳板起飞**不会**打开 Lurch 窗口（R5 实测）。想在跳板后转向，要在**踩板前一点点起跳**，用这次跳跃的 0.5 s 窗口，起飞后马上点 A/D。这是模型推断 [model]，R5 还没测。

练习（训练区 **OY4** 方向道，出生点西北，跳板在地上的蓝框里）：
3. **运动方向起飞**（演示 `m10c_pad_motion`）：站在白色起点，**视角朝北**（左边），按住 D 往东走，快到跳板时松开 D，滑上去 → 往东飞（不是往你看的北边）。松太早会停在跳板前面。
4. **蹲着踩**（演示 `m10c_pad_crouch`）：往东走，**踩板前按住蹲** → 45° 平飞。踩上去之后才蹲 = 站姿 63°。
5. **跳板 TS**（演示 `m10c_pad_ts_prejump`）：冲刺向跳板，**离跳板一步时起跳**（落点在跳板上），起飞后 0.2–0.3 s 点一下 A → 飞行方向转约 24°。点晚了（起跳后超过 0.5 s）就没反应。

## 3. 天花板滑行（重点）

在低天花板下踩跳板：头顶碰到天花板后**不会被弹下来**，而是贴着天花板继续往前滑，向上的速度慢慢耗尽（每秒减 600，跳板飞行有 0.8 倍慢动作）；水平速度保持不变（站姿 514 / 蹲姿 813）。
- 滑到天花板**边缘时如果向上速度还没用完，会被往上抛**（可以抛到高处平台上）。
- 天花板越低，碰到时向上速度越大，能滑越久：150 高约 1.6 s、250 高约 1.5 s、400 高约 1.25 s（站姿）。
- 滑行时可以**松开 W、按 A/D 空中平移**（空中加速度很小，最多横向 69 u/s）。按住 W 再按 A 没用（速度已经超过空中上限）。
- 天花板必须连续平整：碰到边缘、缝隙就结束。
- 不只限于跳板：**冲刺跳进 100 高的低板下**也会贴住，直到起跳的向上速度用完（约 0.27 s）。
- 攀爬、翻越、滑索、钩爪拉扯、Vantage 飞行、重力电梯碰到天花板仍然和以前一样被挡住（不会滑）。

训练区（出生点西南，三条道都朝东，起点是白色小方块，跳板是蓝框）：
- **OY1**：天花板 150（最北一条，y −300）
- **OY2**：天花板 250（中间），天花板尽头往前有一个 **250 高的平台**
- **OY3**：天花板 400（最南），天花板很长，向上速度会在下面用完
- **OY5**：出生点北边 A 道左侧的低板（离地 100），冲刺跳用

练习：
6. **滑行后抛上平台**（演示 `m10c_ceiling_surf`）：在 OY2 从西南斜着走向跳板，**踩板前把视角转正朝东**（让运动方向朝东），站着踩 → 贴着天花板滑 0.7 s，到边缘被抛起（向上约 476），落到平台上。转晚了 = 斜着 30° 起飞，很快从天花板侧边滑出去，落不到平台。
7. **天花板高度对比**：分别在 OY1 / OY3 踩板，看贴住的时间和边缘抛起的高度（150 抛得高，400 基本在下面就用完了）。
8. **蹲姿滑行**：OY2 蹲着踩，碰到时向上速度小一些（约 600），但水平快（813），会越过平台更远。
9. **空中平移**：滑行中松开 W、按一下 A，看身体横向漂移，漂出天花板侧边就会被抛起。
10. **冲刺跳贴板**（演示 `m10c_sprint_jump_ceiling`）：在 OY5 白色起点按住 W + 冲刺，到低板下面起跳 → 头顶贴住约 0.27 s。在板外起跳就碰不到。

## 4. 滑铲修正（M10-D1，所有角色）

这几条改了所有角色的滑铲手感（R5 实测）：
- **松开蹲会结束滑铲**：速度 ≤ 350 时立即结束（接着冲刺 299）；速度更高时先用更强的减速滑一小段，降到 350 以下结束（刚开始滑 0.1 s 就松开：再滑 0.16 s，结束时约 336）。以前松开蹲滑铲会一直滑到底。
- **滑铲跳和滑铲时间**：
  - 滑铲开始后 **约 0.22 s 内**起跳：加速被收回（434 → 273）；
  - 0.25 s 起跳：保住当时速度（约 **397**；以前是 236）；
  - 约 0.8 s 以内、速度低于 350 时起跳：提到 350；
  - 更晚起跳：保持当时的速度（1.0 s 约 236）。
- **滑铲加速要冷却**：上一次滑铲加速后 **1.8 s 内**再滑没有加速（从当前速度开始，比如 297），这次滑铲跳也不会被提到 350。和 M9-C 超级滑翔需要的冷却是同一个时间。
- 蹲着落地接滑铲（不加速、不减速）不变。

练习（A 道，出生点正前方）：
11. **松蹲结束滑铲**（演示 `m10c_slide_release`）：冲刺、蹲下滑铲，0.1 s 后松开蹲 → 滑一小段就停，接着跑。一直按住蹲 = 滑满 1.7 s。
12. **0.25 s 滑铲跳**（演示 `m10c_slide_jump_age`）：冲刺、蹲下，数到"一下"（约 0.25 s）再跳 → 起跳约 397。跳太快（0.1 s）只有 273。
13. **等加速冷却**（演示 `m10c_slide_rearm`）：滑 0.4 s，松蹲接着跑，**过 2 秒**再滑 → 又有加速（458）。只等 1 秒 → 没有加速（297）。

## 5. 对比老版本你可能会注意到

- 以前点一下蹲就能一直滑；现在要按住蹲才会继续滑。
- 以前任何时候滑铲跳都能提到 350；现在滑久了（约 0.8 s 后）就保持当时速度。
- 连续两次快速滑铲，第二次没有加速。
- 时间赛（路线 2）自动跑一圈从 80.82 s 变成 80.55 s：钻过 K 障碍后松蹲，滑铲提前结束改成冲刺。
- 以前碰天花板会被直接弹停；现在在空中自由飞行时会贴着天花板滑（包括钩爪松开之后）。
