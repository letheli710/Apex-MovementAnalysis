## 完成清单

### M10-A Pathfinder 高级钩爪
- [x] **A1 资料**：每条都有来源、版本和证据等级。S21 脚本常数：绳长上限 850，冷却按移动距离 10–30 秒。
- [x] **A2 R5 实测和复现**：
  - S21 的钩爪**没有钟摆**（摆荡开关关闭）。牵引中按侧向键会像空中扫射一样加速（空中加速 650 大于沿绳制动 425），Slingshot 就是由这个机制自然产生的。
  - 和 R5 对比：

    | 技巧 | Unity | R5 |
    |---|---|---|
    | Slingshot | 889 / 975 | 854 / 911 |
    | 侧向键牵引 | 927–934 | 938–945 |
    | Jump Grapple（钩中后 0.2 秒内起跳） | 1025–1049 | 1006–1029 |
    | 钩爪跳跃最高点 | 和 R5 完全相同 | — |
  - **脱钩规则**：
    - 离锚点 36–50 u 自动脱开；
    - 越过锚点；
    - 按下蹲：保留动量；
    - 再按一次战术键：速度限到 460；
    - 视线偏离超过 100°：按 S21 客户端行为实现，见下文"混合版本分裂"。
  - **Rodeo 绕柱**：用同样的输入能自然绕出 212–227°（R5 绕到 393°，因为本地旧服务器不执行视线脱钩），算部分复现。
  - Super Grapple、Slide Grapple、Double Bounce 在 R5 里也没复现出来（止损），所以没有实现。
- [x] **A3 训练**：训练场 GY 按 R5 的锚点几何搭建；HUD 显示起跳窗口和牵引速度；有中文分步练习指南。

### M10-B Zipline Gun
- [x] **B1 R5 实测**：本地可以用真实的终极技能部署。
  - 只能在地面、跑墙或抓墙时发射；距离 700–8000 u，太近会空发，不扣次数；
  - 绳子离两端支架约 112 u 高；
  - 乘坐速度一直加速，上限 1000（地图绳是 600）；陡绳垂直出口；
  - 冷却约 3 分钟。
- [x] **B2 实现**：**只有一套绳索系统**。枪生成一根普通的绳，带上各自的速度参数，然后由原来的乘绳能力乘坐。中段挂绳、空中挂绳、重挂次数、Super Jump、挂绳提示、钩爪接绳全部自动生效。地图绳逐字节不变。
  - 速度对照：0.5 / 1.0 / 1.5 秒时 Unity 502 / 642 / 782，R5 502 / 642 / 782。
- [x] **B3 组合**：Zipline → Super Jump → Lurch；钩爪接自己布的绳（R5 8/8 成功）；串联两根自布绳；训练场 ZG；9 个演示。

### M10-C Octane
- [x] **C1 兴奋剂**：生效延迟 0.158 秒，速度 ×1.49，持续 6 秒，原来就和实测一致。持续期间加 0.7 秒冷却不能重按（R5 实测；Wiki 说的 1.8 秒不符），新增 "Octane S21" 配置。
- [x] **C2 跳板**：
  - 站立和下蹲发射角度分别是 63.4° 和 45°；发射方向取决于触板时的**运动方向**（R5 证实，Wiki 的"不按键就直着向上"不对）。
  - S21 升级做成可选项：第二个跳板在 Fun 开启；×1.2 因为不确定版本，先关闭；二段跳变向在 R5 里看不出差别。
- [x] **C3 天花板滑行**：本地服务器不支持（见下文），**按 S21 客户端行为实现**：贴住天花板后，向上速度按重力逐渐衰减（跳板飞行时 600，普通跳跃 750，R5 是 602 和 756），水平速度和空中扫射保留，飞出边缘时被向上抛。训练场 OY 有三种高度的天花板。

### M10-D 底层
- [x] **D1 滑铲**：
  - 松开下蹲：速度降到 350 以下时滑铲结束（0.10 秒松开：R5 19 帧后 336.26，Unity 19 帧后 336.25）；
  - 按滑铲时长起跳的出口速度：Unity 273 / 396.9 / 361.6 / 350 / 238，R5 273 / 397 / 361.5 / 350 / 236；
  - 滑铲加速 1.8 秒后才能再次触发。
- [x] **D2 输入层**：改成记录每个方向键各自的状态。A+D、W+S 同时按住以及三键组合都能正确表达；旧脚本产生的指令逐位相同。R-1a（按住 W+A 再按 D）现在是 −31.9°，和 R5 一致；Lurch 模型没有改。
- [x] **D3 跳板 Lurch**：按你的决定处理（见上）。
- [x] **D4 遗留问题**：修了一个真缺陷：冲刺后按 S（或原地 180° 转身），会一直以 199.5 u/s 往前走。其余遗留问题都列在 M10C-UNITY.md §9 里，没有发现会破坏功能的。

### Wraith（用户批准的扩展）
- **传送门**：按 R5 实测实现。
  - 放置时速度阶梯提高（364 / 415 / 468 / 519）；
  - 两个门最少间隔约 128 u；门存在 45 秒；
  - 穿越时间 = 路径长度 ÷ 1024，限制在 0.3–2.0 秒（长路径最多 3.5 秒），另加 0.2 秒，期间玩家输入无效；
  - **出口速度为 0**；可以反复穿越；相位状态下穿门无效。
- **相位**：按 R5 曲线重新实现，放进新的 "Wraith S21" 配置；旧的 Revenant-Wraith 配置按你的要求不动。
- **加速换算公式**：速度倍率 = W ×（1 + 2 × 强度），强度按字节取整；W 在拿着近战武器时是 1.15，技能锁住武器时是 1.0。兴奋剂、相位、传送门放置都符合这一条。

## 混合版本分裂：Leader 定的处理原则
本地的 S21 客户端和 S3 服务器有两处表现不一致：天花板滑行，和钩爪"视线偏离 100° 脱钩"。客户端会做出这两个行为，旧服务器会把它纠正回去。

**处理原则**：以 S21 为准。如果社区资料能证实 S21 确实有这个行为，Reference 就按 S21 客户端做，标注为 [S21-client; local dedi differs]。天花板滑行在 2021 年以前就有教程记载，所以按这条原则实现了。**如果你认为应该按本地服务器做，告诉我，我改回来。**

## 下一批推荐（E2，并参考 R2 实测）
1. **Mad Maggie 加速垫**：S21 就有，本地能触发真实技能，已经实测（垫上 ×1.298，不需要冲刺，离开后约 2 秒，在垫上滑铲时摩擦变小）。成本最低。
2. **Newcastle 跃进**：本地能触发，已经实测（最远约 1575 u，发射速度 1798–2447，落地直接停住）。可以复用 Vantage 的位移驱动。
3. **Pathfinder 剩余技巧**：Super Grapple、Slide Grapple、Double Bounce，需要重新设计实验。
4. **Horizon 升梯**补两项小功能：2 秒内不能重新进入、10 秒到期弹出。

**不推荐**：Black Hole、Skyward Dive、Ash 冲刺（你已否决）、Sparrow 和其他 S21 之后的内容，Loba 和 Alter 继续搁置。

## 遗留问题（不影响功能）
- **钩爪**：
  - 锚点在眼睛高度时，R5 是 728，Unity 是 608，原因不明；
  - 制动的触发条件是拟合出来的，部分侧向键试次偏低 8–11%；
  - Rodeo 只是部分复现；
  - 空中钩中后能否跳跃没测。
- **Zipline Gun**：
  - 举枪时间 0.5 秒、打在墙上或天花板时绳子末端的位置，都是设计值；
  - 8000 的最大距离只有脚本证据（场地不够长）；
  - 钩爪接自布绳后，R5 会从头加速，Unity 沿用地图绳的交接方式，所以前约 0.4 秒更快。
- **Octane**：
  - 兴奋剂状态下兔跳，Unity 是 420.9，R5 是 410.6；
  - 天花板滑行的完整长度是按客户端外推的；
  - 跳板跑墙、跳板前起跳接 TS 都没在 R5 测过。
- **Wraith**：
  - 传送门触发范围是设计值；
  - 穿越时 Unity 不转视角，R5 会转；
  - 相位结束后 R5 停在 1.0，直到拔出武器，Unity 回到 1.15。
- **滑铲**：新规则没有放进回放模型（见上）。
