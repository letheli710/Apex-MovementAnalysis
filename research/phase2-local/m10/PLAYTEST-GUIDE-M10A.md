# M10-A 试玩指南：Pathfinder 钩爪（Slingshot / Jump Grapple / 脱钩）

构建：`HSD-Build/M10A/HSD-Practice.exe`。配置用 **Reference**（F1 面板或默认）。角色按 **`\`** 切到 **Pathfinder (S21)**（只有钩爪，1 次充能，冷却 10–30 s，按移动距离算）。练习时嫌冷却长，可以按 `1` 用旧的 Pathfinder-Octane 预设（2 次充能、8 s），钩爪规则一样。

结果分三类：
- 数值 / 规则测试：通过（EditMode `GrappleM10ATests`、`M10AGameTests`）。
- 真实按键演示：通过（F6 面板 `m10a_*` 共 7 个，每个都有失败版本）。
- 真人手感：**尚未验收**，需要你来试。

## 1. 场地：钩爪训练区 GY

在地图南侧（Echo 训练区南边、课程南线北边），站牌 “GY M10-A grapple yard”。

| 位置 | 用途 |
|---|---|
| 黄色起点砖 A（x 6700, y −1300） | Slingshot 600：正前方 438 u 有一块悬空锚块，钩点约 576 u 高（仰角 49.7°） |
| 起点砖 B（x 8000, y −1300） | Slingshot 800：锚块 589 u 远，钩点约 661 u 高（仰角 45.6°） |
| 起点砖 C（x 6700, y −1080） | Jump Grapple 跑道：地上 400 / 700 u 两个标记 |
| 起点砖 D（x 9430, y −1410） | Tether / Rodeo：前方头顶是一块悬空板（底面 470 u 高），东边一根细柱 |
| 跳跃砖 E（x 9200, y −1050） | Grapple hop |

每条 Slingshot 跑道上，锚块前 45 u 有一条横线：钩子会在身体离钩点 45 u 时自动松开（“贴近钩点”脱钩）。起点砖 A 周围的小点是视线角度线：85°（越过钩点脱钩）和 100°（视线离开脱钩）。

## 2. 准星旁的提示（只是显示，不影响手感）

- 钩子落地后、拉动开始前（0.2 s）：准星下显示 **“跳 JUMP → jump grapple”**（绿色）——这时按空格就是 Jump Grapple。
- 拉动中：显示 **当前速度 / 斜坡目标速度**（例如 `612 u/s · ramp 625`）。目标速度从 50 涨到 800（1.5 s），不按键时你的速度就贴着它。
- F2 诊断面板里还有：上次松开的原因（贴近钩点 / 越过钩点 / 视线离开 / 下蹲 / 再按一次）、松开时的速度、这次的冷却秒数和移动距离。

## 3. 先熟悉基本拉动（2 分钟）

1. 站砖 A，看向锚块（准星变成 `( + )`），按 **Q**。
2. 什么都不按。0.35 s 后钩子挂上（你会被抬起一点），再过 0.2 s 开始拉。
3. 看准星下的速度：一路涨到约 **796**，到横线附近自动松开。
4. 再试一次：拉动中按住 **W**。速度会被卡在水平 483（W 方向上限），反而更慢——这是 R5 实测的规则。

## 4. Slingshot（侧向键 + 转视角）

原理：拉动中按侧向键，就像空中扫射，650 u/s² 的加速度大于 425 的横向刹车，所以人会往侧面甩出去，总速度超过只靠绳子的 800。

**第一步：只按侧向键（最简单）**
1. 砖 A，Q 钩锚块。
2. 钩子开始拉之后（准星下开始出现速度数字），**按住 D**（或 A），视角不动。
3. 速度会涨到 **~930**（R5 实测 938–945；不按键 796）。你会从锚块侧面甩过去。
4. 演示：F6 → `m10a_side_key`。失败版本把 D 推迟到拉动结束后：只有 799。

**第二步：完整 Slingshot（社区 G-1 打法）**
1. 砖 A，Q。
2. 拉动开始时（按 Q 后约 0.5 s）：**按住 W+A，同时向左转视角约 80°**（大约 0.27 s 转完）。
3. 拉到一半（按 Q 后约 1.2 s）：**换成 W+D，同时向右转回 90°**，让自己经过锚块时正面朝前。
4. 速度峰值 **~890**（R5 实测 854；不按键 796）。砖 B 的 800 锚块上 R5 是 911。
5. 演示：F6 → `m10a_slingshot`；失败版本把扫射推迟 1.3 s，变成普通拉动。

常见错误：
- 太早按键：钩子还在飞或在 0.2 s 预拉阶段，侧向键只是普通空中移动。等速度数字出现再按。
- 一直按 W：W 方向被卡在 483，等于自己刹车。
- 视角转太多：钩点离开视线超过 100° 会直接松钩（见第 7 节）。

## 5. Jump Grapple（钩地面 + 0.2 s 内起跳）

1. 站砖 C，看向 700 标记（略低头 4.9°），按 **Q**。
2. 约 0.35 s 后钩子落地，你被抬起（准星下绿色 “跳 JUMP”）。
3. **在 0.2 s 内按空格**。跳跃叠加在抬起上（+280 u/s 向上）。
4. 之后绳子在你脚下水平拉你，你从钩点上方飞过，出口水平速度 **~1030**（R5 实测 997–1030；不跳 797）。
5. 演示：F6 → `m10a_jump_grapple`。失败版本晚 0.22 s 跳：拉动已经开始，空格不起作用，只有 800。

计时要点：按 Q 到落地约 0.35 s（700 u 时），落地后 0.2 s 内跳。R5 实测：落地后第 1–18 个指令（≤0.15 s）都可以，第 24 个（0.2 s）就晚了。先慢慢练“按 Q → 数一拍 → 跳”。

## 6. Grapple hop

1. 站砖 E，**低头到底（89°）**，按 Q。钩子落在脚下，太近了，不会拉，只把你抬起 200 u/s。
2. 紧接着按空格：跳跃叠在抬起上，最高点 **~150 u**（R5 146–155）；只抬起是 27 u，普通跳是 55 u。
3. 演示：`m10a_hop`；失败版本晚 0.28 s 跳，窗口已过，只有 27 u。

## 7. 什么时候会松钩（脱钩规则）

| 规则 | 怎么触发 | 速度 |
|---|---|---|
| 贴近钩点 | 钩点离你的身体（脚到头 72 u）45 u 以内 | 保持 |
| 越过钩点 | 已经在远离钩点，并且钩点偏离视线 85° 以上 | 保持 |
| 视线离开 | 钩点偏离视线超过 100°（S21 客户端规则；本地服务器其实会多拉 0.6–1.2 s，按负责人决定 Reference 跟 S21 客户端） | 保持 |
| 下蹲 | 拉动中按 Ctrl | 保持 |
| 再按一次 Q | 拉动中再按 Q | 低于 460 保持；高于 460 变成 max(460, 速度 − 300) |
| 低速 | 速度低于 250 持续 1.5 s（贴墙 1.2 s、贴地 0.7 s） | 保持 |

练习：
- 视线离开：砖 A 钩锚块，拉动中向右持续转视角（180°/s），钩点离开视线 100° 时松开。演示 `m10a_look_away`。
- 越过钩点：Jump Grapple 就是从钩点上方飞过时松开的。
- 松开不算跳：松钩后马上按 A/D 不会有 Lurch（要先跳一下才有，见 M8-B 演示 `m8b_grapple_lurch`）。松钩后按住 Ctrl 落地可以直接接滑铲。

## 8. 地面发射要注意

站在地上冲刺时按 Q，如果同时**松开了 W/冲刺**，助跑速度会按地面减速（1250 u/s²）在钩子飞行的 0.25 s 里掉光（R5 实测 297 → 0，就是这个原因：实验脚本按 Q 时松了键）。演示 `m10a_ground_fire`。按住 W 的话 HSD 会保留助跑（R5 没测过，属于模型推断）。在空中发射则完全保留速度。

## 9. Tether / Rodeo（实验）

砖 D：冲刺 1.8 s 到板下，起跳，0.2 s 后仰头 75° 钩板底面，然后**按住 D 并持续向右转视角（每秒约 120°）**。侧向键加转视角会让你绕着钩点甩，速度约 700（R5 700）。HSD 里大约甩 210–230° 后头碰到板、再被“越过 / 视线离开”规则松开；R5 里贴着岩石继续绕到 393°。这是 [模型] 结果，不是硬编码；细柱目前只是给你自己试的。演示 `m10a_tether`。

## 10. 冷却

Pathfinder (S21)：1 次充能。钩子挂上后开始计算移动距离（钩爪激活中或速度 > 500 时，最多 5 s，上 Zipline 时停止），冷却 = 10 s + 按距离最多到 30 s（约 3100 u 以上就是 30 s）。F2 面板显示本次冷却和距离。

## 需要你反馈的

1. Slingshot 的侧向加速手感（太强 / 太弱？）。
2. Jump Grapple 的 0.2 s 窗口是否好掌握，准星提示有没有帮助。
3. 视线离开 100° 就松钩，会不会在正常转视角时误触发。
4. Pathfinder (S21) 的 10–30 s 冷却在练习场里是否太长（可以只在这个预设上用，旧预设保持 8 s）。
