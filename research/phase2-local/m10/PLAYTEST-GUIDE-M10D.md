# M10-D2 / D3 试玩指南：多方向输入、跳板发射后的 Lurch

构建：`HSD-Build\M10D\HSD-Practice.exe`。技术说明见 [unity/M10D-UNITY.md](unity/M10D-UNITY.md)。

> **验收状态（三类分开）**
> - 「数值/规则测试通过」：按键组合（含 A+D、W+S、三键）、按下/松开的边沿、R-1a 对上 R5 实测、跳板发射后 Reference 不开 Lurch 窗口、Fun 保留，都有单元测试；所有回放、旧演示、M5 路线、赛道单圈都没变。
> - 「真实按键演示通过」：没有新演示；M5.5 的 `pad_lurch` 演示改在 Fun 下运行，判定文字和以前完全一样。
> - 「真人手感未验收」：还没人玩过。

## 改了什么

1. **W/A/S/D 每个键单独记录**。以前 A 和 D 同时按会合成"没按左右"，所以：
   - 按住 W+A 再按 D：以前没反应，现在会往前 Lurch（R5 实测 −31.9°，Unity −31.9°）。
   - 按住 A+D 再松开 D：以前会被当成"按了 A"，凭空 Lurch 一下；现在不会（松开键不算按下）。
   - 按住 A 再按 D：两边抵消，不 Lurch（和 R5 一样）。
   - 方向本身没变：相反的键互相抵消，两个方向键是 45° 斜向。Lurch 的窗口、力度上限都没改，没有加任何新能力。
2. **跳板发射后的 Lurch**（你的决定：尽量贴合 R5）：
   - **Reference**：跳板发射**不再**打开 Lurch 窗口（R5 实测：发射后立刻按方向键没有 Lurch）。想在跳板后 Lurch：先做**跳板二段跳**（空格），二段跳之后 0.5 秒内按方向键就有 Lurch（R5 实测）。
   - **Fun**：保留 M5.5 的"跳板 → Lurch"【设计值】。
   - `pad_lurch` 演示移到 Fun（F6 面板里标题后面多了"Fun：R5 跳板发射不开 Lurch 窗口"），成功版和失败版的结果不变。

## 怎么试

- Tab / F1 切 Reference 和 Fun，去 D 区跳板：
  - Reference：冲上跳板，起飞后 0.1 秒按 D——方向不变。再试：起飞后按空格（二段跳），接着按 D——会拐。
  - Fun：冲上跳板，起飞后 0.1 秒按 D——会拐（和以前一样）。
- 任何地方跳起来：按住 W+A，空中按一下 D——往正前方拐（以前不拐）。按住 A+D 起跳再松开 D——不会突然往左拐（以前会）。

## 没做 / 待定

- 松开一个键不触发 Lurch、以及其他三键组合，R5 没有对应数据，是现有模型推出来的【模型】。
- 手柄摇杆没有单独的按键边沿（摇杆仍按两个轴处理）。
