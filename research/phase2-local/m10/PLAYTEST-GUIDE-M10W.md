# M10-W 试玩指南：Wraith 传送门（Dimensional Rift）+ 虚空（Into the Void）

构建：`HSD-Build/M10W/HSD-Practice.exe`。按 **`'`**（单引号键，回车左边）切到 **Wraith (S21)**：**Q = 虚空（Into the Void）**，**Z = 传送门（大招）**。

- Reference 和 Fun 两个配置里规则一样（都是 S21 实测）。
- 旧的 **Revenant-Wraith** 预设（按 3）保持不变：它的相位仍是 M4 的近似版本，传送仍是旧的固定出口设计。新预设才是 S21 实测版。
- 训练区：**WL 放置道**在出生点右前方（南侧，y −550 那条往东的长线，白色起点方块在 x 400）；**WT 跳塔**在地图东北角附近（M6 滑索区北侧，两个蓝色电梯 + 台阶 + 高塔）。
- 冷却：虚空 25 s（S21），传送门 20 s（练习值；S21 是 3 分钟）。

结果分三类：
- 数值 / 规则测试：通过（EditMode `SpeedBoostM10WTests`、`VoidM10WTests`、`RiftM10WTests`、`M10WGameTests`）。
- 真实按键演示：通过（F6 面板 `m10w_*` 共 8 个，每个都有失败版本）。
- 真人手感：**尚未验收**，需要你来试。

数字都来自本地 R5 实测（m10/r_wraith、m10/r2_wraith、m10/r2_speedboost）。

## 1. 传送门怎么用

1. **按 Z**：举起装置。约 0.4 s 后会突然变慢（冲刺被打断，几乎走不动，然后慢慢恢复）——R5 里也是这样（299 掉到 65）。
2. **按下 1.04 s 后**：在你脚下放出**起点门**（紫色柱子），开始记录路径（地上一条紫线）。这时**自动冲刺**，速度 **364**（平时 299）。
3. 跑远一点，**再按 Z**：在你脚下放出**终点门**。离起点**不到 128 u**（大约三步）会直接取消：没有门，**大招不扣**。
4. 两扇门**存在 45 秒**（柱子上方有倒计时）。
5. **走进任意一扇门** → 沿着你放门时走过的路线**原路飞到另一扇门**（往返都行）：
   - 飞行时间 = 路径长 / 1024，最少 0.3 s、最多 2.0 s（路径 3000–6000 u 时上限逐渐放宽到 3.5 s），按 0.1 s 取整，再加 0.2 s。比如 400 u 路径 = 0.5 s，6100 u = 3.7 s。
   - 飞行中按键全部无效，会穿过路径上的障碍。
   - **到达时速度永远是 0**——不管你冲多快进门（R5 实测 24 次全是 0）。出门是静止状态。
6. **站在刚到达的门上不会被送回去**。想再传，**走出门再走进来**（出门后 0.5 s 内不会再传）。
7. 放门过程中会再碰到旧门不会传送；新的一对门放好后，旧的那对消失。

**放置加速（重点）**：速度看的是你离起点门的**直线距离**（三维，包括高度差），不是走过的路程：
- 一开始 364；
- 直线距离超过约 **40 %**（6000 u 的 40 % ≈ 2400 u）→ **415**；
- 约 **60 %** → **468**；约 **80 %** → **519**（最高）。
- 每次升级后，下一级要比"升级时的位置"再远 20 %（R5 每 0.1 s 检查一次，所以下落很快时会比标线晚一点：R5 实测 43–48 %、65–71 %、87 %）。
- 放置最长 **10 秒**，或者水平走满 6000 u，会自动放下终点门。平地从静止起跑，10 秒内只能到 415；想更快就要从高处往下跳（高度差也算直线距离）。

## 2. 虚空（Q）

- 按 Q 后约 0.37 s 开始变慢、**冲刺被打断**（走路速度，然后慢慢恢复），**1.175 s 后进入相位**：
  - 速度 ×1.596（冲刺 **415**），并且**自动冲刺**；
  - 相位持续约 4 s，最后 1.2 s 速度慢慢回落；
  - 再按 Q 无效。
- **相位中**：
  - 走过传送门**不会传送**（R5 实测 0/3）；要传送得等相位结束、走出门再走进来；
  - 按 Z **没反应，也不扣大招**。

## 3. 练习

### WL 放置道（出生点右前方的长线）

线上每 1200 u 一个标记（20 / 40 / 60 / 80 / 100 %，从白色起点算）。

1. **放门 + 穿越**（演示 `m10w_rift_travel`）：站在白色起点，按 Z，按住 W，1.5 秒后再按 Z（终点门）。转身走回终点门 → 0.6 s 后到达起点门，静止。
   失败版本：两下 Z 按太快（第二下在 1.04 s 举起阶段内）→ 取消，没有门。
2. **最短间距**（演示 `m10w_rift_gap`）：按 Z，等起点门出现，往前走一小步就按 Z：超过 128 u 有门（扣大招），不到 128 u 取消（大招还在，左下 HUD 会提示 "cancelled"）。
3. **出门速度为 0**（演示 `m10w_exit_slide`）：冲刺着冲进门，出来是静止的。出门马上蹲 = 没有滑铲（速度不到 200）；先冲刺约 1 s 再蹲才能滑。出门后马上起跳 + 点 A/D 也能 TS（从静止起跳）。
4. **反复穿越**（演示 `m10w_rift_repeat`）：传到起点门后**站着不动**——不会被送回去；往前走出门、再退回来 → 又传到终点门。
5. **虚空穿门**（演示 `m10w_void_portal`）：放好一对门，按 Q，等相位开始（约 1.2 s）后走过两扇门 → 都不传送。Q 按晚了，进门时还没进相位 → 照样被传走。
6. **放置加速**（演示 `m10w_place_ramp`）：站在白色起点按 Z，等起点门出现后一直按 W 往东跑，看左下 HUD 的百分比和速度：过 40 % 标记附近速度从 364 变 415。不到 40 % 就放终点门 = 一直 364。

### WT 跳塔（地图东北，M6 滑索区北侧）

7. **上塔**：站在地上蓝色方块（电梯）西边，**看着东边走进电梯** → 升上去被弹到台阶（高 1000）上，正好落进第二个电梯 → 弹到高塔顶（高 2000）。
8. **长路径**（演示 `m10w_drop_long`）：在塔顶东边缘按 Z，等起点门出现，往东走下塔、落地、继续往东跑（落地后会硬着陆减速约 1 s）。路上直线距离过 40 % 会升到 415。跑到约 x 11300（白色方块）按 Z。退回终点门 → 2.3 s 后被"倒放"回塔顶（下落路线反着飞上去），静止。
   落地后马上放终点门（路径不到 3000 u）= 飞行时间只有 2.0 + 0.2 s。
9. **不同高度的门**：台阶（1000）、塔顶（2000）、地面之间任意放一对，看飞行路线（下落和电梯段都会原样回放）。

### 组合

10. **跳板飞进门**（演示 `m10w_pad_portal`）：在 OY4 跳板（M10-C 训练区，出生点西北）的落点放起点门，往西走两步放终点门；绕开跳板走到它西边的起点，朝东走上跳板 → 飞行落进起点门 → 传到终点门，静止。
11. **滑索 / 钩爪进门**：把门放在滑索路线或钩爪拉扯路线上（比如骑滑索时放起点门），之后再骑过去 → 进门那一刻滑索 / 钩爪结束，被传走，出门静止。（钩爪在 Wraith 预设里没有，只有测试覆盖。）

## 4. 已知差异 / 待定

- 门的触发范围（半径 32、上下 −36…+72）是设计值，R5 只知道蹲姿门更小（半径 16）。蹲着放的点不会强制蹲下。
- R5 传送时会把视角慢慢转向路线方向（短路线到达时还没转完）；HSD **不转视角**。
- 虚空结束后 R5 的移动倍率停在 1.0（手里没武器），HSD 回到 1.15（HSD 没有武器栏）。
- 放置时按住不放（R5 会一直放到约 8.6 s）、3 m 内取消保留加速（Portal glide）没有做。
- 顺便发现一个旧问题（没改）：Reference 地面转向在"按键方向和当前速度完全相反"时不会掉头——比如冲刺中松开 W、鼠标不动直接按 S，会一直以 199.5 往前滑。鼠标稍微动一点（≥ 1°）就正常。这是 M5 的地面转向规则，修它会改变旧轨迹，交给 Leader 决定。
