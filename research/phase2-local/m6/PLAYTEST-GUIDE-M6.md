# M6-A 试玩路线指南（攀爬 / 翻越 / Superglide、Zipline、连续 Lurch / Tap Strafe）

构建：`HSD-Build\M6\HSD-Practice.exe`。双击即可运行，窗口模式，1600×900。M5.5 的全部内容保持不变，包括地图 A–E、计时赛、镜头和 Demo。新内容都在地图北侧的 M6 区（y > 1450）。

## 1. 按键

| 操作 | 按键 |
|---|---|
| 移动 / 视角 | WASD / 鼠标 |
| 冲刺 / 蹲·滑铲 / 跳 | Shift / Ctrl 或 C / 空格 |
| **使用（上 Zipline）** | **X** |
| **鼠标滚轮** | **= 轻点一次 W**（Tap strafe 绑定，上下滚都算） |
| 技能 | Q / E / Z（F 飞行、G 重力切换只在 Fun 配置里有） |
| 配置 / 技能组 | Tab / 1 2 3 |
| 回检查点 / 重开计时 | R / T |
| 诊断 HUD / Movement Demo 面板 | F3 / F6 |

- 滚轮的每一格都是一次独立的 W 按下。一帧里滚多格，也会拆成每两条指令一次的按下。
- 很短的键盘轻点也不会被吞掉。
- 按住 W 时滚轮无效，因为 W 已经按着，不会产生新的按下。

## 2. 去 M6 区

- 出生点在地图南侧 A 区起点。转身朝 +y 方向，也就是出生朝向的左手边，走约 1500 u，可以看到地面上的站牌 F / G / H / I。
- 想直接看演示：按 F6 打开 Demo 面板，用 PgUp/PgDn 选 7–10 号（M6 演示），按 F7 运行。Demo 结束后人物停在演示地点附近，可以接着自己练。
- 建议先用 **Reference 配置**（Tab 切换，HUD 左上显示）。Fun 配置额外允许在空中上 Zipline。

## 3. 站点与要感受的东西

### F：Lurch / Tap strafe 场（x 0–1800）

- **叠加 Lurch。** 起跳后 0.2 s 内连按两次 D：第二次还会再拐一点，并且不掉速度。
- **反向急刹。** 起跳后先按 A 再按 D：两次都是满额拐向，速度明显下降。
- **Tap strafe。** 起跳后一边向右转鼠标，一边每帧滚一格滚轮（或者快速连点 W）：飞行方向跟着视角走。窗口约 0.5 s，最开始 0.2 s 最强。
- **对照。** 只按住 W 转视角，几乎拐不动。这就是 tap strafe 值得练的原因。
- **请判断：** 滚轮和连点 W 的手感是否一致？拐向够不够顺？

### G：蹬墙跳走廊（x 2400–3600）

- 冲刺，滑铲，滑铲跳，以大约 45° 斜着撞墙，碰墙瞬间再按跳：墙跳弹开。弹开后立刻 tap strafe，窗口按墙跳重新计时。
- 正对墙（约 35° 以内）、按住 W 撞上去，会变成攀爬（见 H），不是墙跳。
- **请判断：** 斜撞弹开和正撞攀爬的区分是否自然？35° 这个角度是设计值。

### H：攀爬墙（x 3800–5320，五个高度）

- 从南边冲刺过来，在墙前约 100 u 处起跳，按住 W 正对墙面。

| 墙高 | 结果 |
|---|---|
| 60 | 直接跳上去 |
| 120 | 接触瞬间翻越（mantle），约 0.6 s |
| 180 | 先爬约 0.4 s，再翻越 |
| 232 | 爬满约 0.85 s，顶端小跳，空中抓边翻越 |
| 300 | 爬满后小跳，够不到，掉下来；落地前不能再爬第二次 |

- **翻越出口** 按住 W 时以 299 u/s 冲出，方向跟随按键方向（W+D 斜着出）；不按 W 就停在顶上。
- **取消翻越。** 翻越的前一半时间里松开 W（或按 S），人会退回起点并掉下去。
- **墙上松开 W。** 人贴着墙先减速再下滑，约 1 s 后自动脱离。这段时间里：
  - 按跳 = 蹬墙跳；
  - 按 S = 立刻脱离。
- **攀爬中按 A/D。** 沿墙面横向漂移。
- **Superglide。** 在翻越**最后约 0.1 s** 按跳，下一帧按住蹲：以 **460 u/s** 低空滑出。
  - 不按蹲只按跳：299 u/s 的翻越跳。
  - 按得太早：被"切"到墙顶，没有跳。
  - 推荐在 180 或 232 墙上练。也可以看 Demo 8 的时机。
- **请判断：**
  - 攀爬速度、翻越时长是否合理？
  - Superglide 窗口（0.1 s）是太紧还是太松？
  - 抓墙、翻越、superglide 的镜头提示是否清楚、不晕？

### I：Zipline（x 5900–11400）

- 站在绳子起点附近**看向绳子**，按 **X**：人被拉到绳下 80 u，0.5 s 内视角自动对准绳子方向，这段时间鼠标无效，之后可自由看。
- 速度先快速增加，1.25 s 左右到 600 u/s 封顶。到终点前约 90 u 自动脱离，以 600 u/s 冲出。
- 绳上按**跳**：脱离，水平最多 400 u/s，附带一次跳跃高度。绳上按**蹲**：直接松手。
- **Super Jump。** 上绳后 0.2 s 内先跳下、再按一次跳：跳得高很多，约高出 214 u。这个时间窗是设计值，可以反馈太紧或太松。
- 四根绳：

| 绳 | 位置 | 说明 |
|---|---|---|
| 平绳 | x 5900→7900 | |
| 上坡绳 | x 8100→9900 | 终点落到平台上 |
| 竖绳 | x 10600 | 一直爬到顶，出顶时朝视角方向推出，落到塔顶 |
| 高绳 | y 2300，z 420 | 只能用钩爪（技能组 1 的 Q）勾上去：勾中绳子后会自动转为滑绳，保留钩爪的速度 |

- 钩爪飞行或拉拽中**再按一次 Q**：立即松开，速度完全保留。
- 每次落地前最多上绳 3 次，每离绳 3 s 回复 1 次。
- **请判断：** 上绳是否容易对准（34° 视锥）？视角被拉的那 0.5 s 是否别扭？Super Jump 的时机能不能稳定按出来？
