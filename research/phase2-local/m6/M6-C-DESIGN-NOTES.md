# M6-C 设计备忘：组合玩法的强项、风险与下一步

依据：M6-A 实测模型（[M6-A-REPORT.md](M6-A-REPORT.md)、[unity/A1-A3-UNITY.md](unity/A1-A3-UNITY.md)）和 M6-C 组合练习场的实现与测试（[unity/M6C-UNITY.md](unity/M6C-UNITY.md)）。

证据标签沿用 M6：**[meas]** R5 实测；**[src]** 源码；**[design]** HSD 的设计值；**[course]** 本次在 Unity 练习场里由真实输入跑出来的数字（不是 R5 实测）。

## 1. 结论先行

- 最有表现力的组合是**「把高度换成速度、把速度换成方向」**的链：
  - zipline super jump（高度）→ lurch / tap strafe（方向）→ 翻越（落点）；
  - 攀爬翻越 → superglide（速度）→ lurch / 蹬墙（方向）。
  - 每一步都有一个**短时间窗**（super jump 0.2 s、superglide 0.1 s、蹬墙 0.1 s、lurch 0.5 s）。这正是技巧感的来源，也是最需要试玩校准的地方。
- 跨族交接（钩爪 → zipline、跳板 → 空中上绳、喷气 → 攀爬）在规则上已经**不会叠速**：
  - 绳速封顶 600；
  - 跳离水平封顶 400；
  - superglide 出口固定 460，stim 不叠加；
  - lurch 每次按键封顶 209；
  - 全局水平上限 900、向上 1100；
  - 两个驱动状态不会同时生效。
  - 随机测试 360 局、约 25 万秒级指令里没有一次越界（数字见 §4）。
- 最大的设计风险不在数值越界，而在**可读性和路线支配**：
  - Fun 配置的跳板 → 空中上绳太省事；
  - 竖直绳到顶的推出距离（约 580 u）难以预判；
  - 下坡滑铲几乎不加速，和玩家直觉不符。

## 2. 哪些组合最强、最有表现力（按实测模型推断）

| 组合 | 为什么强 | 练习场里的数字 [course] | 依据 |
|---|---|---|---|
| Zipline → super jump → 空中转向 → 翻越 | 唯一能从地面"凭身法"获得 200+ u 额外高度的手段；再用 lurch 改落点，用翻越吃掉最后 80 u | 起跳 vz 552，比跳下点高 266 u；lurch 拐 32°；翻上 320 高台（地面攀爬做不到） | super jump [meas，窗口为 design]，翻越 [fit] |
| 攀爬 → 翻越 → superglide | 从 150–232 的任何台子瞬间获得 460 u/s，是全系统最快的"无技能"出速 | 挡板 150：爬 0.17 s → 460 u/s；180 墙：穿过约 420 u/s 才能到的光环 | superglide 460 [meas，H232]，其他高度的窗口 [design] |
| 滑铲跳 → 蹬墙跳 → tap strafe | 不掉速的大角度转向：弹墙后 9 次 W 点按，转向 93–99°，速度保持 325–345 | 峡谷隔墙：99° | tap strafe [meas]、蹬墙 [meas] |
| 钩爪 → zipline 交接 → 跳离 → lurch | 钩爪的拉拽速度沿绳保留（387 u/s），跳离再接一次 lurch，路线连贯 | 交接 387 → 跳离 400 → lurch 32° | 交接 [meas，单几何]，跳离 [fit] |
| superglide → lurch → 蹬墙 | 460 出速后还能再拐一次再弹墙，组合深度高 | 460 → lurch 后 387 → 弹墙后 430 | lurch 封顶 [meas] |
| 喷气 + 攀爬（Valk） | 喷气先抬高，再爬墙翻越，能上 320 高台 | 喷气结束后才开始攀爬（两者从不同时驱动） | 规则 [design] |
| 跳板 → 空中上绳（Fun） | 一下子从地面到 500 高的索道，沿绳保留 494 u/s | 起飞 0.53 s 后上绳，绳速 ≤ 600 | 空中上绳 [design，R5 服务器拒绝] |

**值得注意的反直觉点（都已在测试里固定下来）：**

- **superglide 后马上 lurch 会掉速**：460 → 387。lurch 每次按键最多 209，而且方向改变会吃掉一部分前向速度（[meas] 的封顶规则）。
  - 玩家会在「转向」和「保速」之间取舍。这是好的张力，但需要在指南里讲清楚。
- **stim 不放大 superglide**：出口始终 460（姿态速度只看武器移动系数，不含 stim 加成）。R5 里是否如此**未测**。
- **钩爪上绳后不能 super jump**：super jump 要求从地面上绳（[meas] 条件）。测试里第二次跳被正确忽略。
- **下坡滑铲加速很少**：从 120 高的平台滑下 600 u 长的坡，速度仍从 438 衰减到 300。
  - 原因：坡面滑铲用的是设计值 slideSlopeGravityScale ×1，A4 未实测。
  - 所以隧道只能做成 200 u 长：从平台滑下来刚好能滑过；从平地冲刺起滑大约只滑 470 u。

## 3. 风险

### 3.1 可能的漏洞 / 支配路线

| 风险 | 现状 | 建议 |
|---|---|---|
| Fun 配置跳板 → 空中上绳 | 任何跳板附近的绳子都能"一键直达"。练习场里只放了一个跳板在索道下 | Fun 保留；正式玩法可以给空中上绳加条件（例如只允许在下落段、或只允许跳板后 1 s 内） |
| 竖直绳到顶推出过远 | 出口 vz = 绳速（约 550）+ 沿视角 400，水平飞行约 580 u。东塔加宽到 1050 u 才能稳定落在塔顶 | 竖直绳顶的推出量 400 是单几何实测；竖直出口速度是否应封顶需要 R5 补测 |
| 地图边界 | 随机测试中，喷气 / 钩爪 / Fun 重力 / 飞行能飞过 800 u 的边界墙（z 942、6853） | 已修：边界墙加高到 4000，并加了看不见的天花板 |
| 钩爪 3 s 拉拽保护超时 | 随机测试中偶尔触发：钩点在墙顶或天花板附近，身体被拉着贴墙，GAP 条件不满足 | 正常玩法很难遇到。可以考虑"贴墙且速度≈0 超过 0.3 s 就释放" |
| 跳板 6 s 效果保护超时 | 跳板起飞后被喷气 / 飞行 / 低重力 / 钩爪拖在空中超过 6 s | 属于保护机制按设计生效；如果正式玩法要长滞空，跳板效果应在接到别的驱动时提前结束 |
| 出生在实体里 | 练习场的复位点都验证过（不在实体内、在地面上）；但任意坐标的 ResetToPose 不检查 | 只影响开发工具（Demo / 测试），不影响玩家 |

### 3.2 可读性

- 时间窗都很短，而且**看不见**。super jump 0.2 s 从上绳开始算，不是从跳下开始算；superglide 0.1 s 从翻越结束倒推。
  - 建议：诊断 HUD 里已有状态；可以考虑在 Fun 配置加一个轻量的窗口提示（例如准星短暂变色）。
- 钩爪能勾住绳子，但绳子很细（半径 10），远处很难瞄。挑战门和指南里已说明。
- 34° 上绳视锥 + 0.5 s 视角锁定：上绳后鼠标无效 0.5 s，第一次玩可能以为卡住。
- 每段两种过法的视觉提示：站牌写明了每段的选择；检查点放大到能覆盖所有过法。

## 4. 支撑数据（随机测试，[course]）

练习场随机测试：2 配置 × 3 技能组，每组 60 局。每局 25 s 随机或扰动过的组合输入，加 10 s 空闲。共 360 局、151 万条指令（约 3.5 小时游戏时间）。

结果：

- 从未进入实体；
- 从未穿透；
- 从未越过速度上限（水平最大 867 < 900，向上最大 1027 < 1100）；
- 绳速从未超过 600；
- 跳离从未超过 400；
- 攀爬 / zipline 从未需要保护超时；
- 每局空闲后所有状态都已结束；
- 没有卡在绳或台边。

M5 技能自己的保护超时（钩爪 3 s、跳板 6 s、扑跃、喷气）在随机游玩里共触发若干次，原因见 §3.1。具体计数见 [unity/M6C-UNITY.md](unity/M6C-UNITY.md) §4。

## 5. 最需要试玩确认的设计值

按优先级：

1. **super jump 窗口 0.2 s**（R5 实测在 8–63 条指令之间）：能否稳定按出？
2. **superglide 窗口 0.1 s**，以及在 150 / 180 墙上（不是实测的 232）的手感。
3. **lurch 封顶和 superglide 后转向掉速**：是否觉得"被惩罚"？
4. **上绳视锥 34°、钩爪勾绳半径 10**：是否好瞄？
5. **竖直绳顶推出**：是否太远、太难控？
6. **坡面滑铲加速系数**：是否应该让下坡滑铲更快（A4 设计值）？
7. **Fun 空中上绳**：是否让其他路线失去意义？
8. **路线长度与检查点大小**（一圈地面路线约 81 s）。
9. 各段的镜头提示强度（沿用 M6-A，未调）。

## 6. 下一步建议

1. **先试玩**：用 F9 / F10 收集带状态的反馈（文件里有最近 3 s 的按键），按 §5 的问题逐条看。
2. **R5 补测**（每项 ≥ 5 次有效，按原则保留失败记录）：
   - super jump 窗口的边界（9–62 条指令之间）；
   - 150 / 180 高度的 superglide 窗口；
   - stim + superglide 出口速度；
   - 竖直绳顶出口速度；
   - 下坡 zipline；
   - 坡面滑铲。
3. **练习场工具**：
   - 每段分段计时；
   - 幽灵回放（把最好一圈的输入回放出来，和 Demo 一样走正常通道）；
   - 把练习场布局改为数据文件，方便试玩后快速调整。
4. **规则微调候选**（等试玩结论再做，先不改）：
   - 钩爪贴墙提前释放；
   - 跳板效果被其他驱动接管时提前结束；
   - 空中上绳的条件。
5. M6-B 的独特传奇位移（Alter / Loba / Ash / Valkyrie）可以直接放进这条练习场做组合验证：每段都有现成的"至少两种过法"结构可以对比。
