# M6-C 试玩指南：组合练习场（Combination Course）

构建：`HSD-Build\M6C\HSD-Practice.exe`。双击即可运行，窗口模式，1600×900。

- M5.5 和 M6-A 的内容全部保留：地图 A–E、M5 计时赛、M6 站点 F–I、镜头、20 个旧 Demo，数值不变。
- M6-C 新增的组合练习场在地图**南侧**（y −2600 … −1000），是一条往返环线。
- 旧版说明：[PLAYTEST-GUIDE-M6.md](PLAYTEST-GUIDE-M6.md)（M6 站点、按键细节）、[../m55/PLAYTEST-GUIDE-M55.md](../m55/PLAYTEST-GUIDE-M55.md)。

| **试玩反馈：写一条** | **F9**：暂停，弹出小窗，写一句话 + 打 1–5 分，回车保存，Esc 取消 |

屏幕下方的帮助栏里也有 F2 / F9 / F10 的提示（H 可隐藏）。

## 2. 进入练习场

- 按 **F2**，人物传送到练习场起点（西南角的广场），朝东。
- 屏幕上方显示 `[F2] M6-C course`、下一个检查点和「challenges 0/3」（挑战门计数）。
- 计时从离开起点圈开始。检查点是大圆盘，当前路线高亮；另一条路线的检查点是暗灰色。
- 再按 F2 回到 M5 路线。

## 3. 路线总览

环线：沿南侧车道往东（去程），在东端掉头，沿北侧车道往西（回程）。中间有一道隔墙（spine），两面都能蹬墙跳。

**每一段都至少有两种过法，检查点都很大，任何一种过法都能经过。** 下表中的「挑战」是可选的。

| 段 | 内容 | 过法（任选） |
|---|---|---|
| J 发射坡 + 滑铲隧道 | 坡道上去，120 高的平台，长下坡；坡底是一段 200 长、顶高 60 的隧道 | 从平台滑铲下坡，一路滑过隧道；或者从隧道旁边绕过；或者跳上隧道顶（翻越） |
| K 挡板峡谷 | 一块横跨整条车道的挡板，底下留 60 高的缝，顶高 150 | 滑铲钻过去；或者攀爬 + 翻越，在翻越最后约 0.1 s 按跳 + 蹲 = superglide（460 u/s）飞出去。隔墙可以蹬墙跳 |
| L Zip 场 | 一根上坡 Zipline 通往 250 高的平台；绳子旁边有一个 **320 高的高台** | 上绳直达平台；或者走南侧的坡道上平台；或者攀爬平台 |
| M 东塔 | 440 高、很宽的塔 | 塔西面的竖直 Zipline（到顶自动朝视角方向推出）；或者塔西侧的地图升降台（面朝塔走进去，自动弹到塔顶）；或者南面 240 高的台阶 → 再爬；或者技能（钩爪、喷气、扑跃） |
| N 高空索道 | 从塔顶往西的长下坡 Zipline（高度 520 → 400），地面够不着 | 在塔顶按 X 上绳；或者在地面用**钩爪**勾绳子（自动转成滑绳，保留速度）；Fun 配置下还可以踩绳下的**跳板**，在空中按 X 上绳。隔墙上方有三个钩爪锚点 |
| O Superglide 墙 | 180 高、60 厚的墙，挡住大半条车道；北侧留了绕行口 | 攀爬 + 翻越 + superglide 飞过去；或者从北侧绕过去 |
| P 蹬墙巷 | 北侧两段墙、南侧隔墙、一道缓坡脊 | 在两侧墙之间来回蹬墙跳、tap strafe 过弯；或者直接跑回广场终点 |

参考成绩：只用最慢的地面路线（绕隧道、钻挡板、走坡道、竖绳、高空索道、绕墙），一圈约 **81 s**（脚本实测 80.82 s，任何配置和技能组都一样）。用组合技可以明显更快。

## 4. 挑战门（可选）

金色标记，进入时在事件栏里记下 `CHALLENGE <名字> via <最近 4 s 用到的身法>`，屏幕上方的计数 +1。不进也不影响计时。

| 挑战 | 位置 | 设计意图 | 其他办法 |
|---|---|---|---|
| Super-jump perch（高台） | L 段 320 高台顶 | 上绳 → 0.15 s 跳下 → 0.2 s 内再按跳（super jump）→ 空中按 A + W（lurch 拐向高台）→ 自动翻上去。地面攀爬到 300 以上就够不着 | 钩爪；Valk 喷气 + 攀爬也能上去（已测） |
| Superglide ring（光环） | O 墙西侧的空中金框 | 正对墙 superglide（≈460 u/s）才能穿过；普通翻越跳（299）够不到 | 钩爪、跳板、喷气等 |
| High-line rider（索道） | N 段索道中段的金框 | 坐在高空索道上经过它 | 三种上绳方式都行 |

Demo 都是脚本按键走正常的输入通道（和你按键完全一样），结果按模拟记录判定。Demo 结束后人物停在原地，可以接着自己练。

## 6. 怎么写反馈（F9 / F10）

1. 觉得某个动作不对劲、太难、太容易、镜头不舒服时，**当场按 F9**。游戏暂停，记下按 F9 这一刻的状态。
2. 在小窗里写一句话（做了什么、期望什么、实际发生了什么），点 1–5 分（可不打分），回车保存。Esc 放弃。
3. 来不及写就按 **F10**：立刻保存一份快照，不打断。
4. 文件保存在游戏 exe 旁边的 `Feedback\` 文件夹里，每次两份：
   - `feedback_<时间>.json`：完整数据；
   - `feedback_<时间>.md`：可直接阅读的摘要。
5. 快照内容：时间、配置、技能组、计时路线和成绩、最近的站点、位置 / 速度 / 视角、地面·滑铲·蹲状态、攀爬 / Zipline / 钩爪 / 喷气 / 技能格状态、最近 16 条事件、**最近 3 s 每条指令的按键**（压缩成「按键 × 指令数」）、镜头设置、HUD 模式、鼠标灵敏度、你写的话和评分。
6. 试玩结束后把整个 `Feedback\` 文件夹发回来即可。屏幕上方会短暂提示保存到哪个文件。

## 7. 最想听的反馈

- 每段的两种过法是否都有吸引力？有没有哪条明显没人会走？
- 高台挑战（super jump 0.2 s 窗口 + 空中转向 + 翻越）是否能稳定做出来？窗口太紧还是太松？
- Superglide 光环的距离（需要约 420 u/s）是否合适？0.1 s 的 superglide 窗口在 150 / 180 墙上手感如何？
- 竖直 Zipline 到顶会被推出很远（约 580 u），是否意外或难控？
- 钩爪勾高空索道是否容易瞄准（绳子半径 10）？交接后的速度是否自然？
- 下坡滑铲加速很少（坡面滑铲是设计值）：是否希望下坡更「冲」？
- Fun 配置的跳板 → 空中上绳是否太强、让其他路线没有意义？
- 计时赛一圈的长度和节奏。
