# M6：高级身法与独特位移扩展（用户计划，2026-10-21）

本文件是用户给出的 M6 正式计划的存档（要点逐条保留）。执行记录见仓库根目录 `EXECUTION-LOG.md`，差异审计见 [M6-AUDIT.md](M6-AUDIT.md)。

## 总体目标

在 M0–M5.5 基础上扩大移动自由度、身法深度与技能组合空间：

1. **通用高级身法**：补齐 S21 时期高频、实用、配套价值高的 Movement 机制，在 Unity 中可真实操作、自由组合。
2. **独特传奇位移能力**：研究显著改变移动或空间通行方式的技能，优先独特性和玩法潜力。

暂不做完整战斗，不追求复刻所有身法或全部传奇。目标不是 Apex 模拟器，而是高度自由、可扩展、爽快的运动系统。

## M6-A 通用高级身法（第一优先级）

- **A1 连续 Lurch / Tap Strafe**：多次方向输入与 Lurch Stack；完整 Tap Strafe + 视角转向；与滑跳、墙跳、落地衔接；不同速度/输入下的触发规则。建立通用控制逻辑，不为每个社区命名变体单写机制。
- **A2 攀爬、抓边、翻越**：攀爬、抓边、翻越、取消翻越；不同高度/形状障碍；墙跳与攀爬/翻越衔接；Mantle Boost / Superglide 的触发与退出。需在真实操作与场景交互层面验证。
- **A3 Zipline**：挂绳、乘坐、跳离、重新交互、基础 Super Jump；视验证扩展 Elite Jump 等。调查 Pathfinder 钩爪附着 Zipline 后的状态交接（已知能钩中水平绳中段，**未验证**能否进入乘绳状态，不得混淆）。
- **A4 底层补全**：按需补坡面、边缘、墙面法线、状态切换、必要碰撞。

## M6-C 组合玩法与练习场

接入运动核心与技能槽；灰盒环境；至少验证：

- 滑跳 → 墙跳 → Tap Strafe
- 攀爬 → 翻越 → 加速离开
- Zipline → Super Jump → 空中转向
- 钩爪释放 → 空中调整 → 落地滑铲

不得用预设动画或改位置伪造；动作由真实输入、状态转换、运动规则产生，允许不同路线与搭配。

## 原则

实用优先；机制优先于名称；实测优先（关键条件 ≥ 5 次有效、有对照、保存失败记录）；不盲目追求精确（止损）；保护 M5.5（运动、镜头、输入、HUD、回归稳定，经已有接口扩展）；模块化（运动/技能/环境交互/角色能力不互相硬编码）；不夸大社区证据。

## 验收

- **M6-A**：三个核心家族可玩；独立验证 + 自动回归；M5.5 无重大回归；≥ 3 条代表性动作链由真实输入完成；Windows 试玩构建 + 练习路线。
- **M6-B**：四项技能各有独立结论；区分已测 / 源码支持 / 历史资料 / 未解决；独特性、开发成本、原语复用、组合潜力对比；不擅自全量制作。
- **M6-C**：已选机制自然组合；无异常状态、无法退出、错误叠速、严重碰撞；玩家自由完成而非脚本回放；试玩反馈入口与下一阶段建议。
