# M9-C 试玩指南：Vantage（Echo 位移）

构建：`HSD-Build\M9C\HSD-Practice.exe`。技术说明见 [unity/M9C-UNITY.md](unity/M9C-UNITY.md)。只做 S21 的行为：S22 去掉视线限制、Echo dash、Echo TS、Echolevator 都是后来的，没有做。

> **验收状态（三类分开）**
> - 「数值/规则测试通过」：Echo 放置、轻按/按住规则、1.82 秒起飞、60° 和视线门槛、位移轨迹（和 R5 的 400/800/1200 u 轨迹对照）、追踪移动目标、下蹲 ×0.8、撞墙停止、末端二段跳（窗口和速度）都有单元测试；旧回放、旧演示、M5 路线、赛道单圈都没变。
> - 「真实按键演示通过」：7 个 M9-C 演示（F6 面板里 `m9c_` 开头）成功版和失败版都按预期。
> - 「真人手感未验收」：还没人玩过。下面标【设计值】的都等你的反馈。

## 怎么选

- **`=` 键**：切到新的 **Vantage** 预设（只有战术技能，Q 键）。演示面板打开时 `=` 是调时间偏移，先关面板。
- **Tab / F1**：Reference（R5 实测）和 Fun 切换。两者的 Echo 和位移一样，只有一点不同：Fun 里末端二段跳之后可以接 Lurch/TS【设计值】。
- 训练区 **VE**：在 D 区塔楼的南边（x 7300–10000，y −950…−360）。

## 操作

- **轻按 Q**（0.3 秒内松开）：Echo 沿准星飞出去，碰到东西就停在前面一点，最远 1968.5 u（50 米，本地构建实测）；它至少悬停在地面上方 246 u。再轻按一次 = 从当前位置改去新地点。**E** = 立刻召回。轻按不花次数，冷却中也能用。
- **按住 Q**（超过 0.3 秒）：**按下后固定 1.82 秒起飞**，不管按多久（不是蓄力）。Echo 还在肩上时按住 = 放出去并起飞（1.66 秒）。
- **起飞条件**（起飞前约 0.2 秒检查）：Echo 在视野 60° 以内，而且视线没被挡住。没有距离限制。不满足就取消，**不扣次数**。准星下面会提示「不在视野 60° 内」或「视线被挡」。
- **位移**：943 u/s 起飞，慢慢降到约 787；最后约 180 u 开始刹车，**会穿过 Echo 继续往前**，落在 Echo 后面一点。Echo 在动会跟着拐。撞墙就停在墙面。
- **下蹲**：位移中按蹲 = 速度 ×0.8 立刻退出，之后正常下落；一直按住蹲，落地会滑铲。
- **末端二段跳**：刹车阶段（离 Echo 约 180 u 以内，一直到位移结束）按**空格**：速度换成约 500 往前、394 往上。准星下面出现「二段跳窗口：空格」就是能按的时候。【设计值】窗口什么时候关。
- 和通用二段跳（Fun）、Octane 跳板二段跳互不占用；起飞会清掉没用掉的跳板二段跳（源码行为）。

## 训练区 VE

| 位置 | 练什么 |
|---|---|
| 东西向的道（起点砖在西端，每 250 一条线，砖在 500 / 1000 / 1500 / 1968.5） | 平视轻按：Echo 停在最远那块砖上方；按住 Q 起飞，落在 Echo 后面。起点砖两边的小点 = 60° 视野边界：放好 Echo 后转身 50° 还能起飞，转 70° 就不行 |
| 道北边三根柱子（高 120 / 300 / 500） | 瞄柱顶：Echo 悬停在柱顶上方；站在第 2、3 根柱子之间瞄第 3 根的侧面：Echo 贴在墙前，位移撞墙停下 |
| 东头的地面长条（会动的目标） | 从西边 1000 u 的小砖上把准星落在长条上轻按：Echo 在长条上方来回移动（200 u/s，【设计值】训练用）；按住 Q，位移会追着它 |
| 西南角的短墙（400 高） | 站 A 砖（墙北头外侧）把 Echo 放到墙后的砖上，按住 Q 能起飞；走到 B 砖（墙正后方）再按住：视线被挡，起飞取消 |

## 同时改了的旧东西（都有 R5 数据）

- **滑铲后的 SG**：滑铲加速要约 1.8 秒才恢复（R5：滑铲跳接近 0/5，滑铲 0.75 秒后起跳 0/5，1.25 秒后 5/5）。现在滑铲跳接近时按 SG 只会得到普通翻越跳（约 299），不会到 460。两种配置都是这样。
- **Revenant 攀爬**：A/D 横移约 161 u/s（R5 实测）；按 S 立刻脱离；攀爬中按空格（按住 W）只是停止攀爬、不弹出，约 0.9 秒后可以重新贴墙（R5 实测）。Fun 仍是墙面弹射【设计值】。
- 上坡滑铲、跳板二段跳后的 Lurch 上限：和 R5 对上了，没改。
- 跳板发射本身在 Reference 里还能接 Lurch（R5 实测不能）：这一条**没改**，等你决定（M5.5 的 pad → lurch 演示依赖它）。

## 想听你的反馈

1. 1.82 秒的起飞等待是否太长（这是实测值，S21 就这么长）。
2. 末端二段跳的时机好不好按；窗口什么时候关比较舒服。
3. 位移的弧线和落点感觉像不像。
4. 准星下的提示、Echo 小球和连线是否清楚。
