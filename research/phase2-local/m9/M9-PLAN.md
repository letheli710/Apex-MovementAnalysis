# M9：Apex Movement 复刻深化、传奇能力扩展与操作训练（用户计划，2026-10-22）

本文件存档用户的 M9 计划，要点逐条保留。基线：HSD-Unity main `2ea2a4f`（M8 全部合并）；研究仓库 main `02eedca`。执行记录见 `EXECUTION-LOG.md`；延期设计决策见仓库根目录 `DEFERRED-DESIGN-TODO.md`。

## 总目标和原则
- 继续复刻 S21 的运动机制、高级身法和传奇机动能力，同时提高真实玩家的可操作性、可学习性和复现成功率。
- 严格区分五类来源：官方历史 S21、本地 R5Flowstate 混合构建、后期 Apex、社区技巧、设计值。
- 建立完整、独立、可配置的能力库，不提前绑定角色装备规则。
- 机制正确、容易研究、可以实际操作优先；边缘参数不无限投入逆向工程。"够像就行，不需要完全一模一样。"
- 可以并行使用多个 Subagent，但遵守单实例控制和 Git 分支隔离。
- 结果分三类：
  1. 数值和规则测试通过；
  2. 真实按键演示通过；
  3. 真人手感通过或尚未验收。
  脚本成功不代表手感通过。

## M9-A：Zipline 交互补全与高级身法训练
- **A1 中途挂绳**：
  - 用户在试玩中发现：似乎只能在绳索起点或终点挂绳；站在绳索中段很难上绳；中途下绳后无法从中途重新挂载。钩爪可以在中段钩中并交接。用户记得 Apex 允许在中段正常上下、离开和重新接入，交互范围也没这么苛刻。
  - **不要预设是操作还是代码的问题**：先用 R5 实测、源码和社区资料确定正确行为，再修复 Unity。
  - 调查：水平和垂直绳的中途挂载；站在中间或从空中接近时的条件；垂直绳中途向上/向下的方向判定，能否中途改变方向；跳离后重挂、快速连续挂、空中重新交互；端点与中段的交互距离、视角、目标选择和判定范围；和 Lurch、跑墙、滑铲、钩爪、二段跳的衔接；Zipline Super Jump、Mid Air Interact 等技巧。
  - 优先本地 R5 实测，测不了再查历史教程、视频和源码；不把现版 Wiki 直接当作 S21 规则。资料入口：apexmovement.tech。
- **A2 高手实际操作研究**：
  - 来源：Apex Movement Wiki、r/Apexrollouts、Mokeysniper、Zeddo（Lurch/TS）、Xzylas、Treeree 等。
  - 重点技巧：Bunny Hop、TS、Wall Bounce、SG、LS、RAS、Zipline 高级技巧、传奇专属 Movement。
  - 每项尽量记录：按键顺序（按下/释放/按住的时机）、鼠标方向和转速时机、是否需要滚轮或特殊设置或设备、起始速度/状态/地形/角度限制、时间窗口和典型失败原因、能否衔接、视频里的键盘 Overlay 和慢动作、S21 或之前是否存在、后期有没有变化。
  - LS/RS：前后回旋、反向折返、蛇形、OG Ras Strafe。M8 测到的反向 Lurch 约 156° 是特定高速条件下的结果，**不能扩大成所有初速度和操作方式的绝对极限**，要按原作者操作在不同条件下核验。
  - 建立可追溯的资料库：作者、链接、发布时间、视频时间戳、操作方式、版本、证据等级。**没看过的视频不能声称逐帧分析；没有完整输入证据的技巧不能编造操作序列。**
- **A3 对照教程验证 Unity**：
  - 同样的输入能否产生和本地 R5 相符的轨迹；
  - 区分四类原因：物理模型缺失、输入条件错误、时间窗口过窄、玩家失误；
  - LS/RAS、SG 变体、墙跳变体、Zipline 高级操作做专项测试；
  - 已有机制能自然做出的只补验证；**不为让某个视频动作成功而改 Reference 实测模型。**

## M9-B：Revenant 完整机动
- **B1 Shadow Pounce**：
  - 核验蓄力时间、发射速度、方向和视角的关系；
  - 测不同俯仰角、起始速度、蓄力状态；
  - 测主动释放、取消、碰撞、着地恢复；
  - 组合：扑跃 → 滑铲、扑跃 → 空中变向、扑跃 → 墙面运动；
  - 研究社区高手的真实输入。
- **B2 长攀爬**：
  - 参考 M8 的 800 u 结果，补测并实现更高墙体上的连续攀爬；
  - 区分普通传奇和 Revenant 的参数、状态和结束条件；
  - 研究攀爬中的横向移动、障碍、顶部翻越、主动退出；
  - 扑跃后约 0.75 秒禁爬，以及禁爬和墙跳、普通攀爬、跑墙的仲裁；
  - 不能用特殊角色参数破坏通用攀爬系统。
- **B3**：专项训练区和真实按键演示；Reference 和 Fun 分开；关键参数优先用本地 R5 实测，不确定的标为设计值。
