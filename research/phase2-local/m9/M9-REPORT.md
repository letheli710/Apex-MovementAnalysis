## 完成清单

### M9-A Zipline 与身法训练
- [x] **A1 中途挂绳**：先在 R5 实测，再在 Unity 里复现，最后修复。
  - **R5 实测**（`r_zip/`，约 1000 个试次）：
    - 绳上任意位置都能挂（视线锥 33.2–35.9°，绳在约 120 u 以内）；
    - 空中挂绳可以，65/65；
    - 下绳后约 0.35 秒内不能在空中重挂，从地面重挂立即生效；
    - 终点附近不拒绝，而是反向滑走；
    - 落地前地面挂一次之后，空中最多再挂 2 次；
    - Super Jump 第二次按键的窗口约 0.2 秒；
    - 跳离不会打开 Lurch 窗口。
  - **你遇到的问题的原因**：
    1. Reference 拒绝所有空中挂绳，这是 M6 根据一次距离不够的测试定的错误规则；
    2. M8-A 加的终点拒绝；
    3. 地图上斜绳除了前段都超出站立可及的高度（R5 同样够不到）；
    4. 没有挂绳提示。
  - **已修复**：Reference 按实测改正；新增挂绳提示（抓握点绿球、方向箭头、拒绝原因）；新增训练区 Z。
- [x] **A2 身法资料库**（`d_library/TECHNIQUE-LIBRARY.md`）：
  - 每条记录作者、链接、发布时间、时间戳和证据等级（A/B/C/实测/矛盾）；
  - Wiki 的 101 个页面是全文读取的；**没有观看任何视频**，视频列在"待看"清单里，附章节时间戳；
  - 没有编造任何按键序列；
  - 整理了 20 条可复现实验规格。
- [x] **A3 对照验证**：
  - Zipline 技巧 R-11 到 R-17 全部和 R5 一致。
  - 反向 Lurch 链改用实测值：走路 162.4°、冲刺 157.6°、滑铲跳 144.7°、OG Ras 162°。Unity 和这些值相差都在 3° 以内，Reference 的 Lurch 模型没有改。
  - **结论：156° 不是上限**，它只是某一种条件下的结果。

### M9-B Revenant
- [x] **B1 扑跃**：
  - 公式在俯仰、蓄力、起速的整个测试网格上都和 R5 完全吻合（最大误差 1.6 u/s，n 215）；
  - 发射后 0.85 秒内不能爬墙、跑墙、抓边（源码 0.75 秒加一个服务器帧，R5 实测 0.84–0.89 秒）；
  - 扑跃后不打开 Lurch 窗口；扑跃中按跳仍可以 Tap Strafe；
  - R5 里找不到取消扑跃的输入。
- [x] **B2 长攀爬**：
  - 做成按角色的攀爬参数，其他角色逐位不变；
  - 速度曲线和 R5 一致，300/500/800/1200 墙都能爬到顶翻上去；
  - 攀爬中按 A/D 横移约 161 u/s，按 S 立即脱离，按住 W 再按跳等于松手（均为实测）；
  - **结束规则是设计值**：R5 在光滑高墙上测不了（找不到能站人的高墙），止损。
- [x] **B3**：训练区 Y、单独的 Revenant 配置（游戏内按 `-`）、7 个演示。

### M9-C Vantage
- [x] **Echo**：
  - 按一下技能键，Echo 飞到准星指向的位置，最远 1968.5 u（实测）；按 E 召回（按键是设计值）；

  - 起飞速度 943，逐渐降到约 787；距离目标 180 u 内开始减速；路径穿过目标，不会停在目标点；

### M9-D
- [x] **D1 四项全部结案**：
  - **90 u 翻越时长**：不是模型差异。0.531 秒是测试时在离墙 30 u 起跳造成的；按 R5 的方式起跳，Unity 0.412 秒，R5 0.418 秒。
  - **滑铲跳接近时做不出 SG**：R5 查清是滑铲加速状态还没恢复（滑铲结束 0.5 秒后 0/5，1 秒以上 5/5）。Unity 已改为滑铲加速 1.8 秒后才能再次触发（落在实测区间 1.59–2.09 秒内）。
  - **跳板二跳后的 Lurch 上限**：M8 测到的 212.55 混进了空中加速分量，扣掉后是 209.05，和普通跳一样。Unity 的 209.3 本来就是对的，不改。
  - **上坡滑铲**：R5 补测 30° 坡，减速 −322 u/s²；Unity 不改代码就是 −323.8，已吻合。Fun 的斜坡模型没有动（E2）。
- [x] **D2 候选库**（`D2-CANDIDATES.md`）：S21 结束时在册的 26 位传奇逐个标状态，另附历史来源表。

## 遗留问题
- **真人手感**：全部未验收。
- **Revenant**：
  - 长攀爬的结束规则是设计值（R5 止损）；
  - 禁爬期间 R5 没有出现墙跳，但那组对照试次无效，Unity 保留 M5 的墙跳规则。
- **Zipline**：
  - 垂直绳往下看时挂绳：本地客户端和服务器表现不一致，S21 真实行为未知，Reference 先拒绝（设计值）；
  - 80 u 高的绳 Unity 能挂，R5 不能，原因不明；
  - 空中重挂的冷却 R5 是 0.33–0.40 秒，Unity 统一用 0.35 秒；
  - 重挂次数用完后 3 秒恢复一次，没测。
- **Vantage**：
  - 末端跳窗口的打开点：数据有两种解读，115 u 或 180 u，Unity 用 180（[inf]），参数可调；
  - Echo 没有 AI，没有待机漂浮；
  - 轨迹最高点比 R5 低 10–20 u。
- **Lurch**：
  - Unity 的输入层表达不了同时按住 A+D 或 W+S，所以三键组合（R-1a、R-2）做不出来，要改输入表示；
  - **跳板发射后，Unity Reference 会打开 Lurch 窗口，R5 实测不会。** 没有改，因为 M5.5 你验收过的 `pad_lurch` 演示依赖这个行为。是否按实测改，需要你决定。
- **滑铲**：
  - R5 在滑铲 0.25 秒时起跳，出口速度 397；Unity 的滑铲加速退还窗口给出 236。这一项涉及回放，只记录没有改；
  - Unity 松开下蹲不会结束滑铲，R5 会。
- **没测的项**：兔跳以 450/600 入速时的减速规则（R-10）、Momentum Shift 转镜头的情况（R-4，实验设计失误）。
