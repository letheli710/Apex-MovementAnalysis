## 完成清单

### 第一阶段（M8-A）
- [x] **1 输入冲突**：
  - 做了统一的跳跃键仲裁层（`JumpArbitration`）。爬墙、抓边、Zipline、跑墙、墙跳直接接管按键；二段跳和喷气先申请，等跳板、钩爪等发射和驱动都确定后才裁决，生效时才扣资源。
  - 每次按键最多一个效果，被拒绝时不扣任何东西。
  - 修复了 M7-A 遗留的"跳板和二段跳同帧时二段跳被白扣"。
  - 同帧、提前一帧、延后一帧、长按、连按都有测试。
- [x] **2 斜坡滑铲**：
  - Fun 配置里是设计值模型，下坡获得的速度受下降高度换算的能量上限约束，刷不出无限速度。
  - Reference 按 R5 实测，只在按住下蹲时有坡面加速。
  - 新增 10°/20°/30° 坡和一条连续变坡链。
- [x] **3 Zipline**：系统测试了全部列出的情况，修了两个真缺陷：
  - 在终点区挂绳会从静止被弹到 600 u/s；
  - Fun 配置下空中挂绳会额外抬高 22 u，反复挂绳能叠高度。

### 第二阶段（M8-B）

### 第三阶段（M8-C）
- [x] **8 Octane 跳板二段跳**：
  - Reference 用 R5 实测：发射后 0.108 秒才给，只能用一次，必须重新按；竖直方向 +201.81 或直接设成 409.25；水平方向朝按键改向 240。
  - 单独做成一个能力，和通用二段跳分开。两者都开启时跳板二段跳优先，通用二段跳不扣次数。
  - Octane 配置里两套都有，游戏里按 `5` 开关。
- [x] **9 Horizon**：
  - 升梯原来就和实测一致（0.5 秒后弹出 400/450，侧面出去拿到完整弹射力，没有顶部跳跃加成）。
  - 补了停留很短时弹射力按比例缩小的规则。
  - 修了一个缺陷：弹出后错误地打开 Lurch 窗口，导致按后退 0.36 秒就能反转弹射。实测是 0.61 秒，Reference 已改正。
  - 软着陆是真实的运动差别（R5 实测 Horizon 落地不减速，普通角色落地停住），已经核对。

## 第 10 项：R2 可行性探针结果（本地 R5，Leader 重跑分析一致）

- **Revenant 长攀爬：可行。**
  - 300/500/800 高的墙都能翻上去，同一面墙上 Gibraltar 会掉下来。
  - 速度曲线可以拟合：峰值约 226，之后线性减速。
  - 扑跃后墙面攀爬锁 0.75 秒得到证实。
  - 长攀爬到底怎么结束还没定（测试墙是叠石头搭的，接缝会干扰），Unity 实现需要一个设计值。
  - 数据在 [r2_revenant/](r2_revenant/)。
- **Vantage 的 Echo 喷射位移：可行。**
  - 真实技能和服务器脚本两种方式都能触发。
  - 起飞速度 943，之后巡航约 787，路径会穿过目标并追踪移动目标；到达附近按跳会接一次跳跃（向上 394、水平约 500）；按下蹲会把速度乘 0.8 并结束位移。
  - 数据在 [r2_vantage/](r2_vantage/)。
- **Sparrow 墙面弹射：存在。** 爬墙时按跳：向上 670.82（正好升高 300）、向外 442.8；同样的输入 Gibraltar 只是普通墙跳。数据在 [r2_revenant/](r2_revenant/)。

**下一批推荐：**
1. **Revenant 整套**：长攀爬、扑跃锁、Sparrow 式弹射。复用现有攀爬，Unity 工作量小；还需要约 1 个会话定结束规则。
2. **Vantage Echo 喷射位移**：会追踪移动目标的可控飞行，到达后接一次跳跃。Unity 工作量中等，约 1–2 天，还需要约 1 个会话补测。
3. **动态钩爪锚点**：Vantage 已经证明位移可以追踪移动实体，可以复用；但移动平台支持要另外设计。

## 未完成和遗留问题

- **真人手感**：全部没有验收。
- **没有跳跃输入缓冲**：早按一帧，在 Reference 下这次按键会被丢掉，在 Fun 下会变成二段跳。要不要加缓冲需要你判断。
- **Fun 斜坡滑铲比 R5 实测快约 1.6 倍**：保留为设计值，改 `downhillFriction` 一个参数就能贴近实测。
- **跳板二段跳**：
  - 二跳那一帧同时按方向键时的 R5 结果没有建模；
  - 二跳后 Lurch 上限 R5 是 212.55，Unity 仍用 209.3；
  - 地图上的跳板只给 Octane 配置这个二段跳，R5 里任何人都能拿到；
  - 两种二段跳能否同时装备还没定。
- **Superglide**：
  - Unity 允许滑铲跳接近时做 SG，R5 是 0/15；
  - R5 走路接近时出口 402，原因不明（后来解释：原生 `Jump` 的 +30 u/s，见 `rea-native/n11/N11-OPEN-ITEMS.md`）；
  - Unity 在 90 墙高的翻越用 0.531 秒，R5 是 0.418 秒。
- **Lurch**：按住一个键再按另一个键时，R5 在第一帧有 11.6 u/s 的残差，没有建模。
- **斜坡**：上坡滑铲和坡面边缘都没有实测。
- **Horizon**：2 秒内重新进入升梯、升梯 10 秒到期弹出，都没有建模。
- **Zipline**：从背后空中挂绳，约 0.2 秒内的方向混合不自然。
- **试玩**：Lurch 演示里的连按频率需要滚轮绑定才做得到（HSD 只提供公平输入，是否加辅助要你决定）。
