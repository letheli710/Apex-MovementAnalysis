# M8-B 试玩指南：兔跳、Lurch / 空中变向、Superglide 与墙面长链

构建：`HSD-Build\M8B\HSD-Practice.exe`。技术说明：[unity/M8B-UNITY.md](unity/M8B-UNITY.md)。

> **验收状态**
> - **「数值通过」**：下面每个技巧都有真实按键演示（F6 → 选 `m8b_…`），成功条件和失败对照都由自动测试检查；R5 回放全部逐字节一致。
> - **「真人手感未验收」**：还没人实际玩过。手感、按键时机是否合理、长链难度，都要你来判断。
> - 标 **[design]** 的是 HSD 自定数值，不是 Apex 数据；标 **[实测]** 的来自本地 R5 测量（含本轮 track R）；标 **[模型]** 的是用实测模型推出来的，R5 里没直接测过。

按键：WASD 移动，Shift 冲刺，Ctrl/C 蹲（滑铲），空格跳，X 使用（Zipline），Q 钩爪（Pathfinder），滚轮 = W 点按（tap strafe）。Tab 切 Reference / Fun。F6 打开演示面板，可以把关键按键前后挪动看失败情况。

## 1 兔跳（Reference 和 Fun 都有）[实测机制]

| 技巧 | 怎么按 | 在哪练 | 看什么 |
|---|---|---|---|
| 兔跳 | 按住 W + Shift，起跳；**落地那一帧**再按空格（演示 `m8b_bhop`） | B 区（跳跃 / tap strafe 场） | 每跳都保持 299，**不会超过 299**（地面起跳最多保留 299）。早按一帧（还在空中）这一下会被吞掉，链条断（没有跳跃缓冲） |
| 滑铲兔跳 | 冲刺 → 蹲下滑铲 → 0.4 s 后滑铲跳（350）→ **一直按住蹲**，每次落地那一帧再跳（`m8b_slidehop`） | B 区 | 每跳都保持 350（落地恢复的滑铲起跳不减速）；晚 0.25 s 起跳，每跳被滑铲摩擦吃掉 ~50 |
| 滑铲跳 ↔ 兔跳 ↔ 落地接滑 | 滑铲跳后**松开蹲**落地、立刻跳（变成 299），空中**再按住蹲**，落地接滑再跳（`m8b_hop_chain`） | B 区 | 第二跳被限到 299；落地能接上滑铲，滑铲跳保持 299 |

要判断：
- 连跳高度只有正常的 30%（落地 0.15 s 内起跳，[实测]），节奏约 0.42 s 一跳，手感是否 OK。
- **Fun 下早按空格（落地前一点点）会变成二段跳**，而不是兔跳。要不要加"落地缓冲"需要你决定。

## 2 Lurch / Tap strafe / 空中变向

规则（[实测]）：起跳后 0.5 s 内每按下一个方向键都会 lurch（0.2 s 内全力，之后线性减弱）；每次最多改变速度 209.3；**只有跳跃会开窗口**（地面跳、滑铲跳、蹬墙跳、Zipline 跳离、Superglide；Fun 的二段跳、跑墙跳也算）。走下台阶、钩爪松开**不开窗口**。

| 技巧 | 怎么按 | 看什么 | 证据 |
|---|---|---|---|
| Tap strafe 720°/s（`m8b_ts_720`） | 冲刺起跳，松 W，每两帧点一下 W（滚轮），0.25 s 内把视角转 180° | 轨迹转 ~166°，速度不掉 | R5 实测 −161°（track R）；Unity 166° |
| 纯按键折返（`m8b_ras_reverse`） | **走路**（不冲刺）起跳，松 W，依次按 D、D+S、S，各隔 0.05 s，视角不动 | 折返 ~162°，保持 98% 速度 | [模型]；R5 实测同类链条最多 156°（冲刺），**180° 保速折返 R5 做不到** |
| 蛇形（`m8b_snake`） | 起跳后连点 W，视角左 → 右 → 左摆 | 轨迹跟着视角左右摆，速度不掉 | [模型] |
| 钩爪松开后转向（`m8b_grapple_lurch`，Fun） | 钩爪 → 再按 Q 松开 → 空中按空格（二段跳）→ 0.1 s 后点 A | 二段跳后能 lurch；**没跳就点 A 不会转** | 规则 [实测]，二段跳 [design] |
| 按住 A 再按 W | 起跳前按住 A，空中再按 W | 向 W+A 斜 45° lurch；按住 A 再按 D（反向）不会 lurch | [实测] |

要判断：快速连点的节奏人手能不能做到（演示用的是 60 Hz 点按，相当于滚轮）。

## 3 Superglide [实测为主]

规则：翻越（mantle）最后 **≈0.085 s 内**按空格，**下一帧按住蹲**：460 u/s。早于 ~0.12 s 按会把翻越截断（不起跳）；蹲晚一帧只有 299 的翻越跳。所有高度（90–232）都是 460 [实测]。

| 技巧 | 怎么按 | 在哪练 | 看什么 |
|---|---|---|---|
| 基础 SG | 冲刺，跳向矮墙按住 W，翻越快结束时空格 + 下一帧蹲 | H 区（60/120/180/232/300 墙） | 460 |
| 斜向 SG（`m8b_sg_angle`） | 视角偏墙面 30° 冲过去做 SG | H 区 120 墙 | 沿视角方向（30°）离开，460 [实测 15/15] |
| SG → tap strafe（`m8b_sg_tapstrafe`） | SG 后 0.1 s 松 W 点 A | H 区 180 墙 | 全力 lurch（转 27°；460 下大角度 lurch 会被 209.3 限幅吃掉一些速度） |
| SG → 落地接滑（`m8b_sg_slide`） | SG 后空中松蹲，落地前再按住蹲 | H 区 180 墙后面 | 落地滑铲保持 460 |
| 横向 SG（`m8b_sg_lateral`，**Fun，[design]**） | 翻越前半段按 W，后半段换成 A（不要太早松 W，否则翻越取消），再空格 + 蹲 | H 区 180 墙 | 沿 A 方向 460 离开。R5 里只测了按住 W+D 的情况，只按侧键未测，所以 Reference 里只按侧键 = 原地翻越跳 |

注意（Reference，[实测]）：**走路接近不能 SG**（离开速度 199.5 < 200，蹲不出滑铲）。R5 里滑铲跳接近也 0/15（原因推测是滑铲加速没重新充能，Unity 未建模，会 SG 成功，见差距）。

## 4 墙面长链（Fun，全部 [design]）

练习场：**X 区链条场**（M5 终点平台北边，接 M7 跑墙走廊 S）。

| 长链 | 怎么按（大致时机） | 看什么 |
|---|---|---|
| 下坡滑铲 → 滑铲跳 → Lurch → 跑墙 → 跳离 → 二段跳（`m8b_chain_slope`） | 在终点平台向北冲刺，边缘按蹲滑下坡道；到走廊口滑铲跳，0.25 s 后点 A 贴到西墙（按住 W：跑墙），空格跳离，再空格二段跳 | 坡道加速 404 → 540，跑墙 → 444 跳离 → 二段跳 |
| 钩爪 → 落地滑铲 → 滑铲跳 → Lurch → 跑墙 → 下墙蹬墙跳 → tap strafe（`m8b_chain_grapple`） | 在平台上对吊着的方块按 Q，约 0.85 s 后再按 Q 松开并按住蹲；落地滑行，到走廊口滑铲跳 + 点 A 上墙；跑墙 0.2 s 后按蹲下墙、**立刻**空格（还贴着墙：就是实测的蹬墙跳）；然后连点 W 转视角 | 蹬墙跳 345 → 458，之后 10 次 lurch |
| Zipline → 跳离 → Lurch → 跑墙 → 转向矮墙 → 翻上（`m8b_chain_zip`） | 走到平台北边绳子下按 X，骑到走廊西墙外侧附近空格跳离，马上点 D 贴墙（按住 W 跑墙），跑过 y 2100（墙变矮 200）后把视角转向墙 | 爬墙 → 翻上 200 高的矮墙 |

已知做不到：**Zipline → Super Jump → 跑墙**。Super Jump 的水平速度不到 100，跑墙需要沿墙 ≥ 200 [design]。所以第三条链用普通跳离（400）。要不要放宽，需要你判断。

## 5 请重点反馈

1. 兔跳 / 滑铲兔跳的节奏和 30% 跳高是否舒服；Fun 下早按变二段跳是否烦人。
2. Tap strafe 和纯按键折返的难度；快速点按是否需要辅助（公平性问题，暂不做）。
3. Superglide 的时机窗口（0.085 s + 下一帧蹲）是否太苛刻；横向 SG（Fun）手感。
4. 三条长链的难度、跑墙接入角度、跳离 / 蹬墙跳速度（444–480）是否过快或过慢。
5. Fun 的下坡滑铲比 R5 实测更快（30° 时多约 70% 加速），要不要调到接近 R5。
