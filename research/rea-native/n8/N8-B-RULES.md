# N8-B：每个传送技能的规则

日期 2026-10-24。来源：R5Flowstate S21 脚本（`platform/scripts/vscripts/weapons/`）和武器设置（`platform/scripts/weapons/*.txt`）。这里只写重新表述的规则和数值，不贴源码。

标记：
- **[src]**：读脚本或设置得到；
- **[meas]**：已有实测（PORTAL-R2、M10-W、N8-D）；
- **[native]**：N8-C 读原生代码确认。

共用部分（相位状态、隧道引擎）见 [N8-A-SHARED-SYSTEM.md](N8-A-SHARED-SYSTEM.md) 和 [N8-C-PHASE-NATIVE.md](N8-C-PHASE-NATIVE.md)。

## 0. 隧道引擎的共用规则（Wraith 大招、Ash 大招、Alter 大招）

**路径整理**（`PhaseTunnel_CleanAndFinalizePath`）[src]：
- 旅行时间 = clamp(路径长度 / 速度, 最短, 最长)。
- 每 0.1 s 走一步，每步跨过的路径点数尽量平均。
- 最后多走一步回到终点。
- 相位时长 = 0.1 s × (步数 + 1)。

**旅行**（`PhaseTunnel_MoveEntAlongPath`）[src]：
- 开始前：停掉滑索 / 攀爬、关掉客户端预测、服务器冻结输入、收起武器、清掉已有的相位。
- 玩家挂到一个脚本 mover 上，每 0.1 s 用 `NonPhysicsMoveTo` 把 mover 移到下一个路径点。
- 同时把玩家速度设成这个路径点记录的速度，并回放下蹲。
- 视角每步向前方的路径插值。
- **终点被挡住时**（玩家体积在那里卡在实体里）停在最后一个不被挡的点。

**出口**：
- 解除挂载 → 等一帧 → 把位置设到终点。
- 解除挂载后速度是 0，所以**出口速度总是 0**。[meas：PORTAL-R2 24 次，M10-W]
- 恢复预测和输入；武器在 `holsterRemoveDelay` 后（0.4 s）还回来。
- 如果出口在实体里，用安全落点函数找位置，找不到就把玩家杀掉。

**进入条件**（`PhaseTunnel_ShouldPhaseEnt`）[src]：
- 必须是玩家；
- 不能是泰坦、在载具里、正在复活 / 被复活、处决、正在放置 Wraith 传送门、已经在隧道里。

**相位中的玩家不会被传送**：PORTAL-R2 实测 0 / 3。脚本里没有这条检查，推断是原生触发器过滤在相位中走另一条分支（N8-C 的 `0x1409fbac0`）[meas] [native-inf]。

## 1. Wraith 战术 Into the Void（`mp_ability_phase_walk`）

| 项 | 规则 | 标记 |
|---|---|---|
| 时间线 | 按下 → 0.8 s 准备（`deploy_time`，期间移动减速 20 %）→ 相位 4 s（`charge_time`，类型 `BALANCE`，warmup 0） | [src] [meas 4 s] |
| 速度 | 相位中 `speed_boost` 0.3，持续整个相位，最后 30 % 时间渐退 | [src] [meas 0.30] |
| 移动 | 正常的走路 / 空中规则，世界碰撞照旧；跳板和发射区不触发，不和玩家碰撞 | [native] [meas 跳板] |
| 结束前 | 结束前 1.5 s 出现预告特效 | [src] |
| 冷却 | 弹夹 150、每次 150、回复 10 / s → 15 s | [src] |
| 不能叠加 | 已在相位中不能再按 | [src] |

## 2. Wraith 大招 Dimensional Rift（`mp_weapon_phase_tunnel`）

| 项 | 规则 | 标记 |
|---|---|---|
| 放置 | 按下后自动冲刺、锁武器、`speed_boost` 0.2。每走过最大距离的 20 % 再加 0.1。每帧记录一个路径点（位置、朝向、速度、是否下蹲、是否在动作中、能不能当出口） | [src] [meas 364 u/s] |
| 距离 | 最长 6000 u（`wraith_portal_max_distance`）。起点和终点都要离开 128 u 以上，否则作废并返还大招 | [src] |
| 两条路径 | 同一串点存两份：一份正向、一份反向。**两个门都能进**，各自走到另一头 | [src] [meas] |
| 修剪 | 两头去掉"不能当出口"的点（出口检查：玩家体积放得下、地面可站） | [src] |
| 旅行时间 | clamp(长度 / 1024, 0.3, 2.0) s；有 `PAS_VOICES` 被动、长度超过 3000 u 时，上限从 2.0 线性升到 3.5 s（6000 u） | [src] [meas 0.5–0.6 s / 3.7 s] |
| 出口 | 速度 0（见 §0） | [meas] |
| 反复进 | 进入时 0.5 s 防抖；**离开后 1.0 s 内不能再进**；站在出口不会被送回去 | [src] [meas] |
| 寿命 | 45 s | [src] [meas 45.1 s] |
| 冷却 | 弹夹 90、每次 90、回复 1 / s → 90 s | [src] |

## 3. Ash 大招 Phase Breach（`mp_weapon_phase_breach`）

| 项 | 规则 | 标记 |
|---|---|---|
| 瞄准 | 按住预览，松开发动。终点要通过出口检查（包括视线）；离玩家至少 200 u；最远 75 m（2953 u），升级后 100 m。视线和目标方向夹角在 45° 内才能用满距离 | [src] |
| 路径 | 起点到终点的**直线**，每 16 u 一个点；路径点**不带速度**（速度 0） | [src] |
| 旅行时间 | clamp(长度 / 1200, 0.3, 1.8) s；升级后上限 1.4 s。实测冻结时间 = 0.15 + 0.1 × 步数 s（551 / 1103 / 1833 u → 0.65 / 1.08 / 1.67 s） | [src] [meas M6-B n 20] |
| 谁走 | Ash 按下后**自己立刻走**；起点留下一个门给队友 / 敌人用 | [src] |
| 方向 | **单向**：只有起点有触发区；门存在期间再次进入，还是送到同一个出口 | [src] [meas M6-B 11 / 11] |
| 出口 | 速度 **0**；出口在瞄准地面距离的约 91.8 %、地面上方 5 u；武器 0.4 s 后还回来 | [src] [meas M6-B 31 / 31] |
| 寿命 | 起点的门 15 s | [src] |
| 相位中不能发动 | 已在相位中按下无效 | [src] |

## 4. Alter 战术 Void Passage（`mp_ability_phase_door`）

| 项 | 规则 | 标记 |
|---|---|---|
| 放置 | 按住预览（`offhandHold`），松开扔出。入口点和墙后的出口点**都由原生武器放置系统给出**（`GetObjectPlacementOrigin` / `GetObjectPlacementSpecialOrigin`，`object_placement_special` 1，最远 1750 u）；系统说"没有有效位置"就什么都不做 | [src] |
| 墙厚 | 最多 30 m（`wallThicknessMax`）；可以穿墙、天花板、地板 | [src] |
| 时间线 | 扔出 → 0.7 s 后门打开（`plantDelay`），期间有扫描 → 门存在 15 s | [src] |
| 传送 | 进触发区 → **瞬间传送**到另一头（无插值）；两端都能进；同一个人 1.35 s 防抖 | [src] |
| 出口速度 | 出口方向 × clamp(进门速度在门方向上的分量, 50, 300) | [src] |
| 传送后 | **1.0 s 相位**（类型 `DOOR`，没有加速）：这 1 s 里跳板不触发，不和玩家碰撞 | [src] + [native] |
| 门打开时 | 站在门口的队友直接被送过去（`teleportTeammatesOnPortalOpen`） | [src] |
| 延伸 | 门可以沿墙 / 天花板长出一段"延伸"（以 400 u/s 移动） | [src] |
| **本地放不出来的原因** | M6-B：21 + 13 次全部失败，`ObjectPlacementHasValidSpot()` 返回否、位置 `<0,0,0>`。放置由 SDK 社区重写的 `vscript_server_placement.cpp` 计算，三个 SDK 开关打开后仍然失败。下一步：对照 S21 原生放置代码，找出在哪一步拒绝（N8-D 补测） | [meas] |

## 5. Alter 大招 Void Nexus（`mp_ability_transport_portal`）

| 项 | 规则 | 标记 |

| 方向 | **单向**回 Nexus | [src] |
| 追随门 | 使用后在原地留一个"追随门"：6 s 后开、开 10 s，任何人（包括敌人）都能跟着走；进门时不能背着门的方向走（移动方向和视线夹角要小于约 100°）；同一个人 2 s 防抖 | [src] |
| 出口 | 速度 0（同一套引擎） | [src]，未实测 |
| 冷却 | 60 s | [src] |
