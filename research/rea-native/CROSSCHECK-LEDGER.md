# N3 对照账本：原生代码 × R5 实测 × HSD Unity

日期 2026-10-23。数据在 [ledger.csv](ledger.csv)（60 条，每条一行），这里是说明和摘要。来源是 N2 的六份子系统文档（[subsystems/](subsystems/)），每条的 id 和那边一一对应，细节去那边看。

**范围**：N2 的 P1 子系统（G、L、J、S、T、M）。钩爪、滑索、外力类（P2）和镜头（C2）还没进账本。

## 1. 字段

| 字段 | 含义 |
|---|---|
| native | 原生代码里的公式或数值（[native] / [native-inf]，见子系统文档） |
| measured | R5 实测（M2–M10），写明出处 |
| unity | HSD-Unity main `6b27c04` 的现状：回放电机 `R5MotorV2`，或 Reference 配置（`MovementConfig.cs`、`SkillBody.cs`、各技能） |
| status | **代码和实测**的关系：一致 / 数值差 / 结构差（公式形状不同）/ 只有代码（没测过）/ 只有实测（代码没找到）/ 未定 |
| cause | 不一致的原因：1 代码读错（反编译歧义）；2 实测条件；3 混合构建（S21 客户端 vs S3 dedi）；4 SDK 钩子改写；5 真正的未知；**U = 代码和实测一致，但 Unity 的实现和原生不同** |
| impact | 对手感的影响：高 / 中 / 低（Leader 判断） |
| next | 下一步（N4 编号见 [TODO.md](TODO.md) 的待测清单） |

## 3. 最值得处理的条目

### 3.1 高影响

| id | 内容 | 为什么重要 |
|---|---|---|
| **G-07** | **地面转向**：原生 `Friction` 只减掉偏离意图方向的那部分速度，意图方向按加速度增长，转向是渐进的；Unity 每条命令直接把速度方向设成意图方向，转向是瞬间的 | 地面上按键急转（A↔D、W→D）的手感直接取决于它。M2 只测过从静止起步和鼠标转向，没测过按键急转，所以过去的实测发现不了这个差别 |
| **M-04** | **superglide 窗口**：实测是最后约 0.085 s，代码目前只读到 jumpoff 参数（进度 > 0.5 或按键后 0.1 s），还解释不了 | SG 是高阶身法里最看时机的一个 |
| **M-08** | **原生 SG 和 SDK mantle boost 是两套行为**：SDK 默认开启自己的 mantle boost 状态机（出口 388.7 / 367.42），原生是 460 | Reference 要明确跟哪一套。M8 的原生数据是关掉 SDK 后测的 |

### 3.2 Unity 和原生不同的（cause = U）

| id | Unity 现在 | 原生 | 建议 |
|---|---|---|---|
| G-03 | 冲刺加速边界用 M2 的"s + a·dt ≥ speed·msc" | 固定边界 msc·speed − 1 | 影响很小，可以改成固定边界，更简单 |
| G-07 | v = s·wishdir | 意图方向保护 + 偏离部分减速 | **优先**，见上 |
| G-12 / S-07 | 滑铲完全不能转向 | 垂直于速度的输入按 `slideAccel` 起作用 | 中 |
| J-04 | 超速连跳 min(h, 299) | max(299, h − 100) | 只在 > 399 时不同 |
| J-05 | 没有空中残余增益 | extra air accel 2.0 + 3D 上限 | 每跳 0.1 %，可选 |
| J-07 | 回放电机：任何低于 350 都抬到 350；Reference：只在 0.8 s 内抬 | 只抬 297.5–350 之间的 | 中，改成速度区间更准，也更简单 |
| J-08 | 回放电机 0.4 s；Reference 0.225 s | 0.4 s 内并且下蹲过渡（200 ms）未完成 | 中，改成"下蹲过渡完成"这条规则 |
| S-02 | 加成冷却从上一次**加成**算 1.8 s | 从上一次**开始滑铲**算，每次滑铲都刷新 | 中，连续短滑铲时两者差别明显 |

这些只是建议，**不改 Unity**，由用户决定（计划 §2）。

## 4. 已经解决的老问题

这些是 M2–M10 文档里写着"没解释"、"规则未确认"，或者计划 §6 种子清单里的问题，现在都有了代码出处：

| 老问题 | 出处 | 账本 |
|---|---|---|
| lurch 夹紧 209.3 从哪来 | `jump_grace_max` × msc × `sprintspeed` | L-04 |
| 连跳惩罚的 0.15 / 0.60 s 对应什么 | setfile `antiMultiJump*`（census 没读） | J-02 |
| `skip_speed_reduce` 什么时候生效 | 落地 1.0 s 内、h > 冲刺上限 | J-04 |
| 空中残余增益 ≈1.4e-5·vz² | extra air accel 2.0 + 3D 上限 | J-05 |
| 滑铲跳 0.10 s 削减、0.60 s 抬到 350 | 扣加成（下蹲过渡未完成）；297.5–350 抬升 | J-07、J-08 |
| 滑铲加成多久恢复 | 冷却从上一次开始滑铲算 | S-02、M-07 |
| `sv_friction` 是否参与地面减速 | 只在穿墙飞行和观战里 | G-13 |
| M3 分不开 min(v, 299) 和 max(v − 100, 299) | 后者 | J-04 |
