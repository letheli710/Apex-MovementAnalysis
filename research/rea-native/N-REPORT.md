## 1. 做了什么

**目标**（用户 2026-10-23）：
- 用 REA / Ghidra 读原生代码，给 Apex（R5Flowstate S21）的移动系统画一张完整的地图，作为"解释层"；

## 4. 关键发现

### 4.1 过去的"未解释"，现在有了出处

| 老问题 | 原生出处 | 账本 |
|---|---|---|
| lurch 夹紧 209.3 从哪来 | `jump_grace_max` × msc × `sprintspeed`；高速截断 1100（实测 1090 有、1110 没有） | L-04、L-10 |
| 连跳惩罚的 0.15 / 0.60 s | setfile `antiMultiJumpTimeMin` 0.15 / `TimeMax` 0.75 / `HeightFrac` 0.3 | J-02 |
| 超速连跳是 min(v, 299) 还是 max(v − 100, 299) | 后者，实测 405.1 → 305.1 | J-04 |
| 空中残余增益 ≈1.4e-5·vz² | extra air accel 2.0 + 三维速度上限 | J-05 |
| 滑铲跳 0.10 s 削减、0.60 s 抬到 350 | 下蹲过渡没完成时扣加成；只抬 297.5–350 之间的速度 | J-07、J-08 |
| 滑铲加成多久恢复 | 冷却 2 s，从上一次**开始滑铲**算 | S-02、M-07 |
| 停止吸附阈值 | 速度 < 1 设为 0 | G-06 |
| 斜坡滑铲 | 沿坡水平加速度 g·sinθ·cosθ（M8 拟合在 3 % 以内） | S-09 |
| superglide 窗口 | 分界是结束前约 0.1 s 的**时间**，不是动画比例 | M-04 |
| 钩爪挂上时的 200 上跳 | Pathfinder 的 setfile `grapple_attachVerticalBoost` 200 | P 组 |
| 落地减速 (t / 1.0)² | `landSlowdownDuration` 1、`TimePower` 2 | J-09 |

### 4.2 黑盒没测到、代码先发现、再用实测确认的

- **地面转向是渐进的**（G-07）：`Friction` 只减掉偏离意图方向的那部分速度。冲刺中 90° 按键急转要 0.23 s，速度最低跌到 131。原生公式逐命令吻合到 rms 0.05 u/s 以内（N4-B）。
- **输入曲线 m(2 − m)**（G-08）：第一条命令轴向值 0.5 → 0.75。
- **滑铲中可以转向**（G-12）：垂直于速度的输入按 `slideAccel` 起作用，实测侧向 41.1 u/s²（N4-C）。
- **镜头**（C3）：
  - 落地 kick 是欠阻尼弹簧（k 65、c 9）：约 0.16 s 到峰值，回弹一次，大小随落地速度从 2° 到 43°；
  - **punch 只动镜头，不动准星**；
  - 落进**水里**时 kick × 0.2（玩家 +0x1c7 是水中标志，不是下蹲）；
  - 滑铲眼高在 0.21 s 内下沉；FOV × 1.1；斜着滑才倾斜，最大 15°。

### 4.3 读法上的发现（以后读代码用得上）

- ConVar 从对象 +0x40 读，值在父对象 +0x60。
- setfile 键通过 `.data` 里的描述符读，"谁读描述符 +0"就是"谁读这个键"。
- 大多数客户端移动函数被 SDK 钩子包着，每个子系统都要先查钩子默认开没开（L-13、M-08）。
- 按偏移找字段（`n2/FindOffsetRefs.java`）：整个程序只有几条指令用到某个偏移时，读写它的代码就能直接说明这个字段是什么（CAM-02b 就是这样查出来的）。

### 4.4 本地构建的混合问题 [hyb]

本地是 S21 客户端 + S3 dedi（SDK）。客户端和服务器规则不同时，要分开记：
- F-02 蹲姿跳板：客户端默认 1，本地生效 0.5；
- P-10 钩爪视线离开脱钩：客户端有，S3 dedi 没有，代码还没找到。

## 5. 对 HSD-Unity 的意义

两份清单，**都只是建议，不改 Unity，由用户决定**：

- **[n5/REFERENCE-CHANGES.md](n5/REFERENCE-CHANGES.md)**：Reference 的修改建议，以及每条会影响到的测试和演示。
  - N5 对着 Unity 代码核对时**更正了两条**：
    - Reference 的地面转向已经是渐进的（`groundVectorRedirect`），逐命令误差只有 0.1–0.6 u/s，G-07 从高影响降为低；
    - Reference 的斜坡滑铲用的就是原生公式（S-09）。
  - 剩下中等影响的有 4 条：滑铲转向、滑铲加成冷却、350 抬升、早跳扣加成。后三条是同一组规则，可以一起改。
- **[n5/FIT-TO-NATIVE.md](n5/FIT-TO-NATIVE.md)**：Unity 里哪些拟合值有了原生出处。
  - 20 项只要把出处改成 [native]，行为不变；
  - 5 项行为会变（就是上面的建议）；
  - 8 项找到了出处，但还要核对。
