# 蹬墙跑 B 版规则（实现规格）

日期：2026-10-29。B = **TF2 规则 + R5 数值**（用户 2026-10-28 定为基准）；A = TF2 原版（MP）数值，做成可切换的预设。这份文档是 HSD-Unity 实现 P-01 的规格：一条规则一行，每行写来源。

来源缩写：
- **T3**：`wallrun/T3-REPORT.md`（TF2 静态）
- **T5**：`runtime/T5-REPORT.md` §5（TF2 实测）
- **R1**：`wallrun/R1-R5-WALLRUN-KEYS.md`（R5 静态，Apex 新增的键）
- **D12**：`wallrun/D1-D2-REPORT.md`（R5 静态，系数 f 和参考高度）
- **BT**：本文第 9 节的补测
- **[inf]**：推断；**[design]**：HSD 自己的取舍

## 1. 玩家身上要维护的状态

| 状态 | 规则 | 来源 |
|---|---|---|
| `boostArmed` | 着地时 = false；地面起跳、墙跳时 = true；同一面墙再贴时，算完起跑提速后 = false | D12 §1.2 |
| `refZ`（参考高度） | 站在可站立地面上（法线 z ≥ 0.7）且不在跑墙中时，每帧 = 脚底 z；腾空后只降不升（z < refZ 时跟着降低）；跳板 / 重力炮发射时 = 弹道最高点 z + v²/(2g) | D12 §2 |
| `wallrunCount` | 每次起跑 +1；地面起跳时清 0 | D12 §1.2 |
| 系数 **f** | f = 1 当且仅当 `boostArmed` 且（cutoff < 0 或 z − refZ < cutoff）；否则 0。**每帧重新算**。cutoff = `verticalGainCutoff_wallrun`（B 175；A 无此键，视为关） | D12 §1 |
| 上次接触的墙 | 法线、接触点高度；用于同墙判断 | T3 §2.1 |
| 跑墙计时 t | 从起跑那一刻开始 | T5 §5.1 |

`wallrun_strengthLoss*`（次数衰减）默认 1000，不实现（D12）。

## 2. 起跑条件（每 0.07 s 判一次，`wallrun_retry_interval`）

| 条件 | B | A | 来源 |
|---|---|---|---|
| 在空中；不在滑索、梯子、其他驱动技能上 | 同 | 同 | T3 §2.1 |
| 墙面法线 z ∈ [下限, 0.7] | 下限 −0.5（`wallrunCeilingLimit` 0.5） | 下限 −0.35 | R1；T3 |
| 朝墙移动：速度 · (−法线) > 0（`wallrun_minAngle_air` 180° 即半角 90°） | 同 | 同 | T3 |
| 脚离墙 ≤ 距离 | 17 | 13 | R1；T3 |
| 起跑高度门：接触点 z ≤ refZ + cutoff − `climbFinalJumpUpHeight` | 175 − 28 = 147（滑铲超级跳起跳时 cutoff 再 +200） | 无 | R1 |
| 同一面墙（法线点积 > 0.9）：只能在上次接触点以下重贴 | 同 | 同 | T3；T5 §5.4 ✓ |
| 墙跳后的排斥：0.2–0.4 s 内不能贴回刚跳离的墙 | 同 | 同 | T3（未实测） |
| 不需要按键，没有速度下限 | 同 | 同 | T3；T5 ✓ |
| 0.5 s 计时（TF2 player+0x2588） | 不实现 | 不实现 | 含义未知，T5 已排除"离地时间" [inf] |

## 3. 起跑那一刻

| 规则 | B | A | 来源 |
|---|---|---|---|
| 起跑提速：沿墙向上分量 u < 250·f 时，加 250·f − max(u, 0)（向上慢补到 250，下坠时加 250） | 250 | 250 | R1；T5 ✓（175.7 → 250、−114 → 134） |
| 恢复二段跳次数（`superjump_limitreset_onwallrun`） | 同 | 同 | T3 |
| `wallrunCount` +1；记下墙法线、接触点 | 同 | 同 | D12 |
| 同一面墙再贴：提速照给，之后 `boostArmed` = false（这次跑墙没有重力爬升） | 同 | 同 | D12 §1.2（BT-3 验证） |

## 4. 跑墙中（每帧）

| 规则 | B | A | 来源 |
|---|---|---|---|
| 重力系数 = 1 − f·(1 − t / T)，t ≥ T 时为 1；乘基础重力（750 × gravityScale） | T = 1.0 s | T = 0.7 s | R1；T5 ✓（A 逐帧吻合） |
| 输入映射到墙面平面；按前进时额外"向上输入" = 前进量 × 沿墙分量 × 0.65（`wallrun_upwardAutoPush`） | 同 | 同 | T3；T5 ✓ |
| 水平：朝上限加速（× 移动倍率） | 上限 225、加速 200 | 上限 420、加速 1500 | R1；T3 |
| 水平：输入和视角朝后（点积 ≤ −0.6）时上限 50 | 同 | 同 | T3；T5 ✓ |
| 竖直：朝上限加速，滑落越多越弱 | 上限 112、加速 450 | 上限 225、加速 360 | R1；T3 |
| 减速 / 摩擦 | **线性**：无输入时水平 −500 u/s²；竖直 −300 u/s² 趋向 0，下坠时乘 (1 − 重力系数)(1 − 滑落)。没有指数摩擦 | **指数**：速度每秒 ×(1 − 4·dt)（3D）；无输入时下坠速度中 70% 的滑落部分不受摩擦 | R1；T5 ✓（A） |
| 滑落量：t > 1.5 s 起在 1.0 s 内线性升到 1；无输入时至少 0.7 | 同 | 同 | T3；T5 ✓ |
| 爬升上限：z − refZ ≥ 175 时 f 当帧变 0，重力恢复满值 | 175 | 无 | D12（BT-2：TF2 应无此门） |

## 8. 镜头侧倾（P-05，子开关）

跑墙时朝墙外侧倾：最大角度 B 10° / A 15°；速度 6；提前 0.25 s 开始（`wallrun_viewTiltPredictTime`）。来源 T3 §2.2、R5 ConVar。镜头属于用户单独验收的范围，默认关。

## 9. 补测（BT，2026-10-29，TF2）

结果见 `runtime/T5-REPORT.md` 第 8 节：BT-2、BT-3 和预测一致；BT-1 在这张图上测不了（边缘都有拦挡），替代证据（传送起跑）和预测一致。

| 编号 | 测什么 | 预测 |
|---|---|---|
| BT-1 | 从边缘走下去（不跳），再贴墙 | 没有提速，也没有爬升（着地时 `boostArmed` = false） |
| BT-2 | 跳起后在比起跳点高很多的地方贴墙 | TF2 没有 `verticalGainCutoff_wallrun`，预测**照常**有提速和爬升；R5 的 175 门只能静态确认 |
| BT-3 | 同一面墙墙跳后再贴 | 起跑提速还在，但这次没有重力爬升 |
