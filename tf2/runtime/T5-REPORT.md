# T5 报告：TF2 运行时实测

日期：2026-10-29。地图 `mp_lf_stacks`，本地私服（Northstar 1.31.14），MP 铁驭（`pilot_grapple_male`，主武器 R-201），客户端 144 fps（每次运行帧间隔中位数 6.95 ms）。

## 1. 结论

1. **共用底层抽查全部有结论。** 7 项静态结论成立，3 项需要更正或补充：
   - T-G04：TF2 的加速和减速**都不乘**移动倍率，ADS 和兴奋剂只改速度上限。R5 的加速乘 msc，所以这是 Apex 改过的地方。
   - T-S06：TF2 滑铲跳**不抬速也不封顶**，`slideMaxJumpSpeed` 350 在实测里没有作用。R5 会把速度抬到 350，也是 Apex 改过的。
   - 蹬墙跑起跑提速：规则是 **vz + 250，最多到 250**，不是"提到至少 250"。
2. **蹬墙跑规则基本被证实**：
   - 0.7 s 线性重力爬升、摩擦 4/s、跑满 1.75 s、1.5 s 开始滑落；
   - 墙跳离墙 205、输入方向 80、vz = min(230, vz + 345)；
   - 只能在上次接触点以下重新贴墙。
   - 新发现：**起跑提速和重力爬升只在"跳起后"贴墙时出现**。传送到空中（相当于从边缘掉下）贴墙时，两者都没有，从第一帧就是满重力。
3. **二段跳规则被证实**，包括水平"扣 180、沿输入加 180"（T3 未解项 2）。
4. **兴奋剂 ×1.8 被证实**（走路 173.5 → 312.3，冲刺 260 → 468）。
5. **工具问题已修**：
   - 主服务器上报已关闭；
   - 实验表改为在客户端按游戏时间执行；
   - 逐帧记录输入；
   - 失焦降帧已修。
   - 冒烟测试里"按键晚 1.5 s"的真正原因是开局入场动画冻结了玩家。

## 2. 工具修正（HANDOFF 第 3 节的三件事，加上实测中发现的两件）

| 问题 | 原因 | 修法 |
|---|---|---|
| 主服务器上报（`report=1`） | `autoexec_ns_server.cfg` 在服务器启动时把 `ns_report_server_to_masterserver` 重新设成 1，UI 里设的 0 被覆盖 | 服务端脚本初始化时（仅 `hsd_autorun` 1）设为 0。之后日志里不再出现 "Attempting to register the local server"，`hsd_info` 显示 `report 0` |
| 按标签切段不准、"UI wait 和游戏时间不同步" | 实际是开局约 10 s 的入场动画（`started intro!` → `intro finished!`）冻结了玩家；标签另有网络往返延迟 | 实验表改在客户端线程里执行：`wait` 用客户端游戏时间，每条命令打印 `HSDDIAG CMD <客户端时间>`；客户端等 `GetGameState() >= Playing` 再开始。分析按 CMD 时间和状态变化切段 |
| 不知道按键何时生效 | — | 客户端每帧记录输入轴（前后、左右）和按键位（跳、蹲、冲刺、瞄准、开火） |
| 后台运行只有 20 fps | 引擎 `not_focus_sleep`（默认 50 ms）让失焦窗口每帧睡 50 ms；客户端每帧模拟一个 usercmd，移动积分步长变成 50 ms | UI 脚本运行时设为 0，退出前恢复原值（日志 `not_focus_sleep was 50`）。runner 在 `meta.json` 里记录 `client_dt_median_ms`，必须约 7 ms |
| 传送后的 `until ground` 误判 | 传送还没到客户端时，客户端仍是传送前的"在地面" | 新增 `RA()`：传送后先等"在空中"再等落地 |

新增服务端命令：`hsd_stim`、`hsd_info`、`hsd_weapon`、`hsd_probe`、`hsd_trace`。条件等待：`U(cond)`，即 `HsdDiag_U`。

**日志偏移**：客户端日志的速度是一帧结束时的值。起跳后第一帧的 vz 比理论起跳速度低约 6.3（站立跳记成 293.7，理论 300）；空中二段跳低约 4.2（一帧重力）。下文的竖直速度结论都已扣除这个偏移。

## 4. 共用底层（T2 待定项）

### 4.1 地面加速、减速和移动倍率（T-G01、T-G03、T-G04）

| 条件 | 速度上限 | 加速 | 松手减速 | 无输入减速 |
|---|---|---|---|---|
| 走路 | 173.50 | 2500 | 1500 | 1500（踢到 300 后） |
| ADS（R-201，0.5） | 86.75 | 2500 | 1500 | 1501 |
| 冲刺 | 260.00 | 2500 | 1500 | — |
| 兴奋剂走路 | 312.30 | 2500 | 1500 | 1500 |
| 兴奋剂冲刺 | 468.00 | 2500 | — | — |

- ADS 和兴奋剂都乘在速度上限上（0.5、1.8），**加速和减速都不变**。所以 `player+0x1600` 不是移动倍率，在这些情况下都是 1。
- TF2 铁驭武器的 `move_speed_modifier` 全是 1（只有泰坦武器不同），所以用 ADS 和兴奋剂代替"换武器"。
- **和 R5 的差别**：R5 M2 里加速乘 msc、减速不乘；TF2 两个都不乘。T-G04 归为"改过"。

### 4.2 Lurch（T-L01、T-L02）

做法：冲刺到 260 起跳，起跳后 t 秒新按右键（前进键一直按着）。

| 按下时刻 | 方向偏转 | 反推强度 | 静态预测强度 |
|---|---|---|---|
| +0.11 s | 31.9° | 0.70 | 0.7 |
| +0.31 s | 19.5° | 0.437 | 0.7 × (1 − 0.113/0.3) = 0.436 |
| +0.46 s | 4.1° | 0.097 | 0.098 |
| +0.61 s | 0 | 0 | 0 |
| 起跳前就按住右键 | 0 | — | 不触发 |

- 速度大小不变（260 → 260），只转方向：朝"按键方向"（前 + 右，45°）按强度插值。
- 0.2 s 内满强度，0.5 s 线性降到 0。最大一次改变量 143，没碰到 0.7 × 260 = 182 的上限。
- **起跳前按住的键不触发 lurch**，证实必须新按（T-L02 的 [inf] 去掉）。

### 4.3 空中加速（T-J02）

| 试次 | 结果 |
|---|---|
| 300 u/s 空中按后退 | 500 u/s² 减到 −60 后停住（airAcceleration 500、airSpeed 60） |
| 300 u/s 空中按右 | 侧向分量升到约 60 |
| 300 u/s 空中按前进 | 约 +1 u/s²（300 → 301.1，1.1 s），残余空中加速可以忽略 |
| 30 u/s 空中按前进 | 升到 60 后停 |

结论成立：空中按 Quake 规则，沿输入方向的分量最多到 60；额外加速 2.0 只带来约 1 u/s² 的增长。

### 4.4 Skip（T-J03）

做法：以 h 落地，在落地后不同时刻起跳。

| 落地 h | 起跳延迟 | 起跳 h | 起跳 vz（扣偏移） |
|---|---|---|---|
| 600 | 0.007 s | 588.0（−12） | 259.8 |
| 600 | 0.063 s | 515.9 → 503.9（摩擦后再 −12） | 259.8 |
| 600 | 0.090 s | 474.7 → 462.7 | 259.9 |
| 600 | 0.131 s | 413.4（不扣） | 300 |
| 600 | 0.208 s | 297.8（不扣） | 300 |
| 460 | 0.007 s | 450.0（max(450, 448)） | 259.9 |
| 440 | 0.007 s | 440.0（低于 450 不扣） | 259.9 |
| 350 | 0.007 s | 350.0 | 259.8 |

- 窗口 0.1 s（在 0.090 和 0.131 之间），扣 12，最低到 450。
- 高度 ×0.75，√(2·750·45) = 259.8，全部成立。
- 补充：**落地帧开始就有正常地面摩擦**（约 1500 u/s²），skip 不豁免摩擦。只有落地当帧就起跳才几乎不丢速。

### 4.5 滑铲（T-S01、T-S02、T-S06）

| 试次 | 结果 |
|---|---|
| 冲刺 260 起滑 | 398.7（min(260 + 150, 400)，再扣首帧衰减） |
| 1.0 s / 1.5 s / 1.92 s 后再滑 | 无加速（服务端滑铲标志为 1，速度不变） |
| 距第一次 2.18 s、距上一次 0.26 s 再滑 | 无加速：冷却从**上一次起滑**算，没拿到加速的那次也重新计时 |
| 间隔 2.51 s 再滑 | 有加速 |
| 兴奋剂下 468 起滑 | 能滑，无加速（超过上限 400） |
| 滑铲跳（h 251、354、389） | vz = 273.9（扣偏移），即高度 50；水平速度**不变**（251 → 250.5、354.5 → 353.2、388.9 → 387.6） |

- T-S01、T-S02 成立。
- T-S06：TF2 的 `slideMaxJumpSpeed` 350 在 251 和 389 两边都没起作用，也没有加速返还。R5 会抬到 350 并返还，归为"改过"。
- 滑铲加速是否乘 msc：兴奋剂下速度已超过 400，这次实验区分不了，仍按静态结论（不乘）。

## 5. 蹬墙跑（T3 第 6 节）

### 5.1 起跑

| 起跑方式 | 起跑前 vz | 起跑后 vz | 重力 |
|---|---|---|---|
| 跳起 0.10 s 后踢向墙（`gk_010`） | 175.7 | **250.0** | 0 → 满，0.7 s |
| 跳起 0.30 s 后（`gk_030`） | 45.7 | **250.0** | 同上 |
| 跳起 0.60 s 后（下坠中，`gk_060`） | −114.1 | **133.9**（+248） | 同上，从起跑开始算 |
| 墙跳后回贴同一面墙 | −150 / −317 / −496 | +96 / −71 / −250（各 +246） | — |
| 传送到空中再踢向墙（`tk_280`） | 225.8 | 221.6（不变） | 第一帧就是满重力 |
| 传送到墙边，vz −25 ~ +300（`wr_*`） | — | 不变 | 第一帧就是满重力 |

- **起跑提速**：vz' = min(250, vz + 250)（扣一帧重力后 +246~248）。T3 写的"提到至少 250"要更正：下坠时只加 250，不会直接变成 +250。
- **重力爬升**：按 g_eff = −dvz/dt − 4·vz 反推（上升时摩擦作用在全部速度上），跳起后起跑的 g 依次为 41、118、199、281、367、443、528、598（t = 0.03 … 0.71 s），和 600·t/0.7 吻合。计时从**起跑那一刻**开始（`gk_060` 起跳 0.69 s 后才贴墙，起跑时 g 仍接近 0）。
- **新发现**：传送或从边缘掉落（这次没有起跳）后贴墙，既没有提速也没有爬升。推测是"自上次着地以来跳过"之类的标志 [inf]；墙跳算一次跳，所以回贴时有提速。
- **起跑时机**：跳起后 0.09 s、0.20 s、0.39 s、0.69 s 都能起跑，所以 player+0x2588 那个 0.5 s 计时**不是**离地时间。它是什么仍未确认。

## 7. 未解项

1. player+0x2588 的 0.5 s 计时是什么。已排除"离地时间"；可能和蹬墙结束或墙跳有关，要用"墙跳后 0.5 s 内贴另一面墙"来测。
2. 起跑提速和重力爬升的开关条件 [inf]。需要找一处真实的边缘，走下去再贴墙，确认"掉落起跑"和传送一样。
3. 二段跳"已在上升时只叠加 0.25H"的分支。
4. 墙跳后 0.2–0.4 s 的排斥。
5. 滑铲加速是否乘 msc（需要低于 400 的倍率，比如 ADS 冲刺不可行，要换别的减速效果）。
6. T-M01 攀爬（mantle）没有测，不在本次范围。
7. 实测都是客户端预测值，没有逐帧和服务端核对（服务端只有 10 Hz 记录）；滑铲状态只在服务端日志里有。
