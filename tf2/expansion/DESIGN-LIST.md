# HSD 扩展：设计清单（不用研究，以后做时别忘）

用户 2026-10-29 定：下面这些实现简单，或者是我们自己的想法，**不进研究清单**，只记在这里。做 HSD 战斗框架和技能时从这里拿。

## 1. 总体方向（用户决定，2026-10-29）

- **HSD 最终是 PvE 游戏。**
- **先研究、存档备用。** HSD 现在没有战斗系统（没有血量、伤害、武器、敌人）。技能和道具先把**机制怎么实现**研究清楚、存档；数值等 HSD 战斗框架建好后再回来调，那时再做更深入的研究。
- **泰坦先研究机动和核心等功能，数值以后调。** 用户原话："我觉得可以先研究泰坦的机动和核心等功能，但是对于数值这块，我们可以后期调整。毕竟我认为，调整铁驭和士兵的伤害以及专属武器这类东西，是比较好处理的。"
- **伤害不分泰坦和士兵**：统一的血量 / 伤害体系，不同单位只有数值不同。
- **Apex 有原型的，用 Apex 做参考**（Apex 比较好做；如果 TF2 明显更好做，也可以用 TF2）。见 [APEX-HANDOFF.md](APEX-HANDOFF.md)。
- **只借规则和数值**，不用 TF2 / Apex 的模型、贴图、声音、动画。

## 3. 简单设计项

| 项 | 来源 | 设计要点 |
|---|---|---|
| 能量电池 | TF2 `pas_power_cell` | 技能回复速度 × 1.35（TF2 值），影响所有战术技能 |
| 快速回血 | TF2 `pas_fast_health_regen` | 回血更早开始；具体延迟、速率等战斗框架定 |
| 增幅武器 | TF2 `burnmeter_amped_weapons` | 一段时间内伤害 × 倍率；做成技能或 buff |
| 地狱塔式武器 | 用户自创（《皇室战争》地狱塔） | 对同一目标持续造成伤害，伤害随时间爬升；换目标重置。要定：爬升曲线、上限、断开多久算换目标 |
| 分身升级分支 B | 用户自创 | 可多次释放单个分身（次数、冷却）。分支 A = 一次放多个（Mirage 大招 / TF2 全息新星） |
| 投掷物发射器 | 用户自创，参考 Apex Fuse | 把投掷物发射得更远；Fuse 的数值见 Apex 研究（[APEX-HANDOFF.md](APEX-HANDOFF.md) 第 2.7 节） Apex 研究见 [apex/APEX-REPORT.md](apex/APEX-REPORT.md) 2.7。 |
| 哨戒炮两种 | 用户（TF2 两种炮塔合一） | ① 高射速、低单发伤害；② 低射速、高单发伤害。机制研究在 TF2 任务里 |
