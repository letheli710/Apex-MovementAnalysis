# HSD 扩展：泰坦清单（草稿，等用户填"抉择"列）

用户 2026-10-29：HSD 要做 **3–4 台泰坦**，作为特殊玩法或高级装备。泰坦要测移动和各种数据，包括转向（用户感觉泰坦比铁驭转得慢，以此显出机械感）。

**用户 2026-10-29 补充**：先研究泰坦的机动和核心等功能，数值以后调（原话见 [DESIGN-LIST.md](DESIGN-LIST.md) 第 1 节）。泰坦清单之后再处理，铁驭清单先做。

**用户 2026-10-30**：还没定选哪 3 台，所以**7 台全部实测**，每台拿到详细数据（转向、移动、武器和技能），之后再选。下属会话 tf2-t0-titan 在做，产出放 `expansion/titan/`。

数据出处：解出的游戏文件 `scripts/players/mp/titan_*.set`、`scripts/weapons/mp_titan*.txt`。规矩同 [PILOT-LIST.md](PILOT-LIST.md)：只借规则和数值，不用 TF2 的模型、声音、动画。

## 0. 先要解决的（不用抉择，研究前提）

- **本地私服里召唤并驾驶泰坦。** 昨晚没做过，可能要给诊断模组加"召唤 / 上机"命令。泰坦实测都靠它，是泰坦任务的第一步。
  - → **已完成（T0，2026-10-30）**：7 台都能召唤、上机（动画约 3.5 s 或瞬间）、下机。命令和坑见 [titan/T0-REPORT.md](titan/T0-REPORT.md) 第 1 节。
- **转向速度。** 设置文件里没找到明显的"转向上限"键（`titan_base.set` 只有 `aimAngle*`、`pitchOffsetScale` 这类）。要实测：同样的鼠标输入下，泰坦和铁驭每秒最多转多少度、有没有平滑或加速曲线。如果没有限制，"慢"的感觉可能来自镜头、动画或灵敏度缩放，测试要分清。
  - → **T0 结果**：同样的视角输入下，7 台泰坦和铁驭转速完全相同（实测到 1500°/s），没有上限和平滑。泰坦唯一常驻的差异是**手柄**视角表，转速为铁驭的 0.75 倍，加速时间更长（`cfg/aimassist/looksensitivity_titan.txt`）。真实鼠标也实测过：2000 计数，铁驭和 7 台泰坦都转 144.78°。另有个别技能临时 `turn_slow`：Ion 激光核心 0.25，实测鼠标转速减半。见 [titan/T0-REPORT.md](titan/T0-REPORT.md) 第 2 节。

## 1. 三种底盘（体型）

TF2 的 7 台泰坦分属三种底盘，**移动手感由底盘决定**，武器和技能另配。

→ **T0 实测（2026-10-30）**：走、冲刺跑、dash 速度都和下表一致，同底盘的泰坦移动完全相同。但多人里的**冲刺次数是 2 / 1 / 1**，不是下表的 4 / 3 / 2：每台泰坦的设置文件覆盖了底盘的耗能和回能。逐台的移动表见 [titan/T0-REPORT.md](titan/T0-REPORT.md) 第 3 节；7 台的套件和对比表见 [titan/titans/](titan/titans/README.md)。

| 底盘 | 血量（多人） | 走 / 冲刺 | 冲刺（dash）速度 | 冲刺次数 | 用它的泰坦 | 抉择 |
|---|---|---|---|---|---|---|
| Stryder（轻） | 7500 + 护盾 2500 | 187 → 270 / 400 | 800，0.1 s | 4（每次 25–33） | Ronin、Northstar | |
| Atlas（中） | 10000 + 护盾 2500 | 150 → 250 / 380 | 700，0.2 s | 3（每次 33–50） | Ion、Tone、Monarch | |
| Ogre（重） | 12500 + 护盾 2500 | 112 → 210 / 310 | 600，0.2 s | 2（每次 50–100） | Scorch、Legion | |

（冲刺次数的范围是装备"冲刺增强"前后。所有底盘：不能跳、`stepheight` 80、走路会踩伤附近的人。）
