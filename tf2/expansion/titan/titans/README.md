## 怎么读

- 数值是多人（MP）值。`MP_BASE` 优先，带 `[$sp]` 的值丢掉。
- 伤害写成"对铁驭 / 对泰坦"（`damage_*_value` / `damage_*_value_titanarmor`）。爆炸伤害写成"对铁驭 / 对泰坦"（`explosion_damage` / `explosion_damage_heavy_armor`）。
- 冷却：`ammo_instant` 类技能的冷却 = 每次消耗 ÷ `regen_ammo_refill_rate`（秒）。
- 距离单位都是游戏单位 u。

## 3. 共性（HSD 可以直接照搬的规则）

1. **所有泰坦共用转向规则**：真实鼠标实测和铁驭完全一样，2000 计数都转 144.78°；没有上限，没有平滑。ADS 按武器放大倍数缩放。手柄 × 0.75。技能只在少数场合临时 `turn_slow`，强度 0.25 时鼠标转速减半。铁驭在表里作对照：腰射 144.8°，ADS 99.1°（`20261030_023156_t0_turn`、`20261030_023602_t0_mouseslow`）。
2. **同底盘移动完全相同**，差异只在 dash 次数（Stryder 2 次，其他 1 次）和 ADS 减速（武器决定，0.4–0.75）。
3. **核心**：大多数 `core_build_time` 是 150 s（Ronin 120，Monarch 100）。多人里核心靠伤害充能，这个时间只是基准。
4. **"拿着技能时减速"只有三种**：ADS（`ads_move_speed_scale`）、核心蓄力（`move_slow` 0.6–0.7）、Ion 激光核心（`move_slow` 0.25 + `turn_slow` 0.25）。防御技能（格挡、涡旋、热盾、枪盾）本身不减速，Legion 的枪盾例外：它通过强制 ADS 减速。
5. **近战**：除 Ronin 外都是同一个拳击，500 伤害，距离 280。Ronin 的剑 800，剑核心期间 2200，距离 325（`melee_titan_punch*.txt`、`melee_titan_sword.txt`）。
