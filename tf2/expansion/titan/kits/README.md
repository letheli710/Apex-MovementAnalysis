# 七台泰坦的专属套件：研究清单和总览（2026-11-08，`tf2-titan-kits`）

## 先说结论

- **7 台泰坦的专属技能都写成了能照做的规格**，每台一页：每件技能的状态机、时间线、数值（带出处）、边界情况，以及 TF2 本地私服上的实测对照。顺带的三页：泰坦打步兵（T-b）、舱框和换弹小项（T-f）、护盾来源选项（T-a，给你选）。
- **几条和以前想的不一样的：**
  1. 服务端脚本每 0.1 s 才跑一帧。所有"每帧一次"的伤害和推进（地面火、电弧波、激光核心）都按 0.1 s 算。
  2. Ronin 举剑时，**正后方**的攻击也按 × 0.3 挡下（脚本读下来以为背后不挡）。
  3. Northstar 不蓄力的一枪对泰坦是 550，满蓄 2050；以前 340 u 的悬停高度是测试地图的天花板，不是规则。
  4. 泰坦**一碰到步兵就是 5000**（踩死）；dash 撞人没有单独的伤害，就是踩。
  5. TF2 多人泰坦出生时护盾是 0，默认不会自动回盾。
- **还缺的主要是三项：** ~~Northstar 悬停的最高高度、Ion 涡旋接投射物后的重发散布、泰坦拳打步兵~~——11-13 都补测了，见下面"11-13 补测"。
