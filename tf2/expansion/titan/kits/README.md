# 七台泰坦的专属套件：研究清单和总览（2026-11-08，`tf2-titan-kits`）

## 先说结论

- **7 台泰坦的专属技能都写成了能照做的规格**，每台一页：每件技能的状态机、时间线、数值（带出处）、边界情况，以及 TF2 本地私服上的实测对照。顺带的三页：泰坦打步兵（T-b）、舱框和换弹小项（T-f）、护盾来源选项（T-a，给你选）。
- **几条和以前想的不一样的：**
  1. 服务端脚本每 0.1 s 才跑一帧。所有"每帧一次"的伤害和推进（地面火、电弧波、激光核心）都按 0.1 s 算。
  2. Ronin 举剑时，**正后方**的攻击也按 × 0.3 挡下（脚本读下来以为背后不挡）。
  3. Northstar 不蓄力的一枪对泰坦是 550，满蓄 2050；以前 340 u 的悬停高度是测试地图的天花板，不是规则。
  4. 泰坦**一碰到步兵就是 5000**（踩死）；dash 撞人没有单独的伤害，就是踩。
  5. TF2 多人泰坦出生时护盾是 0，默认不会自动回盾。
- **还缺的主要是三项：** Northstar 悬停的最高高度（没找到能用的开阔场地）、Ion 涡旋接投射物后的重发散布、泰坦拳打步兵（冻结靶子打不中）。详见最后一节。

## 能脱离 TF2 照做的 / 还缺的

**能照做的：** 7 台泰坦每件技能的规则和数值（每页第 1–7 节），加上第 8 节的实测曲线和数值当对照；泰坦踩人、降落砸人；三种底盘共用的舱框晃动；分段换弹的规则；护盾来源的全部选项。

**还缺的：**

| 缺什么 | 为什么 | 怎么补 |
|---|---|---|
| Northstar 悬停、飞行核心的最高高度 | 测试地图头顶只有 340 u；开阔地图上泰坦卡住 | 换一张图、手动找开阔点再测；或者直接用脚本曲线（3 s 升 486 u，6 s 升 696 u） |
| Ion 涡旋接投射物、重发散布 | 敌方 NPC 泰坦几乎不开火 | 用会开火的敌人（例如 hostile 模式的 Scorch / Tone 靠近）再测 |
| 泰坦拳打步兵 | 冻结步兵一次都没打中 | 换成不冻结的步兵，或抬低视角 |
| Northstar 系留的拉力；Tone 多层标记计时；Monarch 虹吸打步兵 | 靶子不会走 / 测试没覆盖 | 要会走的敌方泰坦 |
| 原生代码里的部分（相位碰撞、近战判定锥、换弹检查点时刻、俯仰晃动键等） | 不在脚本里 | 各页第 9 节已列；HSD 可以自己定 |
| 游戏用哪张 FD 等级表 | 两张表不一致 | 只影响 FD 升级，HSD 不用 |
