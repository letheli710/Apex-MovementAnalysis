# 中模够不够当占位：姿势试摆

2026-11-02。在 `_old-713-base-medium/titan_m_mid.blend`（2026-11-02 改名） 上试摆，不保存、不改模型。姿势是我手摆的第一版，没有调过。

总览图 `sheet.jpg` 只在本地（旧模型的图不进公开仓库）。数据：[result.json](result.json)。`sweep.json` 的 `level_aim.eye` 和两个 `*_from_eye` 有误（量的时候身体还留在前一个姿势），下面的数字是用 `S_Eye` 静止位置 (0, −0.8, 4.7) 重算的。

**结论：够用，结构不用重做。** 需要补的是挂点、一个数值和第一人称的做法。
> **2026-11-02 后续：** 用户判断旧结构和实测对不上，决定按实测重新设计。按 TF2 比例对比后确认差得很多（髋高 3.6 对 3.0，肩 5.3 对 4.2–4.8）。上面"够用"的结论已被取代，见 [../v2-design/DESIGN.md](../v2-design/DESIGN.md)。

| 需要的动作 | 结果 |
|---|---|
| 站立瞄准、上下瞄准、走 | 干净，无碰撞 |
| 腰左右转 35 / 55 / 85° | 炮和手都不撞；≥55° 时舱门下沿碰髋毂 1 对零件 |
| 蹲 | 能摆，大腿和躯干底有穿插，看图不明显 |
| 冲刺跑（前倾） | 有穿插，见下面的界限 |
| dash 侧倾 | 能摆；左臂和左腿撞，是这版手摆的问题，抬手臂就能避开（未复测） |
| 登场落地（单膝跪） | 能摆，穿插最多（大腿撞躯干 24 对），轮廓可用 |
| 跪下开舱门 | 能摆，舱门 120° 打开 |
| 近战（左爪挥） | 能摆，腰转 45° 时右髋和躯干有穿插 |
| 濒死歪斜 | 能摆，炮下垂时碰右髋 |

## 量到的界限

| 项 | 数值 |
|---|---|
| 腰前弯，不碰髋毂 | 10° 没事，20° 髋毂碰躯干底（只测了 0 / 10 / 20°） |
| 大腿前摆（腰不弯） | 65° 碰躯干底 |
| 大腿前摆（腰弯 10°） | 55° 碰躯干底 |
| 炮水平 | 肩 −30 + 肘 −31 |

原因：腰的转轴离躯干底太近（都在 3.95 m 左右），躯干底又宽。TF2 冲刺跑胸前倾约 41°，这台靠腰做不到，要整个骨盆前倾。

## 第一人称

炮水平时，炮口相对眼睛：向右 41.5°，向下 7.4°，距离约 2.8 m。TF2 换算到 16:9 的左右视野约 ±45.5°，所以**只有炮口露在屏幕最右边**，肘在眼睛后面。

TF2 也不用身体模型：第一人称的手臂和舱框是单独的模型（`pov_titan_*`、`pov_titan_*_cockpit`）。所以第一人称应该把 `W_Cannon` 这组零件另放在镜头前。
