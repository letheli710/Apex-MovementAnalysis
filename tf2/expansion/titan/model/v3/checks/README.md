## 关节贴合（`joint_test.py`，R6，2026-11-12）

**大白话：** 每个关节两边的零件，在文件打开时的姿势和 19 个姿势里都要贴住（表面相交，或表面距离 ≤ 5 mm）。读每台的成品 FBX，关节对从文件的层级里自动取：每个带网格的节点，配它最近的、也带网格的上级节点。姿势用各条线自己的值（`../lineup/lineup_pose.py`）。

**L 的几处缝是什么：**
- **右腕–武器 0.03**：这个检查把武器配的是手掌（`J_Wrist_R`），握把实际是手指夹住的。另外查了武器和右手三根手指：19 个姿势里手指收 25°，都碰到握把；只有文件打开时的 bind 姿势手指是张开的（0°），差 0.030。所以游戏里的姿势不会有缝，只有 bind 姿势的手指没收。
- **躯干–舱门 0.008**：关着的舱门和躯干之间的板缝（L-D15 里写过：舱门和躯干共用切面，板缝 1.2 cm 刻在两边）。
- **剑–剑架 0.015**：L-2 背上的剑挂在 `S_Sword_Back`，和剑架之间留了 1.5 cm。
- L 线自己的检查（r5b `joints_connected`）只查四肢的 14 个关节，不查武器、舱门、剑，所以没报这几处。

**结论（lead 11-12）：** L 的这几处不修：腕和武器只在 bind 姿势有缝，舱门是有意留的板缝。H-1 修了（V5）。
