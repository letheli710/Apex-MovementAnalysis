# 第一版（V1，2026-11-12）

2026-11-12。五台的 FBX 都已经有了：`../L/Titan_L1.fbx`、`../L/Titan_L2.fbx`、`../M1/Titan_M1.fbx`、`../H/Titan_H1.fbx`、`../H/Titan_H2.fbx`。

## 结论（大白话）

按规范 §2 和 §5 的第一项验收：涂成纯黑、缩到 1/4，**任意两台都能分清**。10 对组合全部通过。

分得最勉强的是**同底盘的两对**：L-1 / L-2、H-1 / H-2。这两对的腿和下半身是同一副骨架，几乎一样，只能靠上半身的轮廓和武器区分。缩到 1/4 以后，这个差别还在，但要多看一眼才认得出。下面第 3 节写了原因和可以加强的地方。

## 3. 1/4 黑剪影：两两能不能分清

判断标准：只看 1/4 的两张黑剪影图，不看颜色和标签，能不能说出是哪一台。

| 组合 | 结果 | 靠什么分 |
|---|---|---|
| L-1 / L-2 | **能分清，但最弱** | L-1 两肩对称伸出翼面，顶线是一条左右对称的横杠，3/4 视角里枪管斜指右上；L-2 的顶线左高右低，3/4 视角里剑斜指右下。腿和骨盆完全一样 |
| L-1 / M-1 | 能 | M-1 的腿粗一倍，脚是厚梯形；L-1 是细腿、关节外露 |
| L-1 / H-1 | 能 | 宽度差 1.5 m，H-1 顶部是两个圆包 |
| L-1 / H-2 | 能 | 宽度差 1.7 m；H-2 是方盒，左上角有盾板 |
| L-2 / M-1 | 能 | 同 L-1 / M-1；另外 L-2 左右不对称 |
| L-2 / H-1 | 能 | 宽度、圆顶 |
| L-2 / H-2 | 能 | 宽度、方盒、盾板 |
| M-1 / H-1 | 能 | M-1 肩线是平的、方的，H-1 是两个圆顶；H-1 宽 1.1 m |
| M-1 / H-2 | 能 | H-2 宽 1.3 m，左上角盾板高出顶线，右臂转轮炮垂到膝下；M-1 肩线左右对称 |
| H-1 / H-2 | **能分清，但偏弱** | 只能靠上半身：H-1 顶部两个圆包、肩甲是圆的；H-2 顶线是平的，左上角突出一块方盾，右臂是一整条炮。腰以下几乎一样 |

**分不清的组合：没有。**

**两对偏弱的原因：**

1. **同一副腿。** 规范本来就是"三副骨架、五套装甲"，同底盘的两台腿长、髋宽、脚形完全相同。黑剪影里腿占了一半以上的面积，能用来区分的只剩上半身。
2. **静止姿势把武器藏了起来。** 手臂垂直向下时，L-1 的长枪、L-2 的剑、H-2 的转轮炮都贴在身体两侧，轮廓上看不出差别。规范里每台的标志（"枪管超出躯干前方 2 m"、"右臂就是炮"）要到瞄准姿势才完全显出来。游戏里它们大多数时间是瞄准姿势，所以实际比这几张图更好认。
3. **L-1 的翼面在正面只是两个小凸起。** 它的识别点"背后一对翼面"主要在侧面和背面才看得到。正面和前 3/4 只能看到翼根的一截。

**可以加强的地方**（只是建议，这次没有改 H、L 的文件）：

- L 线：让 L-1 的翼面收起时向外张开一点（现在大致是贴着身体向后），正面就能看到"V"字形的顶线。L-2 背后的剑柄可以再加长一些，伸出肩线。
- H 线：H-1 背后的燃料罐稍微向两侧张开，正面就能从肩后露出来，和 H-2 的平顶拉开差距。
- 并排图换成瞄准姿势（各条线自己的 `stand_aim`）再出一套。武器伸出来以后，同底盘两台的差别会大很多。
