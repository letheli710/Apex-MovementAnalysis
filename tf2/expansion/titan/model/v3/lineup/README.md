# 五台并排

**现行版本：R5 的静止姿势并排（`r5/`）仍是默认。** R6（`r6/`，五台都摆 `stand_aim`）做了，但没有让 H-1 / H-2 更好分，所以没改默认，见第 00 节。第 0 节是 R5，第一版（V1）在最后。

## 00. R6：五台都摆 `stand_aim`（2026-11-12 夜，lead 要求）

**结论（大白话）：** 摆成 `stand_aim` 以后，H-1 / H-2 在 1/4 黑剪影里**还是分不清**：正面反而更像了（两台互不重叠的黑色从 16.4 % 降到 11.5 %），前 3/4 只从 13.7 % 升到 16.8 %。原因是 `stand_aim` 里炮正对前方，从正面看炮缩成一个圆截面，H-2 最大的标志就没了；3/4 里炮伸出来了，但很细，缩到 1/4 只剩一条线。其他 8 对本来就分得清（31–59 %），L-1 / L-2 在 17–21 %。**所以 lineup 默认仍用 R5 的静止姿势（`r5/`）**，另外做了 H-2 上半身的改法小样（下面），等 lead 审。

**怎么量的：** 每台单独渲染一张纯黑剪影（其他几台、人形块、框都藏掉），同一个正交相机比例、各自居中，480 × 480，再缩到 1/4（4 × 4 取平均，过半算黑）。两台比较时数"只有一台是黑的像素" ÷ "至少一台是黑的像素"，就是**互不重叠的比例**，越大越好分。数字和每台的单独剪影在 `r6/pair_overlap.json`、`r6/masks/`。脚本：`lineup_pose.py`（摆姿势和比较）、`build_lineup.py -- r6 pose=stand_aim`。

**摆姿势的方法：** 三条线用的是同一套规则（关节静止时不转，姿势给每个关节一个局部旋转）。M-1、H-1、H-2 用 v2 的 `stand_aim`（重型 README 第 1 节写明它用 v2 的 `stand_aim`），L-1 / L-2 用 `rig_L1/L2.json` 里轻型自己的 `stand_aim`（髋 23 / 膝 46，右手指收 25）。然后按各线 `solve_pose` 的同一条规则：脚放平（踝 −35…60 以内），最低的脚 / 脚趾 / 小腿点放到地面。L 两台 FBX 打开时是端枪的 bind 姿势（右肩 10°、肘 75°），这里一起换成 `stand_aim`。

## 3. 1/4 黑剪影：两两能不能分清

**分不清的组合：没有。**

**两对偏弱的原因：**

1. **同一副腿。** 规范本来就是"三副骨架、五套装甲"，同底盘的两台腿长、髋宽、脚形完全相同。黑剪影里腿占了一半以上的面积，能用来区分的只剩上半身。
2. **静止姿势把武器藏了起来。** 手臂垂直向下时，L-1 的长枪、L-2 的剑、H-2 的转轮炮都贴在身体两侧，轮廓上看不出差别。规范里每台的标志（"枪管超出躯干前方 2 m"、"右臂就是炮"）要到瞄准姿势才完全显出来。游戏里它们大多数时间是瞄准姿势，所以实际比这几张图更好认。
3. **L-1 的翼面在正面只是两个小凸起。** 它的识别点"背后一对翼面"主要在侧面和背面才看得到。正面和前 3/4 只能看到翼根的一截。

**可以加强的地方**（只是建议，这次没有改 H、L 的文件）：

- L 线：让 L-1 的翼面收起时向外张开一点（现在大致是贴着身体向后），正面就能看到"V"字形的顶线。L-2 背后的剑柄可以再加长一些，伸出肩线。
- H 线：H-1 背后的燃料罐稍微向两侧张开，正面就能从肩后露出来，和 H-2 的平顶拉开差距。
- 并排图换成瞄准姿势（各条线自己的 `stand_aim`）再出一套。武器伸出来以后，同底盘两台的差别会大很多。
