# SPEC 补丁（R5，2026-11-12）：重型骨长冲突

**给 titan-model-v3 会话：** 建议加到 `../SPEC.md` 第 3.2 节「要注意的实测结果」之后。SPEC 只由那个会话改，所以这里只提供文字，没有直接改 SPEC。详细数据见 `README.md` 第 0 节和 H-SK8。

---

**重型骨长（用户决定 2 的后果，11-12 R5 定）：** 重型压到 5.97 以内，骨长就不可能同时保持 `[meas]` 原值和「腿短 40 %」。处理办法是**所有骨头统一乘 0.878**：

- 0.878 = 5.95 ÷ 6.78。6.78 是 TF2 重型把腿伸直后的身高估计：待机身高 6.55，加上待机时膝盖弯曲少掉的 0.23（2.84 − 2.61）。
- 结果：大腿 / 小腿 / 踝 / 上臂 / 前臂 = 1.52 / 0.59 / 0.39 / 0.95 / 0.95。
- 静止直腿髋高 2.50，占身高 42.0 %。TF2 直腿也是 41.9 %。在 `stand_aim` 里是 41 %；TF2 待机屈膝时量出的就是那个 40 %。
- 宽度（髋间距 2.11）不缩，"重"靠宽度表现。

**重型的 5 % 验收依据：** 和「`[meas]` × 0.878」比，现在差 ≤ 1 %。和原始 `[meas]` 统一差 −12 %，原因是决定 2。

**没选的方案（留档）：**

| 方案 | 做法 | 结果 / 为什么不选 |
|---|---|---|
| A 只缩腿到 40 % | 第 1–4 轮的做法，开关 `HSD_HEAVY_RIG=A` | 腿 ×0.838 = 1.45 / 0.56 / 0.37，静止髋高 2.38 = 40 %。腿比原始值短 16 %，手臂不变（0 %），腿和手臂比例不一致。另外是拿直腿的 40 % 去比屈膝量出的 40 %，口径不同 |
| C 照原长 | 骨长全按 `[meas]` | 髋高 2.84 = 47.7 %，丢了"腿短"，违反决定 2 |
| D 只缩大腿 | 大腿缩到 1.27（−27 %），小腿和踝不动 | 大腿 : 小腿 = 1.90，实测是 2.58，腿形变了 |
| E 只改依据 | 几何不动，只换比较口径 | r4 的手臂相对身高比 TF2 长 10 %，换口径也过不了 |

**v2 姿势在重型上的默认版：** `kneel_hatch`、`landing_one_knee` 两个名字在重型上用重型自己的值：

- 右踝 30°（v2 是 55°）。
- 前腿分别是髋 40 / 膝 55、髋 52 / 膝 64（v2 是 90 / 105、100 / 110）。

原因是重型小腿和踝加起来 0.98，比大腿 1.52 短；照 v2 的角度，右脚掌会插进大腿，前脚会悬空 1.1 m。v2 原版保留成对照。
