## 00000. R6c：重型腿（重型会话改，2026-11-13，本节由 titan-v3-model 会话记）

重型会话在 Unity 里做重型走路时，膝盖弯过约 105° 的时候，摆动脚的脚跟会碰到大腿后面。改的只是腿：
- 大腿后下角削得更多，两根液压杆缩短，外侧裙甲下沿抬高约 0.2 m、背面收窄；
- 脚跟后块缩短 6 cm，脚面上块后部收进；
- 小腿前下角和脚趾顶面压低，踝能弯到 −40°。

开关是 `HSD_HEAVY_LEG=r6b`（默认 r6c）。成品 `Titan_H1.*` / `Titan_H2.*` 现在是 r6c，r6b 的副本在 `H*/r6b_final/`，新一轮在 `H*/r6c_final/`。

结果：19 / 19 姿势不穿；静止最高 5.956 / 5.950；三角面 49,696 / 43,188；FBX 往返通过。titan-v3-model 会话又跑了一遍跨线关节检查（`../checks/joint_test.py`），两台都全部贴住。

决定、数据和没选的方案见 HSD-Unity #73 的 `Animation/README-heavy-walk.md`，共享日志 `2026-11-13-titan-heavy-r6c-*`。新脚本都是重型会话写的：
- `walk_replay_blend.py`：拿 .blend 按 Unity 的 `joints.tsv` 逐帧复核；
- `unity_export.py`：给 Unity 的三角化副本，加每件面积；
- `part_boxes.py`：每件相对关节的包围盒；
- `walk_stats.py`：脚滑统计。

`build_heavy.py` 新增 `saveblend`、`replay` 两个模式。

## 0. R5 轮改了什么（2026-11-12 夜，lead 审阅、本会话执行）

1. **骨长冲突（H-SK8）**：重型压到 5.97 以内后，r4 的腿骨比实测短 16 %。R5 改成**所有骨头统一乘 0.878**（大腿 1.52、小腿 0.59、踝 0.39、上臂 / 前臂 0.95）。这个系数让 TF2 重型直腿站立的高度（6.78）正好缩到 5.95。宽度不缩。按「实测 × 0.878」比，差值都在 1 % 以内；和原始实测值比，统一差 −12 %，原因是用户决定 2。骨盆、腰和躯干转轴跟着髋往上提了 0.12。r4 的做法留作开关：`HSD_HEAVY_RIG=A`。
2. **重型自己的跪姿（H-P3）**：`kneel_hatch` 和 `landing_one_knee` 这两个名字现在指重型默认版本，所以 19 个姿势就是重型的姿势组，**19 / 19 不穿模**。和 v2 的差别有两处：
   - 右踝 30°（v2 是 55°，脚掌会插进大腿）。
   - 前腿把脚踩在地上：髋 40 / 膝 55，以及髋 52 / 膝 64（v2 是 90 / 105 和 100 / 110）。r4 的跪姿前脚悬空约 1.1 m，看图像飘着。

   v2 原版留作对照（`*_v2orig`），仍然会穿模、前脚仍然悬空，数据写在 `checks.json` 的 `pose_v2_original_compare` 里。
3. **自查发现并修好的**：

## 1. 大白话

两台共用一副新的**重型骨架**：TF2 重型的骨长统一乘 0.878（R5；r4 是腿乘 0.838、手臂不缩），静止直腿时髋高 2.50 = 42 %，`stand_aim` 姿势里 41 %；髋间距 2.11 m，手臂 0.95 / 0.95 m，身高压在 5.97 m 以内（H-1 5.956，H-2 5.950）。H-2 只换装甲和武器。

- **H-1 熔炉**（锈红 / 炭黑 / 琥珀发光）：锅炉一样的圆桶躯干，底部是 45° 的锥形「炉底」；两个直径 1.44 m 的炭黑半球肩甲；背上两个竖立的燃料罐（高出躯干顶 0.2 m，罐身有琥珀色液位窗）；右侧单圆镜头带格栅护罩；舱门做成带三道横肋的炉门；右肩甲上有朝前上 30° 的陷阱发射管；左前臂比右臂粗一圈，外侧带喷火口；右前臂是铝热剂发射器（v2 的「炮即前臂」）。
- **H-2 军团**（橄榄绿 / 哑光黄 / 正绿发光）：棱角分明的方盒躯干，前上方是斜装甲板，上面横排两个方镜头；右臂从肘往下就是 3.40 m 的六管转轮炮（管束直径 0.80 m，管束能转）；背部右侧一个直径 1.30 m 的弹鼓（能转），供弹链从弹鼓绕到右肩下、沿上臂背面接到炮尾；左肩一块竖直的黄色厚盾板，高出躯干顶 0.30 m。

**肩甲的做法**（两台一样）：肩甲固定在躯干上（和 M-1 的决定 4 一致），里面是空腔；上臂顶端是一个沿前后摆动轴的「肩鼓」，在空腔里转。肩甲前后各开一道槽，让手臂能往前、往后摆；肩鼓正好把这道槽填满，所以从正面看肩甲是实心的。

图都是 v2 的 `stand_aim` 姿势（髋 14°、膝 28°、炮水平前指）。橙色方块是 1.8 m 的人，蓝框是碰撞体 3.05 × 5.97。

## 6. 怎么重做

```bash
"/c/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b -P build_heavy.py -- H1 r5c export
"/c/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b -P build_heavy.py -- H2 r5c export
py -3 build_heavy.py compose r5c_final
```

R5 起，成品轮用 `r5x` 起名，输出到 `H*/r5x_final/`；只有加上 `export` 才会覆盖 `Titan_H*.blend / .fbx`。`final`（= r4）会被拒绝，以免覆盖 r4。诊断命令：
- `-- H1 contacts`：每个姿势的脚着地。
- `-- H1 kneelfit kneel_hatch`：跪姿前腿搜索。
- `-- H1 dbg '<json 姿势>' 件A 件B`。

r4 的骨架用 `HSD_HEAVY_RIG=A`，但姿势和 H-2 的配色是 R5 的；r4 原样在 `_r4_source/`。

（以下是 r4 时的说明）第二个参数换成 `r1` / `r2` / `r3`（可加后缀，例如 `r1g`）就只出那一轮的图，放进新的文件夹，不会覆盖。`-- H1 dbg <姿势> <件A> <件B>` 打印两件在某个姿势里相交的位置。成品那一步会覆盖 `Titan_H*.blend / .fbx` 和 `H*/r4_final/`。脚本只读 `../../v2-design/out/spec.json`（19 个姿势），不改 v2、M1、L 的任何文件。
