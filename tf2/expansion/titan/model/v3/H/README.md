# 重型泰坦 H-1 熔炉 / H-2 军团：成品

2026-11-12。规范：[../SPEC.md](../SPEC.md)（v1.2）第 3、5 节，用户原规范 `HSD_泰坦建模规范.md` 第 4.2、4.5 节。用户 11-12 要求直接做到成品，中途不停，所以下面的决定都是这里自己定的，选中的和没选的都写了（也写进了共享日志，topic「泰坦模型」，id `2026-11-12-titan-heavy-*`）。

## 1. 大白话

两台共用一副新的**重型骨架**：腿按 TF2 重型的骨长比例缩到 40 % 身高，髋宽 2.11 m，手臂 1.08 / 1.08 m，身高压在 5.97 m 以内（H-1 5.956，H-2 5.950）。H-2 只换装甲和武器。

- **H-1 熔炉**（锈红 / 炭黑 / 琥珀发光）：锅炉一样的圆桶躯干，底部是 45° 的锥形「炉底」；两个直径 1.44 m 的炭黑半球肩甲；背上两个竖立的燃料罐（高出躯干顶 0.2 m，罐身有琥珀色液位窗）；右侧单圆镜头带格栅护罩；舱门做成带三道横肋的炉门；右肩甲上有朝前上 30° 的陷阱发射管；左前臂比右臂粗一圈，外侧带喷火口；右前臂是铝热剂发射器（v2 的「炮即前臂」）。
- **H-2 军团**（橄榄绿 / 哑光黄 / 正绿发光）：棱角分明的方盒躯干，前上方是斜装甲板，上面横排两个方镜头；右臂从肘往下就是 3.40 m 的六管转轮炮（管束直径 0.80 m，管束能转）；背部右侧一个直径 1.30 m 的弹鼓（能转），供弹链从弹鼓绕到右肩下、沿上臂背面接到炮尾；左肩一块竖直的黄色厚盾板，高出躯干顶 0.30 m。

**肩甲的做法**（两台一样）：肩甲固定在躯干上（和 M-1 的决定 4 一致），里面是空腔；上臂顶端是一个沿前后摆动轴的「肩鼓」，在空腔里转。肩甲前后各开一道槽，让手臂能往前、往后摆；肩鼓正好把这道槽填满，所以从正面看肩甲是实心的。

图都是 v2 的 `stand_aim` 姿势（髋 14°、膝 28°、炮水平前指）。橙色方块是 1.8 m 的人，蓝框是碰撞体 3.05 × 5.97。

## 5. 没做到、没查到的

- **行走动画没有重定向**（任务说只写工作量）。B-沉 是给中型骨架做的：中型髋 2.85 / 大腿 1.40 / 小腿 0.75 / 踝 0.70 / 髋距 1.72；重型髋 2.38 / 1.45 / 0.56 / 0.37 / 2.11。小腿和踝短得多，直接套关节角会让脚离地或插地，步宽也差 0.39 m。要做的：按脚的轨迹重新解腿部 IK（步长按腿长 × 0.835 缩，站距加宽 0.195 / 边）；重调步频和身体起伏；重查跪姿里脚掌折到大腿的问题（H-P1）；B-沉 已知的踝 −35° 限位打滑要在重型上再看一遍。估计 1–2 天，加上在 Unity 里试走。
- **没有进 Unity。** 换模型时：`TitanImportTests` 按 `G_Foot_L`、`G_Hatch_Wing_L`、`G_Torso_Shell`、`G_Torso_Antenna` 找网格，这里的网格名是 `H1_*` / `H2_*`，测试要跟着改；`TitanPoseData.gen.cs` 要换成重型关节坐标；两台的 `J_Hatch` 位置不同；H-2 多了 `J_Barrel`、`J_Drum`。FBX 只在 Blender 里重新导入检查过。
- **静止（rest）姿势有穿模**：左手指和右前臂垂下时碰到大腿，H-2 的 3.4 m 炮垂下时穿过右腿和右脚。19 个动作姿势里都不穿；规范只要求查动作姿势。
- **动作姿势会超过 5.97**：H-1 dash 浮空 6.58；H-2 抬枪 45° 时炮口到 7.58。规范只限静止站立，v2 也超（6.16）。
- 手臂抬过水平（肩前摆 > 85°）的动作没有查（19 个姿势里最大 85°）。
- 跪姿时炮管尖没有和地面做碰撞检查（只查了部件之间）。
- 肩甲厚度是沿肩轴竖线量的（壳顶减腔顶）。
- 网格都是平直面（FBX 用面法线），没有 UV、没有贴图。
- **Google Drive**：这份 README 是过程报告，按 CLAUDE.md 第 5 节暂时不放；如果要给用户读，请 lead 决定是否抄送到 `设计规范`。

## 6. 怎么重做

```bash
"/c/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b -P build_heavy.py -- H1 final
"/c/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b -P build_heavy.py -- H2 final
py -3 build_heavy.py compose
```

第二个参数换成 `r1` / `r2` / `r3`（可加后缀，例如 `r1g`）就只出那一轮的图，放进新的文件夹，不会覆盖。`-- H1 dbg <姿势> <件A> <件B>` 打印两件在某个姿势里相交的位置。成品那一步会覆盖 `Titan_H*.blend / .fbx` 和 `H*/r4_final/`。脚本只读 `../../v2-design/out/spec.json`（19 个姿势），不改 v2、M1、L 的任何文件。
