# M-1 棱镜：成品

2026-11-12。规范见 [../SPEC.md](../SPEC.md)（v1.3）。成品阶段做的决定在 SPEC 0.2 节。

## 大白话

M-1 已经按规范第 5 节做完：剪影 → 中模 → 细节 → 材质 → 挂点，导出成 FBX。用户 11-12 改了流程，不再每一步停下来看图，所以第二轮剪影就当作定稿，后面一口气做到成品。

- **外形**沿用第二轮剪影：楔形躯干、实体肩甲、骨盆裙甲、小发射器。在这个基础上又改了几处：
  - 胸口斜面更陡（后倾 35°），顶面前沿再往后收，胸口往前顶的感觉更明显；最前沿仍然在碰撞体以内。
  - 背后加了一个下厚上薄的楔形背包。推进器横槽在下面，百叶在右侧，油管在左侧，背面不再是一道直墙，也不像一张脸。
  - 舱门拆成三块板。铰链改到外表面，这样门开到 120° 时不会转进胸口，开着的门正好像一块踏板。
- **骨架**仍然是 v2：关节位置、限位、19 个姿势全部原样，只有舱门铰链 `J_Hatch` 挪了位置。19 个姿势都摆过一遍，没有穿模。
- **材质**只有 4 个槽，名字固定。发光只有三处：胸口发射器、传感器横缝、炮身三条能量槽。
- **面数** 51,464 个三角面，在 4–6 万之内；最大的单件 4,780，没有超过 6000。
- **还没做的**：没有进 Unity，没有提交。Blender 里重新导入 FBX 是对的，但 Unity 怎么读没有验证。五台并排的对比要等 H、L 两条线出了 FBX 再补。

身高 H = 静止站立时的最高点 = **5.92 m**（左肩火箭巢顶）。数字来自 `final/m1_final_checks.json`。

| 19 个姿势摆一遍不穿模 | 通过 | 19 / 19 都不穿。肩甲和上臂另外单独查过，也不碰。中模阶段同样是 19 / 19 |
| 跪姿开舱门 | 通过 | 开口宽 1.12、沿斜面长 1.17，坐着的人要 0.60 × 0.94，放得下。三块门板开到 120° 都不碰躯干和肩甲。铰链离地 3.09 m |
| 肩甲厚 ≥ 0.45 且罩住上臂顶端 | 通过 | 上臂上方厚 0.46，外侧楔形厚 0.66，上臂顶端的圆毂（半径 0.34）在肩甲下面 |
| 半躺的 1.8 m 驾驶员装得下 | 通过 | 280 个采样点全部在关着门的躯干、舱门和背包里面 |
| 面数 4–6 万，单件 ≤ 6000 | 通过 | 51,464；最大单件 `Torso_Upper` 4,780 |
| 左右不完全镜像 | 通过 | 右前臂炮、左爪、左肩火箭巢、背后百叶在右、油管在左 |
| 背面没有像五官的对称图案 | 通过（目测） | 见 `final/colour_back.png` |
| FBX 重新导入 | 通过（只在 Blender 里） | 全部关节位置误差 0，28 个网格，高度 0–5.92。Unity 导入没有跑 |

**这些检查没覆盖到的：**

- 登机动画没有逐帧播，只查了"关门时坐得下"和"开门时门不碰东西"。
- 19 个姿势里没有手臂抬过水平的动作，这种动作没有查。
- 后仰瞄准时最高 6.20、dash 浮空时 6.21，会超出 5.97。v2 也是这样（6.16），v2 DESIGN 定过可以接受。
- 碰撞检查判断的是三角面是否相交，不判断一个件是否整个藏在另一个件里面。

## 换进 Unity 时要改的地方（这次没做）

- `TitanImportTests` 按名字找网格的四处：`G_Foot_L` → `M1_Foot_L`，`G_Hatch_Wing_L` → `M1_Hatch_Wing_L`，`G_Torso_Shell` → `M1_Torso_Upper`。`G_Torso_Antenna` 要删掉，M-1 没有天线。
- `TitanPoseData.gen.cs`：`J_Hatch` 改成 (1.42, 0, 4.30)；另外加上挪过位置的挂点（SPEC 0.2 #27）。
