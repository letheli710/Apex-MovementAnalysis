# 轻型行走重定向：方案（待 lead 批）

2026-11-12，titan-light-v3。只出方案，没有动 Unity。代码依据：HSD-Unity `titan/walk-compare` 510c971（工作树 `HSD-Unity-TITAN-WALK`，只读过）。

## 0. 大白话

B-沉 不是一段录好的动画，而是**每帧现算**的：一张"关键姿势表"给出骨盆该在哪、身体怎么晃；脚踩在地上的位置按走过的距离排好；然后用两节骨的 IK 把腿接到脚上。所以"重定向"不是改关节角度，而是**换掉腿的尺寸和几张表里跟腿长有关的数**，IK 会自己算出新的角度。

难点不在数，而在**这些尺寸现在是全局常量**（`TitanSkeleton` 里 `const`，只有中型一套），重型那边也要改同一处。所以分两步：先由一个会话把常量改成"按底盘取"（中型输出逐字节不变），再各自在自己的新文件里填轻型 / 重型的数。这样两边不碰同一批文件。

验证用两套工具：Unity 里现成的 `TitanWalkFilm`（逐帧数据 + 录像，加上真网格的脚底高度），以及把逐帧关节角导回 Blender、用 `build_light.py` 已有的穿模和关节检查在真网格上逐帧复查。

估计：**只做走路约 3 天，走 / 跑 / 冲刺 / 蹲走全做约 4.5–5 天**，其中第一步（改常量）约 1 天，重型也能直接用。

## 4. 怎么验证脚不离地、不插地

| 检查 | 怎么量 | 合格线 |
|---|---|---|
| 踩住的脚不离地 | `TitanWalkFilm` 新列：踩住时接触点（脚尖或后刺尖）离地高；`ikMiss`（IK 够不着的距离） | 每帧 ≤ 0.01 m（中型 B-沉 现在 0） |
| 不插地 | 新列：每只脚的真网格最低顶点（`Foot`、`Toe`、`Heel_Spur`、`Ankle` 四件）离地高 | 每帧 ≥ −0.01 m，两只脚、所有路线 |
| 摆动脚不蹭地 | 同一列，摆动中段 | ≥ 0.05 m |
| 脚滑 | 现成 `slide.tsv`（接触点水平移动总和） | ≤ 2.0 m / 100 m（中型 B 2.03，B-沉 4.93）；踝 −35 和 −45 各报一次 |
| 关节限位 | 现成：超限帧 | 0 |
| 真网格穿模、关节接上 | `replay_walk.py`：读 `TitanWalkFilm` 导出的逐帧关节角，摆 `Titan_L1.blend`，跑 `build_light.py` 的 `collide`、`joints_connected`、脚底高度（每 2 帧一次） | 0 次穿模；关节全接上；脚底和 Unity 量的差 ≤ 0.005 m（两边对账） |
| 中型不变 | 第一步的逐字节对照 | 相同 |
| 看 | 侧面、斜后方 30 fps 录像 + 关键姿势截图，中型 B-沉 并排 | 给 lead / 用户看 |

路线：直走（静止 1 s → 走 6 s → 停 2.5 s）、走 → 跑 → 冲刺、原地转身、蹲走 / 后退 / 横移（只报数，按现有台架）。

**后刺先要查。** 轻型脚跟有一根往后伸的刺（下沿从踝后 0.10、离地 0.02 斜到踝后 0.48、离地 0.10）。绕脚掌后沿（−0.22）滚时，脚尖抬到约 21° 刺就碰地。刺尖本身离地 0.10，不能直接当支点（`TitanFeet` 假定支点在地面上）。所以建议支点用脚掌后沿，脚跟着地时脚尖最多抬 18°（`TitanFeet` 里加一个上限，属于轻型尺寸）；"不插地"一项会直接查到。

## 7. 风险

- 中型 B-沉 的打滑来自"骨盆低 + 脚尖钉住 → 踝要弯过 35°"。轻型踝更低（0.38）、小腿更长，几何不同，可能更好也可能更糟，只能量。
- `walk-compare` 没合并到任何分支，`titan/chassis-dims` 也只能叠在它上面。合并顺序要 lead 安排。
- 轻型右腕在走路里固定 0。如果以后要边走边放低枪，右腕规则（L-D17）要搬进 Unity，这次不做。
- 方块碰撞（`TitanSkeleton.Parts`）是中型的盒子，不适用轻型。轻型的穿模只靠 `replay_walk.py` 在 Blender 里查。
