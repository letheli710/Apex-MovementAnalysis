### 0.1 r5b：关节连上（lead 11-12，R5 批准后）

lead 看到 L-1 3/4 图里膝盖处大腿和小腿断开。查了所有姿势（`_diag/diag_knee.py`）：两台的膝在**每一个姿势里都没接上**，缝 0.08–0.11 m（bind 0.02–0.04）。按同一种查法扫了所有肢体关节（`_diag/diag_joints.py`），踝 0.056、肘 0.032、腕 0.18、躯干到上臂 0.10–0.23 也有缝；髋、腰没有。一起修了（L-D20），并把"关节两边的件要接上"加进构建检查 `joints_connected`（14 个关节 × 全部姿势 + bind）。

| 关节 | 改法 |
|---|---|
| 膝 | 大腿下端加叉形件 `Thigh_Clevis`（挂 `J_Hip`）：膝轴两侧各一个圆盘（内 r 0.24、外 r 0.23 厚 3 cm），带连接条接进大腿；连接条在 z 1.97 以下不进小腿宽度。小腿护板和膝护片顶部收窄到 y 0.64–0.96，在两片圆盘之间转 |
| 踝 | 踝鼓半径 0.17 → 0.23；小腿芯往下到 0.56 |
| 肘 | 肘毂半径 0.17 → 0.195（0.21 会碰到长枪枪托） |
| 腕 | 新件 `Wrist_Hub_L/R`（挂 `J_Wrist`，腕俯仰轴上的鼓）；前臂芯往下到 2.54 |
| 肩 | 新件 `Shoulder_Socket_L/R`（挂 `J_Torso`）：从躯干侧面伸到上臂圆毂内端的短鼓 |

连带改动：枪托上沿降到 0.24（让开肘毂）。外侧膝盘起初厚 6 cm、r 0.24，蹲姿时碰到右手武器，求解器给 `crouch` 加了肘 40°，改薄后 `crouch` 回到原样。结果：L-1 29 / 29、L-2 21 / 21 不穿，关节全部接上，右腕表（L-D17）不变，武器最低 0.205 / 0.152。面数 51 780 / 49 012，部件 119 / 105。图在 `L1/r5b`、`L2/r5b`；只修膝的中间版在 `r5b_i1`。R5 版成品文件被 r5b_i1 覆盖前没有另存（R5 的图和 checks 在 `r5_final`）。

## 1. 大白话

两台共用一副轻型骨架，只换装甲和武器。

- **轻型骨架**：腿、髋、骨盆全部用 TF2 实测值（大腿 1.69、小腿 1.21、踝高 0.38、髋间距 1.57）。静止姿势（rest）是直腿，所以比站姿高 0.23；站姿时髋弯 23°、膝弯 46°，髋就落在实测的 3.05。比中型多了**右手**（L-2 要握剑）和一对**翼面关节** `J_Wing_L / _R`。
- **L-1 北辰**（深海军蓝 + 骨白，青色发光）：子弹头躯干往前伸，舱门就是"弹头"斜面；肩上是固定在躯干上的实心肩块；背上一对翼面，可收（斜向后上 45°）可展（翼展 5.5 m）；右手端 4.2 m 长枪（握在枪顶的镫形握把里），左前臂有束缚陷阱发射器；左前方三个竖排小镜头。
- **L-2 浪人**（哑光黑 + 朱红，电紫发光）：躯干比 L-1 再前倾 10°；左肩是三层叠片大肩甲，右肩几乎裸露；腰后、两侧加了裙甲，大腿前有护片；躯干中线上方一条竖缝传感器；背上斜挎 3.6 m 单刃直刀，装在剑架上；右手拿霰弹枪。
- 两台的"反关节"观感都靠**小腿外侧的长跟骨**（calf blade）和**脚跟的后刺**做出来，膝关节本身还是普通的人形膝（和中型一样），不加骨头。

## 6. 没做到的、要注意的

- **骨架色偏多**：Frame 占 31 % / 33 %（目标 22 %）。轻型"关节外露"，圆毂、液压杆、手都是骨架色；已经把四肢的骨杆改成主色，再改就看不出关节了。L-2 主色 49.5 %（目标 60）。
- ~~v2 原版的蹲姿和 dash 浮空在轻型上穿模~~（R5 已解决，L-D19）：现在只有 `dash_float_L` 左臂外展是 22（v2 是 12），轻型动画要按这个值做。
- **手臂抬过水平、各关节限位逐个扫到底**没有查（v2 做过限位扫描，这里只查了姿势）。
- ~~rest 姿势本身枪口在地下~~（R5 已解决，L-D16）：文件改成 bind 姿势打开。注意全零姿势（双臂下垂）仍然会让枪插地，Unity 不要把全零当待机姿势用。
- **右腕的值是按规则解出来的**（L-D17），Unity 动画里右腕要用 `rig_*.json` 里的值，或者照同一规则做。`landing_one_knee` 还多弯了肘 40°。
- **超出碰撞体的部分**：L-1 收起的翼面在碰撞体后面伸出约 0.5 m，长枪在前面伸出 3 m 多（v2 的炮也伸出）；瞄准向上 45° 时 L-1 枪口最高 7.36、L-2 最高 6.34，dash 浮空 6.72 / 6.15。
- **双手持枪不做**：L-1 左手空着（发射束缚陷阱），是设计如此（lead 11-12 确认保持）。
- **剑换手要 Unity 做**：拔刀时四个剑件从 `S_Sword_Back` 改挂 `S_Sword_R` 并加固定旋转（L-D10），Unity 里还没有这段代码。
- **第一人称视角**没有出图检查（v2 查过炮口在屏幕右下）。
- **Unity 没跑**：FBX 只在 Blender 里重新导入核对过。`TitanImportTests` 按 `G_*` 找网格的四处、`TitanPoseData.gen.cs`、`TitanSkeleton` 都要有轻型版本（多了右手、翼面关节，没有 `W_Cannon` / `J_Launcher_L`）。
- **轻型行走动画要重定向，这次没做**。方案见 [WALK-RETARGET-PLAN.md](WALK-RETARGET-PLAN.md)（11-12，待 lead 批；估计只走路 3–3.5 天、全部步态 4.5–5 天，替代下面这段粗估）。工作量估计：B-沉 是按中型腿长做的（大腿 1.40 / 小腿 0.75 / 踝 0.70、站姿 14° / 28°），轻型是 1.69 / 1.21 / 0.38、站姿 23° / 46°，髋间距 1.57（中型 1.72）。不能直接套用：每一帧要按新骨长重新解腿的 IK、步幅约放大 1.2 倍、重找落脚点和离地高度，翼面和枪的跟随也要加。估计每种步态（走、跑、冲刺、蹲走）1–2 天，加上 dash / 着地 / 跪姿上机各 0.5–1 天。
- **待同步到 Drive**：本 README 是给人读的文档，按工作区规则可以抄送到 Drive 的 `设计规范`。这次没有放，等 lead 决定。
