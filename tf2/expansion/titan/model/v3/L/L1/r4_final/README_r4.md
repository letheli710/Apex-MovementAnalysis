# 轻型泰坦 L-1 北辰 / L-2 浪人：成品

2026-11-12。规范：[../SPEC.md](../SPEC.md)（v1.2）+ 用户原规范 `HSD_泰坦建模规范.md` 4.3 / 4.4 节。用户 11-12 要求直接做到成品、中途不停；SPEC 4.2 节"开工时列给用户定"的几件事，这里自己定了，选中的和没选的都写在第 3 节，也写进了共享日志（topic "泰坦模型"）。**没有提交，没有进 Unity。**

## 1. 大白话

两台共用一副轻型骨架，只换装甲和武器。

- **轻型骨架**：腿、髋、骨盆全部用 TF2 实测值（大腿 1.69、小腿 1.21、踝高 0.38、髋间距 1.57）。静止姿势（rest）是直腿，所以比站姿高 0.23；站姿时髋弯 23°、膝弯 46°，髋就落在实测的 3.05。比中型多了**右手**（L-2 要握剑）和一对**翼面关节** `J_Wing_L / _R`。
- **L-1 北辰**（深海军蓝 + 骨白，青色发光）：子弹头躯干往前伸，舱门就是"弹头"斜面；肩上是固定在躯干上的实心肩块；背上一对翼面，可收（斜向后上 45°）可展（翼展 5.5 m）；右手端 4.3 m 长枪，左前臂有束缚陷阱发射器；左前方三个竖排小镜头。
- **L-2 浪人**（哑光黑 + 朱红，电紫发光）：躯干比 L-1 再前倾 10°；左肩是三层叠片大肩甲，右肩几乎裸露；腰后、两侧加了裙甲，大腿前有护片；躯干中线上方一条竖缝传感器；背上斜挎 3.6 m 单刃直刀，装在剑架上；右手拿霰弹枪。
- 两台的"反关节"观感都靠**小腿外侧的长跟骨**（calf blade）和**脚跟的后刺**做出来，膝关节本身还是普通的人形膝（和中型一样），不加骨头。

## 6. 没做到的、要注意的

- **骨架色偏多**：Frame 占 31 % / 33 %（目标 22 %）。轻型"关节外露"，圆毂、液压杆、手都是骨架色；已经把四肢的骨杆改成主色，再改就看不出关节了。L-2 主色 49.5 %（目标 60）。
- **v2 原版的蹲姿和 dash 浮空在轻型上穿模**（L-D13）。轻型版本不穿，但这只是姿势参数，动画要按轻型版本做。
- **手臂抬过水平、各关节限位逐个扫到底**没有查（v2 做过限位扫描，这里只查了姿势）。
- **rest 姿势本身**：手臂下垂时枪口在地面下 0.54（L-1），霰弹枪碰右小腿外侧长跟骨（L-2）。rest 只是参照姿势，游戏里不会出现。
- **超出碰撞体的部分**：L-1 收起的翼面在碰撞体后面伸出约 0.5 m，长枪在前面伸出 3 m 多（v2 的炮也伸出）；瞄准向上 45° 时 L-1 枪口最高 7.27、L-2 最高 6.29，dash 浮空 6.72 / 6.15。
- **双手持枪没做**：L-1 左手空着（发射束缚陷阱），枪只挂右手。
- **剑换手要 Unity 做**：拔刀时四个剑件从 `S_Sword_Back` 改挂 `S_Sword_R` 并加固定旋转（L-D10），Unity 里还没有这段代码。
