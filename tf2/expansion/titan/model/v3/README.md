## 这个文件夹里放了什么

- 所有脚本（`.py`）、说明（`.md`）、每一轮的检查数字（`checks.json`）。
- 每台的成品 `.blend` 和 `.fbx`。
- **只有最后一轮的渲染图**：`M1/final/`、`H/H1/r4_final/`、`H/H2/r4_final/`、`L/L1/r4_final/`、`L/L2/r4_final/`，加上并排图 `lineup/`、`L/lineup/`、`H/compare/` 和重型两台的四轮 3/4 汇总图 `H/H1/rounds_3q.png`、`H/H2/rounds_3q.png`。
- **中间轮次的图只留在本机的 `TF2-Research/expansion/titan/model/v3`**，没有进仓库（一共约 139 MB）。各子文件夹 README 里提到的剪影轮、中模轮、细节轮的 PNG 都在那里。
- **中间轮次的 `.blend` 放进来了**（L-1、L-2 的 r1–r3 和 M-1 的剪影稿，一共约 2.2 MB）。理由：中间轮的图不进仓库，留下这几个小文件，以后还能打开当时的模型看；H 线的中间轮没有单独存 `.blend`，可以用 `build_heavy.py` 重新生成。Blender 的自动备份 `.blend1` 没放。
