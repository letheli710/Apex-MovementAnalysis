## 0. 这次改了什么、为什么改

v1 的方向不变：三副骨架 + 五套装甲，先过剪影再谈细节，肩宽过髋、小腿和脚有体量、一个主色占大头。改动是把 v1 里和**已经做好、要保留的东西**（v2 的碰撞体、骨骼、关节限位、行走动画 B-沉、挂点、武器、舱门）对不上的地方改过来，并把能用实测数据的地方换成实测。

## 3. 全体通用规则

### 3.1 比例铁律

1. **肩宽 ≥ 髋宽 × 1.5。** 肩宽 = 正面看肩甲外缘的距离；髋宽 = 正面看、髋关节高度上骨盆和大腿的外缘距离。
2. **小腿围度 ≥ 大腿。** 用最粗处的宽 × 厚比较。
3. **脚长 ≥ 身高 × 0.22**（含脚趾），脚要有厚度和脚趾分件。不许平板脚。
4. **没有脖子，没有独立的头。** "头"是嵌在躯干前上方的传感器。
5. **腰高 ≤ 身高 × 0.06。** 量法：站立静止时，骨盆顶到躯干下段底的可见间隙。同时必须让出 v2 的弯腰范围（前弯 45、后仰 25、侧弯 ±30、扭 90 再前弯 45 时躯干下段不碰骨盆）。
6. **站姿微屈膝。** 用 v2 的 `stand_aim` 姿势出图（髋 14°、膝 28°），不改动画。
7. **肩宽靠装甲体量。** 薄板、悬空板凑出来的宽度不算数。肩甲厚度至少 0.45 m，并且要罩住上臂顶端。正面看，躯干到肩的上沿要是一条连续的线；剪影缩到 1/4 时，不能看出括号、衣架、桌面的形状。

"身高" = 静止站立（v2 的 rest 姿势）时网格最高点，不含天线。

**要注意的实测结果：**

- **重型不矮。** v1 写重型"矮宽"、身高 5.80、比中型矮，这个说法删掉。实测重型髋低（2.61 vs 2.80），但上身更高：待机轮廓顶 6.55，比中型的 5.92 高 0.63，也高出共用碰撞体 0.58。这个数取自动画序列文件里的包围盒，比真实网格偏松，但 MDL 头里的轮廓也给出重型 6.70、中型 5.78，方向一致。
- **用户决定（11-12）：重型压到 5.97 以内**，"重"靠宽度和厚度表现，保留"腿短（40 %）、上身大"的比例。没选：照 TF2 做到 6.55。理由：三型共用碰撞体，超出上沿的部分子弹会直接穿过去。
- **腿长占比是 53 / 48 / 40 %**，三型差距比 v1 写的（57 / 52 / 47）更大，重型尤其腿短。
- **中型 v2 的髋比 TF2 宽**（1.72 vs 1.20）。这是 v2 为了让大腿从躯干下段两侧扫过特意加宽的（v2 DESIGN 第 1 节第 2 条），保留。
- 轻型和重型的大腿、上臂骨长几乎一样（1.69–1.73 / 1.08），区别主要在小腿、踝高和骨盆高。

**重型骨长（用户决定 2 的后果，11-12 R5 定，H-SK8）：** 重型压到 5.97 以内，骨长就不可能同时保持 `[meas]` 原值和"腿短 40 %"。处理办法是**所有骨头统一乘 0.878**：

- 0.878 = 5.95 ÷ 6.78。6.78 是 TF2 重型把腿伸直后的身高估计：待机身高 6.55，加上待机时膝盖弯曲少掉的 0.23（2.84 − 2.61）。
- 结果：大腿 / 小腿 / 踝 / 上臂 / 前臂 = 1.52 / 0.59 / 0.39 / 0.95 / 0.95。静止直腿髋高 2.50，占身高 42.0 %（TF2 直腿 41.9 %）；`stand_aim` 里 41 %，TF2 的 40 % 就是在屈膝待机时量的。
- 宽度（髋间距 2.11）不缩，"重"靠宽度表现。
- 5 % 验收的依据改成"`[meas]` × 0.878"，现在差 ≤ 1 %；和原始 `[meas]` 统一差 −12 %，原因是决定 2。
- 没选：**A** 只缩腿到 40 %（第 1–4 轮，腿 −16 %、手臂 0 %，比例不一致，而且拿直腿的 40 % 比屈膝量出的 40 %，开关 `HSD_HEAVY_RIG=A` 留着）；**C** 照原长（髋 2.84 = 47.7 %，丢了"腿短"）；**D** 只缩大腿到 1.27（大腿 : 小腿 = 1.90，实测 2.58，腿形变了）；**E** 只换比较依据、几何不动（r4 的手臂相对身高比 TF2 长 10 %，换依据也过不了）。
- 重型的 `kneel_hatch`、`landing_one_knee` 用重型自己的值（右踝 30°，前腿髋 40 / 膝 55、髋 52 / 膝 64）：重型小腿加踝 0.98，比大腿 1.52 短，照 v2 的角度右脚掌会插进大腿、前脚悬空 1.1 m。v2 原版保留作对照。

**没选的数据（留档）：** v1 的三组碰撞体 2.70×6.10 / 3.05×5.97 / 3.80×5.80，以及 v1 的轻 / 重型肩宽、髋宽、躯干、腿长 3.5 / 2.7、腿长占比 57 / 47 %、身高 6.10 / 5.80。不用的理由：碰撞体与 TF2 实测不符（三型同一体型），而且要动游戏里的移动和地图数据；腿长和身高与实测骨架不符。肩宽、髋宽、躯干、脚这几项没有可靠实测，暂作 `[design]` 保留。

- **躯干是楔形。** 正面看是倒梯形：肩线最宽（含肩甲 3.90），躯干本体 2.00，往下收到躯干下段 1.00（v2 规则：躯干下段半径 ≤ 0.50，腰转 85° 时不碰大腿）。侧面看，胸口在 z 4.1–4.4 往前凸到 x 1.40，从那里往上是一个后倾 26° 的斜面，一直到顶（顶面前沿 x 0.72），舱门就在这个斜面上。
- **肩甲是实体块。** 固定在 `J_Torso` 上，顶面平（z 5.44），和躯干顶部连成一条线。在上臂上方厚 0.46，外侧往下延伸成实心楔形，到 4.78 时厚 0.66，背后有一块后裙。上臂顶端是一个沿转轴方向的圆毂（半径 0.34），填满肩甲下面的空间，手臂前后摆动时圆毂不会抬高。
- **骨盆有裙甲围领。** 后面和侧面高到 3.35，前面斜着压低，给前弯 45° 让出空间。可见腰高 0.26。
- **胸口发射器**：核心直径 0.40（成品；剪影稿 0.44），外面一圈 0.64 的深色格栅环和 8 颗螺栓，在中间那块舱门板上，朝向跟着斜面，中心是 `S_Chest`。
- **传感器**：横缝，宽 0.60、高 0.12，在 `J_Optic`（z 5.40），在斜面上、舱门上方。
- **座舱**：驾驶员半躺（后仰 40°），臀在 `S_Seat`（z 4.28），腿往前伸进胸口凸出的部分。第一人称看到的座舱另做模型。
- 左肩后上方是 v2 的火箭巢（`J_Launcher_L`），是全身唯一的不对称凸起，兼作 `S_Mine_L`。右前臂炮、左三指爪（v2）。
- **不带天线**（决定 3）。

**肩甲挂在哪儿（决定 4，用户 11-12 同意方案 A）：**

| 方案 | 做法 | 好处 | 代价 | 状态 |
|---|---|---|---|---|
| A 挂躯干 | 肩甲跟着 `J_Torso`，手臂在下面动 | 任何姿势肩线都平，剪影稳定 | 上臂顶端要做成圆毂；肩甲底面在 4.98，外侧楔形的下底面要斜着让开，手臂往外抬 30° 才不碰。19 个姿势都不碰。19 个姿势里没有手臂抬过水平（肩前摆 > 90°）的动作，这种动作没有查 | **选中** |

**专属挂点：** `S_Chest`（核心）、`S_Shield_L`（左前臂外侧，新增）、`S_Mine_L`（火箭巢，新增）。

## 5. 给 Blender 建模 AI 的工序要求

**文件与单位**（不变）米，缩放 1.0，Z 朝上，泰坦面朝 −Y，脚底在 Z = 0。导出 FBX 用 Unity 预设、应用变换。场景放 1.8 m 人形方块。每台一个 `.blend`，`Titan_<代号>.blend`。

**分件**
- 按骨骼分件，每个刚体部件是独立物体，不合并、不蒙皮。**一件只跟一根骨骼**；一根骨骼可以带几件。
- 每个部件的原点放在它的关节转轴上。
- 物体命名 `<代号>_<部件>_<L/R>`，例如 `M1_Forearm_L`。换进 Unity 时，同步改 `TitanImportTests` 里按 `G_*` 找网格的四处。

**分件 ↔ 现有骨骼（中型）：**

| 规范要的件 | 跟哪根骨骼 | 说明 |
|---|---|---|
| 骨盆（含髋轴） | `J_Pelvis` | |
| 腰盘 | `J_Waist` | 不转；躯干在它上面转（v2 的腰转、弯在 `J_Torso`） |
| 躯干（上段、下段）、肩甲 L/R（M-1） | `J_Torso` | |
| 舱门（含 M-1 发射器） | `J_Hatch` | |
| 传感器 | `J_Optic` | |
| 火箭巢 | `J_Launcher_L` | |
| 上臂 L/R | `J_Shoulder_L / _R` | |
| 前臂 L | `J_Elbow_L` | |
| 前臂 R | `W_Cannon` | 就是炮 |
| 手 L（掌 + 三指） | `J_Wrist_L`、`J_Finger_L_1..3` | 比规范多三根指骨 |
| 手 R | — | **没有**，v2 右臂是炮 |
| 大腿、小腿 L/R | `J_Hip_*`、`J_Knee_*` | |
| 踝、脚、脚趾 L/R | `J_Ankle_*` | **没有脚趾骨**，脚趾是跟踝骨的独立件。要能弯就要加 `J_Toe_*`（改骨架和 B-沉，没选） |

**建模顺序（每步出图给用户看，过了再往下）**
1. 剪影稿：15–20 种基础体块，正、侧、背、前 3/4 四张纯黑剪影 + 灰度体块图 + 和上一版的对比图。
2. 中模：体块切成装甲板，硬边倒角 2–4 cm。
3. 细节：螺栓、格栅、液压杆、管线，集中在关节和背部。**螺栓只放在有东西被固定的地方**：接缝、铰链、装甲板的角和边；大平面上不放，不要均匀撒（R5 #33）。
4. 材质与挂点。

**面数预算**（不变）每台 4–6 万三角面，单件 ≤ 6000。

**禁止项**（不变）方块脑袋、独立脖子、细柱腰、平板脚；背面不许出现像五官的对称图案（v2 背面两个通风口 + 一个圆喷口就是"笑脸"）；三种以上装甲色、发光超 3 %；左右完全镜像。

**验收清单**
- [ ] 纯黑剪影缩到 1/4，能和其他几台分清（做到第二台起才能查）
- [ ] 肩宽 ≥ 髋宽 × 1.5（3.1 节的量法）
- [ ] 小腿最粗处 ≥ 大腿最粗处
- [ ] 腰高 ≤ 身高 × 0.06，且弯腰范围内躯干下段不碰骨盆
- [ ] 脚长 ≥ 身高 × 0.22
- [ ] 静止站立最高点 ≤ 5.97（天线除外；后仰瞄准时超出可以，v2 也到 6.16）
- [ ] 与 3.2 节 `[v2]` / `[meas]` 值相差不超过 5 %；`[design]` 值只作参考
- [ ] 挂点按 3.3 节对照表齐全，名字一字不差
- [ ] 只有 4 个材质槽，名字正确；颜色占比按**看得见的像素**量（R5 #36）
- [ ] 螺栓都贴在外壳上（底面离外壳 ≤ 1.5 cm），大平面上没有螺栓（R5 #33、#38）
- [ ] 每个部件原点在关节上；v2 的 19 个姿势逐个摆一遍不穿模
- [ ] 手臂抬过水平：写出不穿模的上限（信息项，R5 #37）
- [ ] 每个关节两边的件，在静止和全部姿势里都贴住（表面相交或 ≤ 5 mm，R6 #40、#41）
- [ ] 跪姿开舱门：开口宽 ≥ 0.60、高 ≥ 0.94，并写出舱口离地高
- [ ] 肩甲厚 ≥ 0.45 且罩住上臂顶端；黑剪影缩到 1/4 看不出括号或方盒子
- [ ] 半躺的 1.8 m 驾驶员（臀在 `S_Seat`）整个装得进关着门的躯干
