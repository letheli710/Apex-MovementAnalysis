# HSD 泰坦：占位符设计方案（草案，等用户确认）

写于 2026-11-01。

**一句话：** 不等原型。先用占位符做一台能上机、能开、能打的泰坦，边玩边定设计。每个占位符都标明有多准：准的当真值验收，模糊的只求能玩，以后直接换掉。

"占位符"在这里包括两种：**数值和规则**（速度、血量、技能），**外观和表现**（模型、动画、镜头）。

## 1. 为什么现在就能做

1. **移动数据已经够了。** T0 把 7 台泰坦的走、跑、冲刺（dash）、转向都实测过了（[T0-REPORT.md](T0-REPORT.md)）。
2. **开泰坦时基本看不到泰坦。** 第一人称坐在舱里，主要看到舱框、HUD 和枪。模型模糊，对"开起来什么感觉"影响不大。外观主要在上下机和站在它旁边时才看得见。（这条是我对 TF2 的印象，没有实测，T1 试玩时验证。）
3. **代码不用大改。** `MovementWorld` 的 `hullRadius`、`hullHeight`、`stepUp` 已经是可改的字段；战斗场是 x 3700–7000、y 700–1500 的平地，没有障碍物，放得下 120 u 宽的泰坦。
4. **7 选 3 可以晚点定。** 底盘只有三种，先玩底盘，再选泰坦。

## 2. 占位符清单：哪些准，哪些模糊

| 级别 | 含义 | 怎么用 |
|---|---|---|
| **A 精准** | TF2 实测过 | 照搬，写成自动测试，差了算错 |
| **B 半精准** | 从 TF2 文件读到，没在运行中验证，或只有部分验证 | 照搬，标"未实测" |
| **C 模糊** | 我们自己定的，或只有方向 | 只求能玩，随时换 |
| **D 没数据** | 还没研究 | 先研究再做；要提前做就标"猜的" |

### A 精准（T0 实测）

| 项 | 轻型 Stryder | 中型 Atlas | 重型 Ogre |
|---|---|---|---|
| 走 / 冲刺跑（u/s） | 270 / 400 | 250 / 380 | 210 / 310 |
| 0 → 走速 | 0.19 s | 0.19 s | 0.24 s |
| 走 → 冲刺跑（"重"的主要来源） | 1.02 s | 1.25 s | 0.80 s |
| 松手减速（u/s²） | 约 1770 | 约 1500 | 约 1165 |
| dash 速度 / 次数 | 800 / 2 | 700 / 1 | 600 / 1 |
| dash 回能（每秒） | 10，每次耗 50 | 16.6，每次耗 100 | 9.9，每次耗 100 |

三种底盘共用：

- 体型 120 × 235 u，眼高 185 u，台阶 80 u。
- 不能跳、不能滑铲、不能蹬墙。
- 鼠标转速和铁驭完全一样（2000 计数都转 144.78°），手柄 × 0.75。
- 上机动画约 3.45 s，下机 1.03–1.42 s，铁驭出现在泰坦上方 120–170 u。

### B 半精准（文件数值，部分验证）

- 血量和护盾：7500 / 10000 / 12500 + 2500。
- 7 台的武器和技能数值（[titans/README.md](titans/README.md) 第 2 节）。
- 拳击 500 伤害，距离 280。
- 视角弹簧（被打和开火时的晃动），刚度 / 阻尼：35 / 9、65 / 15、95 / 30。

技能的移动效果（悬停、相位冲刺、核心减速）实测过，算 A。

### C 模糊（只求能玩）

| 项 | 第一版占位 | 以后换成 |
|---|---|---|
| 外观 | 方块和圆柱拼的灰盒，零件按简报 5.2 命名；三种底盘只改比例。方向参考 `Weathered Titan in the Ruined City.png`（躯干为主、单眼、细腰、爪脚） | Blender 模型，接口不变 |
| 舱内 | 屏幕边一圈舱框 + 现有 HUD | 正式驾驶舱 |
| 手里的枪 | 沿用 `HeldModels` 的静态模型，放大 | 正式模型和动画 |
| 上下机 | 不播动画，只有镜头移动和计时（时长是 A） | 动画 |
| 脚步和震动 | 按 T0 的镜头数值，声音先用占位 | 正式音效 |
| 对铁驭武器的血量比例 | 先用 TF2 数值，平衡以后再调 | PvE 平衡时定 |

### D 没数据（TITAN-LIST 第 3 节，都还没测）

呼叫降落、自动泰坦、濒死、处决、弹射、核弹弹射、牛仔骑乘、电池、核心充能来源。

已有工具可以测（`hsd_titan` 等命令）。按"研究 → 做"的顺序来，不提前做。

**用户 2026-11-02：** 捡电池、拆电池、处决动画都不做，太难处理，也不适合 HSD。目标是玩法加一些简单好看的动画（比如登场）。上面列表里这几项不用再研究。

## 3. 分几步做

| 步 | 内容 | 做完能怎样 | 验收 |
|---|---|---|---|
| **T1 开起来** | 三种底盘的移动、镜头、上下机、灰盒；Esc 里切底盘 | 走到灰盒旁按键上机，开着跑、冲刺，再下机 | 第 2 节 A 级数值写成测试；铁驭移动哈希 741/741 不变 |
| **T2 打起来** | 主武器、血量和护盾、ADS 减速、拳击、大号假人 | 开着泰坦打靶，也能被打 | B 级数值写成测试 |
| **用户试玩 → 选泰坦** | 用 T1、T2 的手感填 TITAN-LIST 抉择列 | 定下 3–4 台 | 用户决定 |
| **T3 套件** | 只做选中泰坦的技能和核心 | 每台有自己的玩法 | 技能的移动效果对上 T0 实测 |
| **T4 系统** | 先测第 2 节 D 级，再做 | 呼叫降落、濒死、弹射等 | 对上新实测 |

**美术是另一条线，不卡这条线。** GPT 原画和 Blender 继续做，好了就替换灰盒。

## 4. 技术做法

- **单独写 `TitanMotor`，不改 `R5MotorV2`。** 泰坦的两段加速、冲刺跑慢爬坡和 dash 规则和铁驭不同，分开写才能保证铁驭手感一点不变。
- **上机时切换。** `SkillBody.motor` 现在固定是 `R5MotorV2`，所以 T1 第一件事是让 `PracticeSession` 在驾驶时改走泰坦这一路。不驾驶时走原来的代码，靠哈希检查保证。
- **数值放配置，每项写来源。** 沿用 `provenance` 的做法，标 `[meas T0]`、`[set]`、`[placeholder]`，一眼能查到哪些还是占位。
- **基于哪个分支：** 建议 `combat/wp4-placeholder-models`，等它的准星修复提交之后再开。T2 要用 Arsenal 武器和 `HeldModels`，这些都还在未合并的 #60、#61 里。代价是整条 PR 线又多一层。
- **不上机就没有影响：** 不驾驶泰坦时，游戏和现在完全一样。

## 5. 用户曾有的印象和实测不一样，需要留意

用户之前感觉"泰坦比铁驭转得慢"。T0 实测：**鼠标不慢，只有手柄慢 25 %**。"重"主要来自冲刺跑爬坡慢和镜头。

## 6. 待定（都有默认值，不用马上答）

| # | 问题 | 默认（推荐） | 另一个选项 | 数据 |
|---|---|---|---|---|
| 1 | 鼠标转向 | 和 TF2 一样，不减速 | 开关：按底盘把鼠标输入乘一个系数，试玩时对比 | TF2 的七台泰坦和铁驭都是 144.78°。T0 建议不做上限和平滑，会"卡手" |
| 2 | 身高和碰撞体 | 碰撞体和眼高照 TF2（235 u ≈ 6.0 m，眼高 185 u ≈ 4.7 m），模型比碰撞体略高 | 按原画 7 m（约 276 u）放大碰撞体，走速和地图尺度都要重新看 | 原画写的有 6.5 m、7 m、7.4 m，不统一；只有 235 / 185 是实测 |
| 3 | 第一批做几种底盘 | 三种都做，差别只是数据 | 只做中型，更快 | T0 表 |
| 4 | 第一轮的武器 | 每种底盘配一把：轻型散弹、中型步枪、重型机枪 | 只做一把共用，更快，但试玩时分不出底盘的火力差别 | TF2 武器数值（B 级） |
