# TF2 泰坦的动画混合和手感：重做 HSD 泰坦时照着做的参考（T-c）

2026-11-09，会话 `tf2-titan-anim`。只借规则和数值，不用 TF2 的模型、动画、声音、截图。HSD 现在的泰坦只读对照，没有改 Unity。

**数据等级：** 〔动画〕= 解码游戏模型（MDL v53）里的序列和动画数据；〔文件〕= 设置文件、武器文件、脚本；〔原生〕= 从 `client.dll` / `server.dll` 读出的 ConVar 默认值；〔实测〕= 本地 Northstar 逐帧记录（这次没有新开 TF2，用的是 11-02、11-03 已有的运行）；〔推断〕= 由数据推出、没有直接验证。单位 1 u = 2.54 cm；"周期"指一个完整左右步。

---

## 先说结论（白话）

1. **TF2 泰坦的身体动作几乎全是美术做好的循环片段，程序只做五件事：** 按移动方向在 3 个片段之间混合、按速度调播放快慢、把瞄准姿势叠在上面、脚落地时用 IK 贴地、腿落后视线 60° 才转过去。HSD 现在反过来，全靠程序算，所以"像什么"只能靠调参数去凑。
2. **"重"不是靠慢，是靠"稳"。** TF2 三种底盘走路的周期都是 1.133 s（一步 0.57 s），比 HSD 现在的 B-沉（一步 0.42 s）慢约 35 %。站着的时候完全不动（待机片段里骨盆、胸、手臂的摆动都 < 0.3°），没有呼吸晃动。持枪的右臂走路时几乎不动（肩 3°、肘 5°），只有空手的左臂在摆。
3. **健康时头和骨盆是一块铁。** 走路时头相对骨盆的高度只变 2.8 u（相关 0.99），上身和下身只在"扭"上反向（骨盆扭 13°，胸反向扭 10°），不在"上下"和"左右"上各晃各的。TF2 想让泰坦看起来"坏了"的时候（濒死走），恰恰是把这个关系拆开：头相对骨盆变 16.8 u、相关只有 0.64。**HSD 当时"像喝醉"的样子，就是 TF2 濒死走的样子。**
4. **骨盆最低点正好在脚踩实的那一刻**（IK 落脚相位 0.294，骨盆最低 0.294），最高点在两腿交错时；起伏几乎是纯正弦（非正弦成分 0.6 %）。所以"顿挫"不是曲线形状做出来的，而是**脚、骨盆、镜头、声音四件事在同一刻发生**。
5. **起步和停步没有专门的片段。** 起步靠"走路片段 0.95 s 慢慢混入 + 播放速度跟着实际速度从 0.25 倍起涨"，停步靠"0.55 s 混出"。电机本身 0.19 s 就到走速，所以身体比速度慢半拍，这就是惯性感。
   - **11-09 补测更正**（[ref-gait/REF-GAIT-1109.md](ref-gait/REF-GAIT-1109.md)）：换序列的混合时长是 min(旧混出, 新混入)，所以待机→走、走/跑→待机都是 0.2 s，走↔跑 0.55 s；满速 250 u/s 走路播的是跑片段（门槛 0.45 × 站姿速度 = 112.5 u/s）；播放速度 = v ÷ 地速但有 0.15 死区，匀速时比目标慢最多 0.14。上面"0.95 s 混入、0.55 s 混出"是推断，保留作对照。
6. **镜头和身体是两套系统。** 第一人称镜头的走路起伏是 0.70 s 的定时器，枪的晃动周期 0.69 s，和它对齐；身体动画在第一人称里根本看不见（驾驶舱里看不到自己的腿）。
7. **上半身动作（开火、换弹、受击）都是"叠加层"**，按骨骼权重只作用于上身：腿 0、骨盆 0–0.1、脊柱约 0.6、手臂 1、镜头骨 0。所以开火、换弹、挨打时腿照走、镜头不被身体带歪。
8. **核心技能、换武器，不是加一个动作，而是整套换掉**：比如 Ion 激光核心开着时，走、跑、蹲、待机、开火、瞄准全部换成"胸口发射"版本（12 个序列）。模型用"活动修饰"（activity modifier）按武器名挑序列。

对 HSD 的意思：要么照 TF2 的结构做（美术片段 + 薄程序层，第 4 节给了步骤），要么继续程序生成但守住第 3 节的十几条约束。两条路都能脱离 TF2 照做；还缺的只有几项需要再开 TF2 才能量的（第 5 节）。

## 1. 整体结构

### 1.1 一帧里身体是怎么算出来的

```
① 选主序列：引擎按"活动"(ACT_MP_WALK_FORWARD…) + 活动修饰(武器名、ads、crouch…) 挑一个序列
② 主序列内部混合：move_yaw（或 move_yaw_backward、sprinttilt）在 3 个片段间线性插值
③ 序列之间换：旧序列按 min(旧 fadeout, 新 fadein) 淡出，权重 smoothstep（11-09 原生；原写"按新序列的 fadein，走/跑 0.95 s"是推断，不对）
④ 播放速度：实际水平速度 ÷ 片段自带的地速，限在 [0.25, 10]，冲刺 ≤ 1.25
⑤ 自动叠加层：主序列自带一个 3×3 瞄准层（aim_yaw × aim_pitch），权重 1，一直开
⑥ 手势层：开火、换弹、受击、技能，叠加型（delta），按每块骨头的权重只作用上身
⑦ 身体朝向：腿（"feet yaw"）落后视线，差超过 60° 时目标整跳 60°，腿以 400 × min(1, 差/60) °/s 追（时间常数 0.15 s；11-09 原生）
⑧ 脚 IK：片段里标好每只脚什么时候踩实（IK ground 规则），踩实时把脚锁在地面并把骨盆按地面高度修正
```

① ② ③ ⑤ ⑥ 都写在模型里〔动画〕；④ ⑦ ⑧ 的参数是引擎 ConVar〔原生〕。

### 1.3 序列选择：活动 + 活动修饰

每个序列带一个活动名和 0–3 个修饰名〔动画〕。修饰就是"当前状态的标签"，最常见的是武器或核心的类名：

| 修饰 | 换掉的序列（中型，举例） |
|---|---|
| `ads` | 待机、开火叠加层换成瞄准版 |
| `mp_titancore_laser_cannon`（Ion 核心） | 12 个：待机、蹲、走、跑、蹲走、开火、瞄准层全换成胸口发射版 |
| `mp_titancore_salvo_core`（Tone 核心） | 8 个，同上 |
| `mp_titanweapon_xo16_vanguard` 等武器名 | 换弹手势换成这把枪的 |
| `mp_titanweapon_rocketeer_rocketstream` | 冲刺跑也换（扛火箭的冲刺姿势） |
| `mp_titanweapon_predator_cannon`（Legion） | 重型 21 + 20 个：整套持枪姿势 |
| `mp_titanweapon_flightcore_rockets`（Northstar 核心） | 轻型 16 个：dash、跳跃全换飞行版 |
| `melee_titan_sword`、`mp_titancore_shift_core`（Ronin） | 剑的走路、格挡、换手 |
| `movingforward/backward/left/right` | 起跳、滞空按移动方向选 |

**照做：** HSD 的动画状态机做成"状态 × 标签集合 → 片段"的查表。核心技能、换武器只改标签集合，不写新的状态。

### 1.4 脚怎么贴地

每个移动片段里写好了 IK 规则〔动画〕。中型走路（`a_WalkForward`，周期 1.133 s）：

| 规则 | 脚 | 开始 | 满权重 | 满权重到 | 结束 | 踩实相位 |
|---|---|---|---|---|---|---|
| ground | 左 | 0 | 0 | 0.206 | 0.471 | 0 |
| ground | 右 | 0 | 0.294 | 0.588 | 1.0 | **0.294** |
| ground | 左 | 0.471 | 0.765 | 0.941 | 1.0 | **0.765** |
| release | 第 3 链 | 0 | 0 | 1 | 1 | — |

- 每条规则的探测高度 50 u、脚半径 15 u。
- 左脚满权重从 0.765 到下一周期 0.206（0.44 周期 = 0.50 s），右脚 0.294 到 0.588（0.29 周期 = 0.33 s），**不对称**：持枪的右侧身体前倾，右脚支撑短〔推断〕。
- 冲刺跑多两条 `unlatch` 规则（右 0–0.24–0.6，左 0.12–0.72–1.0）：冲刺时锁脚提早解开，脚可以滑一点换取流畅〔推断〕。
- dash（起、飘、落）、跳跃、上下机、弹射、处决：**全程 release，不做脚 IK**。
- 待机：两只脚整段 ground，满权重。

### 1.5 镜头和动画的关系（总规则）

- 第一人称镜头**不挂在身体骨骼上**。走路片段里 `jx_c_camera` / `jx_c_pov` 骨骼高度变化 0（`cam_z` 峰峰 0）〔动画〕；实测走路时镜头只动约 0.36 u，而骨盆起伏 15.5 u〔实测，POSE §4.1、GAPS §6〕。
- 所有上身叠加层给镜头骨的权重都是 0〔动画〕，所以开火、换弹、受击的身体动作不会推镜头。
- 镜头只在"脚本序列"里由动画驱动：上机（约 3.25 s 的 1P 动画）、下机、弹射、处决、近战（POSE §4.5）。

## 3. 手感细节：TF2 靠什么"好"，HSD 可能缺什么

每条：TF2 的做法和数据 → HSD 现在（只读对照：`titan/walk-compare` `510c971`，B-沉 默认，数据取自那次的会话报告和 `WALK-DEEP-DIVE.md`）→ 照做。HSD 的数是另一套测量（米、骨骼定义不同），**只能比方向和量级**。

**F1 步频和步幅。** TF2 三种底盘走路周期都是 1.133 s（轻 1.0 s），一步 0.57 s，步幅 139.5 u（约髋高 117 u 的 1.2 倍）〔动画〕。重型和中型用同一套走路片段，"重"不靠步子短。HSD B-沉一步 0.42 s，快 35 %，步子短。→ 走速 250 u/s 下一步 0.55–0.6 s，步幅约 1.2 倍髋高；重型要显重，改上身和手臂（F5、F11），不缩步幅。

**F2 站着就是不动。** 中型待机 `a_MP_CQB_idle` 1.93 s 循环，骨盆、胸、手臂所有通道峰峰都 < 0.3°（轻、重的待机片段 0.33 / 0.67 s，同样不动）〔动画〕。没有呼吸晃动，没有重心摇摆。→ 待机姿势完全静止；"活"的感觉交给舱内的 HUD 和声音。

**F3 头和骨盆刚性同步，只有扭转反向。** 中型走：头相对骨盆的高度差峰峰 2.8 u，相关 0.99；轻 2.5 u，重 5.6 u。扭转：骨盆 12.9°、胸 10.1°，互相关最佳滞后 0.38 周期（接近反向）；冲刺时骨盆扭 42°、胸反向 20°〔动画，`walkphase.py` + 本节的互相关〕。HSD 第一轮"醉"的主因正是腰侧弯和骨盆滚转同向叠加，头和髋反着走（相关 −0.998）；B / B-沉 把躯干滚转压到 1°左右〔HSD 报告〕。→ 上下、左右上身跟骨盆走（腰不做独立的侧弯摆动）；只有扭转让胸反向抵消骨盆的扭转，比例约 0.8（走）/ 0.5（冲刺）。TF2 的胸滚转峰峰 10.7°，比 HSD B-沉的 0.9° 大很多，说明 HSD 现在可能压过头，显得"僵"——但两边滚转的定义没对齐，先按"胸滚转不超过骨盆滚转的 1.3 倍、方向不和骨盆同向叠加"去检查，而不是追 10.7° 这个数。

**F4 骨盆最低 = 脚踩实。** 骨盆最低点 0.294 = 右脚 IK 踩实相位；最高点在两脚交错处（0.03）。曲线 98 % 是纯二次谐波，非正弦成分 0.6 %〔动画〕。HSD B：骨盆最低点在落脚后 0.085 s，第一轮有"落脚那一帧掉 5.8 cm"的跳变〔HSD 报告〕。→ 骨盆高度直接用 `cos(4π(φ − φ_contact))` 型的平滑曲线，最低点放在踩实时刻；不要靠腿长反推出"一帧掉下去"。顿挫感来自 F8 的对齐，不是曲线上的尖角。

**F5 持枪臂稳、空手臂摆。** 中型走：右臂（持枪）肩 3.0°、肘 4.7°；左臂肩 10.8°、肘 34.6°。冲刺：右 12° / 35°，左 39° / 59°。重型冲刺左臂肩只有 1.9°：重型连空手都锁住〔动画〕。→ 持枪臂锁在瞄准姿势上（只随瞄准层），空手臂按步态摆；底盘越重摆得越少。HSD 的手臂由 titan-weapon 接管（`LendArm`），走路时持枪臂是否在晃要看录像。

**F6 起步惯性。** 走的混入 0.95 s，播放速度从 0.25 倍起跟着速度涨〔动画 + 原生〕；电机 0.19 s 到走速。所以速度先到、腿后到。HSD `moveW` 上升 τ 0.22 s（95 % 约 0.66 s），起步第一步 0.458 s〔HSD〕。→ 移动权重用 0.9–1.0 s 线性或 smoothstep 混入，不用一阶指数（一阶指数前段太快）；腿相位按走过的距离推进（等效于"播放速度 = 速度 ÷ 片段地速"），下限 0.25。

**F6 · 11-09 补测（[ref-gait/REF-GAIT-1109.md](ref-gait/REF-GAIT-1109.md) §1）：** 上面的"0.95 s 混入"和"从 0.25 倍起涨"是推断。实测：待机→走只混 0.2 s（混合时长 = min(旧混出 0.2, 新混入 0.95)），到 ≥ 112.5 u/s 再混 0.55 s 换成跑片段，所以从按键到身体完全进入跑约 0.6 s；播放速度起步时从 1.0 开始，按 v ÷ 地速只在差 > 0.15 时改写，匀速时比目标慢最多 0.14，脚会滑（最多约 40 u/s）。"身体比速度慢半拍"的感觉主要来自这 0.6 s 和死区，不是 0.95 s。→ 移动权重按片段规则 0.2 s + 0.55 s 混；播放速度照抄带死区的规则，或把死区缩小换取不滑脚（那就和 TF2 不同）。

**F7 停步不回弹。** 混出 0.55 s；实测 0.5 s 速度到 0、0.9 s 回到站姿〔动画 + 实测〕。片段里没有"停步晃一下"。HSD 第一轮停步回弹 1.26–1.70°，B 以后 0〔HSD〕。→ 保持 0 回弹：停步只做"把走路权重 0.55 s 降到 0"，不加任何欠阻尼弹簧。

**F7 · 11-09 补测（[ref-gait/REF-GAIT-1109.md](ref-gait/REF-GAIT-1109.md) §3）：** 起作用的是待机的混入 0.2 s，不是走的混出 0.55 s。250 u/s 松键后 0.17 s 速度到 0，再约 0.05 s 换待机，再约 0.2 s 身体回到站姿：松键到站稳约 0.4 s（原记的 0.9 s 不是身体）。→ 停步把走/跑权重 0.2 s smoothstep 降到 0；仍然 0 回弹。

**F8 落脚时刻对齐。** 脚步事件（声音、灰尘）在 IK 踩实前约 0.06 周期（中型走 0.235 对 0.294，即 0.067 s）；冲刺两者重合（0.24 / 0.72）〔动画〕。镜头起伏用另一个 0.70 s 定时器，不对齐（GAPS §6）。→ 脚步声和地面灰尘挂在"脚接触地面"那一帧（比完全锁住早约 0.07 s），骨盆最低点在锁住那一帧；镜头照用定时器。

**F9 转身：腿落后 60°。** 见 §2.4。HSD 已照做（60° 才迈、每步 60°、0.42 s）〔HSD WALK-DEEP-DIVE §3.6〕。→ 保留；把"60°"和"400 °/s"写成参数，名字对应 `mp_maxbodyyaw` / `mp_bodyyawrate`。

**F10 横移靠腰扭。** 腿朝移动方向、胸朝视线，腰扭到 ±85°（POSE §2.2）。HSD 的建模目标腰 ±35°（POSE §6 方案 B 推荐 ±85，待定）。→ 腰扭范围至少 ±85°；否则横移只能做螃蟹步。

**F11 冲刺的样子。** 胸前倾 41°、骨盆俯仰几乎不变、骨盆扭 42° 胸反向 20°、骨盆滚转 25°；转弯时整套换到 Lean 片段，骨盆侧倾 ±34°、髋降 16 u〔动画〕。倾斜按 120 °/s 转速到顶，有自己的加速度（35）不跳〔原生〕。→ 冲刺姿势用一张关键姿势表，不从走路参数外推；转弯倾斜用"转速 ÷ 120 °/s"做目标，二阶追随、临界阻尼。

**F12 驾驶舱：镜头不跟身体。** 第一人称起伏 = 定时器（走 0.70 s、冲刺 0.417 s）+ 舱体弹簧（k 65、d 9）+ 每步竖直冲量（轻 −6、中 −5、重 −4 u/s），下沉 0.32 u；舱框转身最多落后 33 px、τ 0.37 s；视角事件（落地、开火、受击）带着舱框一起动（GAPS §5–6、T-f §1）。HSD `TitanCamParams.cs` 已逐条照做〔HSD 代码，只读〕。→ 保留。重做身体时**不要**把镜头挂回骨骼上。

## 4. 具体操作

### 4.1 照 TF2 的结构做（推荐给"以后更好的版本"）

前提：新模型有骨架（蒙皮或刚性部件挂骨骼都行），能播放 Unity AnimationClip。片段由 HSD 自己做（手 K 关键姿势或动捕），只借下面的规格。

1. **片段清单（每种底盘一套，可以共用）。** 待机（静止，1–2 s 循环）；走：前、左前 45°、右前 45°（1.13 s，地速 246 u/s ≈ 6.25 m/s，按 HSD 尺寸换算）；后退走、左后、右后（1.8 s，87 u/s）；后退跑 3 向（0.8 s，282 u/s）；冲刺：中、左倾、右倾（0.83 s，438 u/s）；蹲走 3 向（1.13 s）；dash 起 / 飘 / 落 × 左前右 × 前后两组（0.2 / 0.27 / 0.4 s）。
2. **每个循环片段标三样东西：** 根运动地速（用来算播放速度）；每只脚的踩实窗口（开始、满、放开、结束，相位值照 §1.4）；脚步事件相位（比踩实早 0.06 周期）。
3. **Unity 结构：**
   - Base Layer：1D Blend Tree，参数 `moveYaw`（−90…90），前进组和后退组各一棵，按 §2.5 的方向判断切换。
   - 状态之间的过渡时间：进走 / 跑 0.95 s，出 0.55 s；冲刺进 0.95 s（轻、重 0.2），出 0.2 s；dash 每段 0.15 s；蹲走 0.2 s。
     - **11-09 补测更正：** 实际时长是 min(旧序列混出, 新序列混入)：待机↔走 / 跑 0.2 s，走↔跑 0.55 s，跑→冲刺 0.55 s，冲刺→跑 0.2 s，→dash 0.15 s（[ref-gait/REF-GAIT-1109.md](ref-gait/REF-GAIT-1109.md) §2、§3）。
   - 播放速度 = 水平速度 ÷ 片段地速，钳到 [0.25, 10]，冲刺钳到 ≤ 1.25。 **11-09 补测：** 另加 0.15 死区（差超过 0.15 才改写），停下置 1.0；走 / 跑按 v ≥ 0.45 × 站姿速度选（[ref-gait/REF-GAIT-1109.md](ref-gait/REF-GAIT-1109.md) §1、§2）。
   - 播放速度 = 水平速度 ÷ 片段地速，钳到 [0.25, 10]，冲刺钳到 ≤ 1.25。
   - Aim Layer：Additive，3×3 2D Blend Tree（aimYaw ±85、aimPitch ±70），权重 1，冲刺时权重 0。
   - Gesture Layer：Additive + Avatar Mask，权重按 F16（腿 0、骨盆 0.1、脊柱 0.6、手臂 1）；开火 0.3–0.5 s、受击 1.27 s、换弹按换弹时长缩放；进出 0.2 s。
4. **程序层（脚本）：**
   - 腿朝向：落后视线 ≤ 60°，超了以 400 °/s 追；
   - 冲刺倾斜：目标 = 转速 ÷ 120 °/s，钳 ±1，二阶追随；
   - 脚 IK：踩实窗口内把脚锁在世界坐标，骨盆高度按两脚地面高度修正（速度 2 × 步长 / s）；
   - 标签集合（§1.3）：武器、核心、ads、蹲 → 选片段。
5. **镜头不接骨骼：** 继续用 `TitanCamParams.cs` 那套（定时器起伏、舱体弹簧、dash 滚转、落地冲量、受击 jolt）。
6. **验收：** 用 §3 的数逐条量：周期、骨盆最低点相位、头 − 骨盆高度差、持枪臂角度、待机静止、停步回弹 0。
