# T-1 / T-7：EPG 火箭跳（真实开火）和投掷物击退

日期：2026-10-29。工作区 `TODO.md` 的 T-1（来自 R5 研究 D-48）和 T-7。**只做研究，不改 Unity。** 场景和指标逐项对照 R5 research #64（`Apex-MovementAnalysis/research/epg/EPG-ROCKET-JUMP.md`，下称"R5"）。

环境：
- TF2 v2.0.11 + Northstar 1.31.14，本地私服，地图 `mp_lf_stacks`。
- MP 铁驭 `pilot_grapple_male`，每次试验前血量设为 1000（防止自伤致死）。
- 144 fps；每种情况 3 次，标准差 < 1 的不写。

证据等级：**[meas]** 本次实测；**[native]** 游戏文件 / 脚本原文；**[inf]** 推断。

## 1. 结论（先看这里）

1. **TF2 的 EPG 能真开火，推人的规则和 R5 是同一套引擎击退。** [meas]
   - 速度变化 ≈ 推力 / 100；
   - 推力和伤害按同一个比例随距离衰减；
   - 方向从爆点指向身体中心；
   - 上限约 1000 u/s（实测 997）。
   - R5 #64 用模拟开火得到的规则，在 TF2 真开火下全部成立。
2. **普通 EPG 不能火箭跳；`jump_kit` 模式能，推力和 R5 完全一样（65000）。** [meas][native]
   - TF2 的 EPG 基础模式武器文件里没有 `impulse_force_explosions`，实测爆炸推力是 17500（等于直接命中的 `impulse_force`，推断是缺省时用它 [inf]）。
   - 结果：站着朝脚下打只有 48 u/s 的水平推动，不起飞；空中打 +167。
   - 换 `jump_kit`（65000，自伤 ×0.75）才是火箭跳。另有 TF2 独有的 `rocket_arena` 模式（55000，伤害 35）。
3. **同样的推力，TF2 飞得比 R5 高很多，主要因为重力小。** TF2 下落重力 600，R5 750。
   - 跳 + 开火同时按：TF2 约 716 u，R5 486；
   - 站着开火：TF2 334 u，R5 270。
   - 爆炸半径也不同：TF2 30 / 150，R5 52 / 180。所以 TF2 的推力随俯视角衰减得更快（45° 只剩 0.63，R5 0.89）。
4. **地面门槛比 R5 低，而且没有"一下跳到 266"的台阶。** [meas]
   - TF2：站着时推力 ≤ 17500 完全不动，25000 起按推力线性给速度（25000 → 240）。
   - R5：≤ 31000 不动，31500 一下就是 266。
   - 空中两边都没有门槛。
5. **冲刺中不能开火。** TF2 冲刺时武器是放下的。按下开火后约 0.26–0.31 s 才真正发射（武器抬起）。所以"冲刺跳 + 开火"实际是起跳后约 0.28 s 才炸，这点和 R5 不同。[meas]
6. **投掷物**：[meas]
   - 手雷（50000）和炸药包（50000）朝脚下炸，都推 484 u/s（地面最高 199 u，空中最高 484 / 457 u）。
   - 重力星对自己**完全没有作用**（脚本只拉敌方队伍）。
   - 铝热剂、电烟雾有伤害但没有击退。
   - 手雷对自己伤害 200，正常血量必死；炸药包 125 也必死。
7. **自伤**：EPG 基础 90（100 血的铁驭只剩 10）、`jump_kit` 68（90 × 0.75，和 R5 同一行脚本）、`rocket_arena` 35。TF2 没有护盾，R5 的"护盾挡击退"在 TF2 无对应。[meas][native]

**对 HSD 火箭跳（D-56）的含义**（只是信息，不是改动建议）：

- "照 TF2 做"实际上就等于"照 R5 的 `jump_kit` 做"：推力、自伤系数、击退规则相同。
- 两边飞行高度不同，是重力和爆炸半径造成的，不是火箭跳规则不同。
- TF2 原版 EPG 本身不是火箭跳武器。
- 你提到 TF2 的机动比 Apex 快、不一定适合 HSD：这一项上，如果按 R5 的重力和半径，就自然得到 R5 #64 的高度（270 / 486）。

## 2. 方法

- 管线：`runtime/runner.py` + 诊断模组 `HSD.TF2Diag`。本次新增的服务端命令：
  - `hsd_weapon <类名> [模式…]`：重新给武器并带上模式；
  - `hsd_hp`：设血量；
  - `hsd_throw <投掷物> <引信> [偏移]`：用武器本身的 `FireWeaponGrenade` 在脚边放一颗，伤害和推力是它自己的；
  - `hsd_detonate`：引爆炸药包；
  - `hsd_blast <推力>`：脚本 `RadiusDamage`，同 R5 的推力扫描；
  - 每次被伤害打印一行 `HSDDIAG DMG`（伤害、伤害力向量、伤害点相对位置、来源）。
- **EPG 是真开火**：本地按 `+attack`，真实弹体飞行、碰撞、爆炸。俯视角用 `hsd_setup` 设置。
- 指标（`runtime/analyze_t1.py`）：
  - Δv = 开火后 1.5 s 内单帧最大的速度跳变（客户端逐帧）；
  - 最高点 = 之后脚离地面的最大高度。
  - **注意**：`mp_lf_stacks` 到处有顶，出生点上方脚的最高高度约 503。超过的情况用"爆炸后一帧的高度 + vz² / (2·600)"计算（下表标"算"）。在没碰顶的情况下，计算值和实测值完全一致（334 / 334、456 / 456、248 / 248）。

## 4. 静态依据

- **武器文件**（`scripts/weapons/mp_weapon_epg.txt`，VPK 解包）[native]：
  - 基础：`impulse_force` 17500、无 `impulse_force_explosions`、`explosion_damage` 90（MP）、`explosion_inner_radius` 30、`explosionradius` 150、`explosion_damages_owner` 1、弹速 2000、`ammo_clip_size` 5、射速 1 / s。
  - 模式：`jump_kit`（17500 / 65000）、`pro_screen`、`slowProjectile`、`rocket_arena`（弹速 1750，17500 / 55000，伤害 35）。
- **自伤脚本**（`mp/_base_gametype.gnut`，Northstar.CustomServers 和训练关版本相同）[native]：
  - `explosion_damages_owner` 为 0 就不伤自己；
  - `jump_kit` 的弹体对自己伤害 ×0.75；
  - ×2 推力那行被注释掉。
  - 与 R5 #64 §5 所述完全相同。
- **击退设置**：TF2 的 `server.dll` 里没有 R5 的 `damageImpulseScale` / `damageImpulseScaleAir` / `damageImpulseSpeedBoostLimit` / `damageImpulseSpeedLossLimit` 这几个 setfile 键（字符串扫描），是 Apex 后加的。上限约 1000 在两边一样，推断是代码里的同一个常数 [inf]。
- **重力星**（`mp_weapon_grenade_gravity.nut`）：触发器按队伍过滤，只拉敌方；对自己既不拉也不推，实测一致。

## 5. 未解

1. 地面门槛的精确值（17500 – 25000 之间），以及它的判断方式（看起来是竖直分量被吃掉，30° 时只剩水平分量）。
2. EPG 基础模式的爆炸推力是"缺省时用 `impulse_force`"还是别的来源 [inf]；读 `server.dll` 的武器参数读取可以确认。
3. 冲刺后武器抬起的确切时间（0.26–0.31 s 是"按下 → 爆炸"的总时间，含弹体飞行约 0.02 s）。
4. 滑铲开火水平增益为什么不稳定（447±240）。
5. 没有露天场地，超过约 503 的最高点是按公式算的。
