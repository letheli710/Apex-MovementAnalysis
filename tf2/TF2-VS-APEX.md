# Titanfall 2 和 Apex 的移动：发现与差异

2026-10-28。面向读者的汇总，细节和证据在各阶段报告里（[README](README.md)）。

- "Apex"指本项目的 R5 基准（R5Flowstate，S21 客户端）。
- "TF2"指 Titanfall 2 v2.0.11 的 MP 铁驭。
- 单位：长度 u（英寸），速度 u/s，加速度 u/s²。
- 结论来自静态分析（读游戏文件和反编译代码），2026-10-29 起大部分已在游戏里实测（T5，[runtime/T5-REPORT.md](runtime/T5-REPORT.md)）。仍需确认的标 ⚠。

## 1. 一句话

**Apex 的移动代码几乎全部来自 TF2。** 地面、空中、滑铲、lurch、镜头的代码结构相同。两边手感的差别主要来自三件事：

1. 参数不同：加速分段、跳跃高度、重力。
2. Apex 新加的惩罚规则：连跳扣速、反复跳的高度惩罚、硬着陆减速。
3. Apex 把蹬墙跑和二段跳关掉了。代码还在，只是在设置里关了。

## 2. 总览

| 方面 | 规则相同吗 | 数值相同吗 | 一句话差别 |
|---|---|---|---|
| 地面速度上限 | 是 | 是（173.5 / 260） | 没有差别 |
| 地面加速 | 是（同一个三段函数） | **否** | TF2 只开了一段：2500。Apex 是 2500 / 450 / 100，所以加到冲刺速度慢很多 |
| 地面减速 | 是 | **否** | TF2 1500，Apex 1250 |
| 地面摩擦公式 | 是 | — | 两边都不用 `sv_friction` |
| 空中控制 | 是 | 是（60 / 500） | 没有差别 |
| 空中额外加速 | 是 | 是（2.0） | TF2 设计它是为了帮助蹬墙跑起跑，Apex 关了蹬墙跑但保留了它 |
| 跳跃 | 是 | **否** | TF2 起跳 300 u/s、下落重力 600（跳得高、滞空久）；Apex 289.8 u/s、重力 750 |
| 连跳（落地后马上再跳） | **否** | **否** | TF2 几乎不罚；Apex 罚得重。这是 bhop 手感差别的根源 |
| lurch（起跳后转向） | 是 | 是 | Apex 改了名字，加了速度截断 |
| 滑铲 | 是 | 几乎 | 只有 `slideDecel` 不同（50 / 100） |
| 二段跳 | 是 | **否** | TF2 所有铁驭都有；Apex 默认关（只有 Sparrow） |
| 蹬墙跑、挂墙 | 是（代码还在） | **否** | TF2 开；Apex 在设置里关了，残留数值慢很多 |
| 镜头 | 是 | 几乎 | 只有蹬墙跑侧倾角不同（15° / 10°） |

## 3. 逐项对照

### 3.1 地面加速：同一个函数，不同的分段

两边都用同一段代码选加速度（TF2 `0x18016ea60`，R5 `Ground_GetAccel`）：

```
如果在滑铲：             用 slideAccel
否则如果 冲刺段开着 且 速度 > 走路上限 − 1：  用 sprintAcceleration
否则如果 低速段开着 且 速度 < lowSpeed：      用 lowAcceleration
否则：                   用 acceleration
结果再乘 player+0x1600
```

T5 实测：TF2 的 player+0x1600 不是移动倍率。ADS、兴奋剂只改速度上限，加速 2500、减速 1500 都不变。Apex 的加速乘移动倍率，这一点 **Apex 改过**。

值为 −1 表示这一段关闭。

| 键 | TF2 | Apex |
|---|---|---|
| `acceleration` | 2500 | 450 |
| `lowSpeed` / `lowAcceleration` | −1 / −1（关） | 120 / 2500 |
| `sprintAcceleration` | −1（关） | 100 |
| 实际效果 | 任何速度都按 2500 加速，冲刺几乎瞬间到速 | 低速 2500，中速 450，冲刺段只有 100，到满速要好几秒 |

### 3.2 地面减速

选减速度的规则相同（TF2 `0x18016eda0`）：

```
速度 > 走路上限：用 sprintDeceleration；没有就用 sprintAcceleration
滑铲中：         松开蹲或反向输入时用 slideWantToStopDecel，否则用 slideDecel
上面得到的值还是 −1 时：用 deceleration
deceleration 也是 −1 时：用 acceleration × 0.6
```

| | TF2 | Apex |
|---|---|---|
| 站立减速 | 2500 × 0.6 = **1500** | `deceleration` **1250** |

摩擦公式两边相同，有两个要点：

- 速度在输入方向上的分量会保留，最多保留到目标速度，只有其余部分被减速。所以边走边转弯不会掉速。
- 受到冲击（击退、爆炸）后，会有一段 \|冲量\| × 0.003 秒的时间完全没有摩擦，最后 0.5 秒恢复。两边都有。

### 3.3 连跳：差别最大的地方

两边都有"落地后马上再跳"的规则（skip），但 Apex 改得非常重，还新加了两条规则。

| 规则 | TF2 | Apex |
|---|---|---|
| 判定窗口 | 落地后 **0.1 s** 内 | 落地后 **1.0 s** 内 |
| 每跳扣水平速度 | **12** | **100** |
| 扣到多少为止 | **450** | 冲刺上限 **299** |
| 跳跃高度 | × 0.75 | 不变（只在速度 > 450 时才降） |
| 反复跳的高度惩罚（`antiMultiJump*`） | 没有 | 有（0.15–0.75 s 窗口，高度 × 0.3） |
| 硬着陆减速（`landSlowdown*`） | 没有 | 有（1 s） |

**结果**：在 TF2 里，450 以上的速度连跳每次只掉 12；在 Apex 里，任何高于冲刺上限的速度跳一次就掉 100。所以 TF2 的连跳能保速、能越跳越快，Apex 不行。

### 3.4 跳跃和重力

| | TF2 | Apex |
|---|---|---|
| 跳跃高度 `jumpHeight` | 60 | 56 |
| 重力倍率 `gravityScale` | 0.8（实际 600） | 1.0（实际 750） |
| 起跳竖直速度 √(2 · sv_gravity · H)（起跳不乘 gravityScale） | **300**（实测约 298） | **289.8** |
| 理论跳跃高度 v²/(2 · 下落重力) | **75** | **56** |
| 走过台阶高度 | 18 | 22 |

TF2 起跳时用满重力 750 计算起跳速度，下落时却只用 600。所以起跳更快、下落更慢，跳得比 Apex 高约三分之一（75 u 对 56 u），滞空也更久。（2026-10-29 更正：原先按 268.3 推出"起跳更慢"，是把 gravityScale 误算进了起跳；T5 冒烟测试实测约 298。）

### 3.5 空中

| | TF2 | Apex |
|---|---|---|
| `airSpeed` / `airAcceleration` | 60 / 500 | 60 / 500 |
| 公式 | 每帧最多加 500 × dt，不乘目标速度 | 相同 |
| 额外空中加速 | 已超过目标速度时，还能沿输入方向加 2.0 × dt，但总速度不超过原来的 3D 速度 | 相同 |

这条额外加速的引擎说明写着"帮助开始蹬墙跑"。它会把竖直速度转成水平速度，R5 M2 测到的"空中残余增益 ∝ vz²"就是它造成的。

### 3.6 lurch

TF2 叫"keyboard grace"，Apex 改名叫 `jump_grace`，数值一个没变。

| 项 | TF2 | Apex |
|---|---|---|
| 满强度窗口 | 起跳后 0.2 s | 0.2 s |
| 强度降到 0 | 0.5 s | 0.5 s |
| 强度 | 0.7 | 0.7 |
| 速度改变上限 | 0.7 × 冲刺速度 | 0.7 × 冲刺速度 |
| 必须新按方向键 | 写死在代码里（T5 ✓：起跳前按住的键不触发） | 变成 ConVar `require_tap` 1 |
| 高速截断 | 没有 | 1100 以上不触发 |
| 连按衰减 | 没有 | 有（默认关） |

### 3.7 滑铲

| 项 | TF2 | Apex |
|---|---|---|
| 起滑速度 | ≥ 200 | ≥ 200 |
| 起滑方向 | 偏离视角 ≤ 53°（cos 0.6） | 相同 |
| 加速 | +150，不超过 400（T5 ✓：260 → 398.7） | 相同（Apex 乘移动倍率；TF2 是否乘没测出来 ⚠） |
| 加速冷却 | 2 s，从上一次起滑算（ConVar） | 2 s（改成了 setfile 键） |
| 滑行减速 | `slideDecel` **50** + 速度衰减 0.7^t | `slideDecel` **100** + 0.7^t |
| 滑铲跳 | 高度 50；水平速度不变（T5：251、354、389 都不变，`slideMaxJumpSpeed` 不起作用） | **改过**：抬到 350 并返还加速。2026-10-29 按 T5 更正，原写"相同" |
| 空中起滑 | 不行 | 有门槛 90（Apex 新加） |
| 滑铲超级跳 | 没有 | 有（Apex 新加） |

## 4. Apex 改了什么：清单

**Apex 新加的规则（TF2 没有）**
1. 反复跳的高度惩罚 `antiMultiJump*`
2. 硬着陆减速 `landSlowdown*`
3. lurch 高速截断（1100）和连按衰减
4. 滑铲超级跳、空中起滑门槛
5. 蹬墙跑和攀墙的新键：竖直增益截断、天花板限制、蹲下脱墙、蹬墙减速
6. 蹬墙跑镜头抖动

**Apex 改了规则或数值**
1. 连跳惩罚：0.1 s / −12 / 450 → 1.0 s / −100 / 299
2. 地面加速分段：只开一段 → 三段全开
3. 跳跃：60 × 0.8 → 56 × 1.0
4. 钩爪拉力：1000 → 1500
5. 若干 ConVar 改成 setfile 键：滑铲冷却、5 个蹬墙跑参数

**Apex 关掉的（代码还在）**
1. 蹬墙跑、挂墙
2. 二段跳（只给 Sparrow）

**完全没动的**
地面速度上限、空中控制、空中额外加速、lurch 数值、滑铲规则、冲击后低摩擦、视角弹簧和落地踢。
