# R5 补测单（2026-11-13）

## 先说结论

R5 的移动已经研究透了。没研究透的集中在三块：**开枪手感的几个关键项**、**第一人称持枪动画**、**一批只在用到时才要补的移动边角**。这份单子把它们按"要什么条件才能测"分成四批，每项写明为什么要测、怎么测、现在的依据在哪。

- **A 批**要你让出鼠标和窗口焦点，约 15 分钟，影响最大，建议最先做。
- **B 批**是枪械补测，runner 能自动跑，不用你在场。
- **C 批**是第一人称动画，一半是实测，一半要读原生代码。
- **D 批**是移动边角，只在 HSD 真的要用那个动作时再测。

还有一些本地 R5 测不了，放在最后一节，不排进来。

依据：`research/DESIGN-PHILOSOPHY.md` §10–§11（main）；`research/combat/gun-measure/INDEX.md`、`D-EXTENSIONS.md`、`B-STATES.md`（research #95，没合并）；`research/combat/MOVEMENT-ANIMATION.md` §10（research #97，没合并）；`phase2-local` 各阶段报告里写了"没测"的条目（M8、M10、M5.5、M6-C）。
