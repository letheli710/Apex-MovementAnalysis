## 最初的目标

**一句话**：通过本地 R5Flowstate（Apex S21 社区版）研究 Apex 的移动机制，用研究结果做 **High Speed Doom**。这是一款 Unity 游戏，让 Apex 玩家在里面练移动手感。

**要研究的东西**：地面摩擦和加速、空中控制、动量保持，以及高级技巧（lurch / tap strafe、蹬墙跳、翻越加速 / superglide 等），后来扩展到各传奇的机动能力。

**一开始就定下的原则**
- **参考，不是照抄**：Apex 是参照物，HSD 可以有自己的设计（后来分成 Reference / Fun 两套配置）。
- **自动化、可重复的实验优先**：用游戏原生接口（机器人命令 `BotCmd_*`、`bridge_move_trace`、职业变量）按帧发输入，少靠手玩。每个条件至少 5 次有效试验，分析结果由主控重跑核对。
- **研究对象是本地离线 R5Flowstate S21**（S21 客户端 + S3 专用服务器 + SDK），不是官方版本；不连在线服务，不上传游戏文件。
- **证据分级**：源码证实 / 逆向注释 / 合理推断 / 未验证假设（Phase 1 起），后来简化成 [meas] / [native] / [design]。

**最初的计划**："High Speed Doom：Apex 移动机制提取与 Unity 转化执行计划"，M0 → M5：
搭环境 → 自动跑测循环 → 基础移动参数 → 高级技巧模型 → 传奇移动原件 → 技能槽和第一版可玩版本。
Phase 1（云端静态分析）的核心判断是：**真正的移动算法在闭源 exe 里，开源 SDK 只有钩子和参数接口**，所以必须靠实测。

**目标后来怎么扩展的**

| 时间 | 变化 | 原因 |
|---|---|---|
| 10-21 | 加 M5.5：镜头和第一人称反馈 | 第一版试玩时动作很难感觉到 |
| 10-21 起 | M6–M10：高级身法、HSD 原创动作、更多传奇 | 原计划 M0–M5 做完，继续扩库 |
| 10-23 | 加原生代码研究（N 系列，D-15） | 用 Ghidra / Frida 解释实测，给每个数值找到来源 |
| 10-24 | B 系列：移植后续赛季的移动改动（B1） | 你想要 S27 的翻越加速 |
| 10-25 | 手感验收改成叠图对比（F 系列，D-25） | 没有动画，真人试玩的感觉不可靠 |

**对照目标，现在做到哪了**
- "研究 Apex 移动"：基础移动、高级技巧、9 个传奇的机动能力都有实测数据，大部分还有原生代码的解释。**这部分基本完成。**
- "转化进 Unity"：Reference 配置在同样输入下和 R5 的一致率是平地 99.6 %、技能 89 %、攀爬 89 %、镜头 72 %。**这部分大部分完成。**
- "让 Apex 玩家练手感的游戏"：有练习地图、组合训练场、技能槽和传奇选择，但还没有动画，也没有正式的关卡、技能配置和平衡。**这是离最初目标最远的一块。**

## 2. 各阶段做了什么、得到了什么

### Phase 1 / 1.5（云端 Agent）
- **研究**：R5Flowstate SDK 静态分析（架构、移动代码、可 mod 能力、实验计划）。
- **成果**：HSD.MoveDiag mod v0.2、hsdtel 遥测管线、实验文档、Unity 数据契约。位置 `research/phase1/`、`research/phase2-prep/`。

### M0–M3（10-20）自动化管线和基础移动
- **M0**：本地 R5Flowstate 跑通，基线 = 训练场 + Gibraltar + 空手（移动倍率 1.15）。
- **M1**：AgentLink 自动跑测（按帧发输入、不抢焦点）：`research/phase2-local/tools/hsd_session.py` / `hsd_trial.py`；新建 Unity 工程 `HSD-Unity`，回放误差 32 u。
- **M2**：17 种基础条件 × ≥5 次，参数表 `m2/PARAMETER-TABLE.md`（地面加速、减速、跳跃、滑铲、反多跳规则）。`R5MotorV2` 终速误差 0.000 %，M1 误差降到 1.4 u。
- **M3**：lurch 模型（0.2 s 全强度、0.5 s 消失、上限 209.3）、蹬墙、翻越、翻越加速窗口（最后 133 ms）。客户端固定 120 fps（D-02）。

### M4–M5.5（10-21）传奇能力和第一版可玩版本
- **M4 / M4b**：7 类移动原件进 Unity（兴奋剂、跳板、升梯、喷气、钩爪、落地减速、Horizon 空中参数）。钩爪不是钟摆，是"沿绳加速 + 横向刹车"。
- **M5**：技能槽、Reference / Fun 两套配置、练习地图、第一版 `HSD-Practice.exe`，`FINAL-REPORT.md`。
- **M5.5**：第一人称反馈（镜头、滑铲反馈、钩爪状态、一键演示）。你认可镜头手感 → 方法写成 `fps-camera-design` skill（D-05）；M5.5 定为两个仓库的 `main`（D-06）。

### M6（10-21）高级身法和传奇机动
- **M6-A**：lurch / tap strafe 细节、攀爬 / 翻越 / superglide（原生 460）、滑索（有 Super Jump，跳离 = 绳向·min(v,400)+289.8）。
- **M6-B**：Valkyrie、Ash、Loba、Alter 研究 → 只做 Valkyrie 喷气和 Ash 相位突破，Loba、Alter 搁置（D-07，`SHELVED-ABILITIES.md`）。
- **M6-C**：组合训练场（J–P 段）、自动驾驶跑圈、F9 / F10 反馈记录。

### M7–M9（10-22）HSD 原创动作和移动库
- **M7-A**：跑墙、抓边悬挂、二段跳。R5 没有 → HSD 设计，Reference 关、Fun 开，游戏内 7 / 8 / 9 切换（D-08）。
- **M8 移动库**：跳跃键仲裁、斜坡滑铲、滑索修正、兔跳 / lurch / superglide、跳板二段跳、Horizon。R5 实测、资料研究、Unity 三线并行。
- **M9**：滑索空中上绳修正、身法资料库、Revenant、Vantage。E1–E3 三个设计问题暂缓（D-09）。

### M10（10-23）更多传奇
- Pathfinder 钩爪（72 次实测拟合）、Zipline Gun、Octane（兴奋剂、跳板、天花板滑行）、滑铲规则、按键输入层、Wraith 传送门 + 相位。
- 决定：跳板起飞不开 lurch 窗口（Reference 按 R5，D-10）；Ash 冲刺不做（D-11）；Wraith 传送门做（D-12）；客户端 / 服务端不一致时跟 S21 客户端（D-13）。
- **M10-R**：技能代码一技能一文件夹 + 中文 README（D-14）。单圈 80.82 → 78.98 s。
